# 10.3.15-18 会话管理 Python 对齐修复设计

## 背景

对 `internal/swarm/server/session/` 包逐函数对照 Python `jiuwenswarm/server/runtime/session/` 审查后，发现两处代码逻辑差异和一处计划标记过时。

## 修复项

### 1. IMPLEMENTATION_PLAN.md 标记修正

**问题：** 第677行 `AutoTitle回填⤵️11.x自动标题` 标记过时。AutoTitle 已在 `session_utils.go` 中完整实现，且在 `session_metadata.go` 两处调用点已回填。11.x 是 Gateway + IM 渠道章节，与 AutoTitle 无关。

**修复：** 将 `AutoTitle回填⤵️11.x自动标题` 改为 `AutoTitle已实现`。

### 2. readHistoryFile 错误处理对齐 Python

**问题：** Python `_read_history` JSON 解析失败时 log.Warn + 返回空列表，Go `readHistoryFile` 返回 error。差异导致 Go 侧调用方可能因可降级的 history 损坏而被 error 中断。

**修复：** `readHistoryFile` 中 `json.Unmarshal` 失败时，改为 log.Warn + 返回空切片，对齐 Python 行为。

修改文件：`internal/swarm/server/session/session_history.go`

```go
// 修改前
var records []map[string]any
if err := json.Unmarshal(data, &records); err != nil {
    return nil, err
}

// 修改后
var records []map[string]any
if err := json.Unmarshal(data, &records); err != nil {
    logger.Warn(logComponent).Err(err).Str("path", fpath).Msg("读取 history.json 失败，已忽略并重建")
    return []map[string]any{}, nil
}
```

### 3. TruncateHistoryRecords 截断前刷盘

**问题：** Python `truncate_history_records` 先 `_WRITE_QUEUE.join()` 等待异步队列刷盘再截断。Go 直接持锁截断，未等待异步写入队列。如果队列中有待写项，截断后异步 worker 可能将被截掉的记录写回。

**修复：** 在 `TruncateHistoryRecords` 开头调用 `FlushHistoryQueue()` 确保所有待写项落盘，再持锁截断。

修改文件：`internal/swarm/server/session/session_history.go`

```go
// 修改前
func TruncateHistoryRecords(sessionID string, cutIndex int) (TruncateResult, error) {
    sid := NormalizeSessionID(sessionID)
    fpath := historyFilePath(sid)
    historyFileMu.Lock()
    defer historyFileMu.Unlock()
    ...
}

// 修改后
func TruncateHistoryRecords(sessionID string, cutIndex int) (TruncateResult, error) {
    // 对齐 Python: _WRITE_QUEUE.join()，先等异步队列刷盘再截断
    FlushHistoryQueue()
    sid := NormalizeSessionID(sessionID)
    fpath := historyFilePath(sid)
    historyFileMu.Lock()
    defer historyFileMu.Unlock()
    ...
}
```

## 不修复项（附理由）

| 项 | 理由 |
|----|------|
| SerializeValue 缺少 date 类型 | Go 无 date 类型，time.Time 已统一覆盖 datetime.datetime 和 datetime.date |
