## 1. 背景与定位

团队会话中多个成员默认共享同一工作目录；当成员需要并行修改仓库文件时互相覆盖。Worktree 隔离用 `git worktree` 给每个成员独立的分支+目录，干完由 leader 收编。

**开关语义（非 UI 配置，运行时声明）**：
1. leader 的 `spawn_teammate` 工具可选 `isolation: "worktree"` 参数（LLM 决定，描述文案一比一复刻 tool_member.py:747-755）；
2. 团队模板 `blueprint.py:482 worktree: Optional[WorktreeConfig]`（Go blueprint 已有 `spec.Worktree` 字段，`CreateWorktreeManager` 已于 9.66a 落地——**已核实**）；
3. swarmflow `agent()` 调用 per-call isolation（⤴️ swarmflow 章节，本批不做，登记）。

git 存在性只是事后校验：只有成员请求 isolation 时才校验，非 git 仓库报错走 spawn 失败路径（manager.py:162 语义）。

**分层**（对齐 Python）：
- agentcore 通用工具箱 `harness/tools/worktree/`（怎么建/删/算 diff/锁）——Go 已有，本批 Task 0 对拍补缺；
- 团队所有权管理层 `agent_teams/worktree/`（谁/何时/复用还是新建/写 DB/散会清场）——Go 零实现，本批主体。
