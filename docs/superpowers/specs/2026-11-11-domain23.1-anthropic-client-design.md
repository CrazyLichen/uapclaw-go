### 2.3 登录模型澄清（不补 GetAvailableModels 的依据）

`get_available_models(config, session_id)` 不传 `session_id` 时第一行即返回 `get_default_models(config)`。`_evict_stale_llm_clients` 调用**不传** `session_id`（登录模型凭据按用户走 passthrough，不进 AgentServer 进程缓存，连接池里不可能有）。故：

- **不补** `GetAvailableModels`（该调用点是死路径）；
- 驱逐用 `GetDefaultModels`，但必须先补 agentos 分支（agentos 条目有完整凭据、会真实建连接，漏掉会误关）。

## 7. 回归风险

| 风险 | 缓解 |
|---|---|
| 删 Reloader 后用户改文件不生效 | spec 明示登记；Web 保存 / RPC 路径不变 |
| transport key 变细 → 连接复用率下降 | 池参数（100/20/60s）对齐 Python；对比改造前后同一配置的连接复用测试 |
| HandleHTTPError 文案变化 | `classifyTransientFailure` 现有用例全绿 + provider_code 契约测试 |
| GetDefaultModels 追加 agentos → 启动默认模型选择面变化 | `is_default=false` 不抢默认（Python 同）；启动选默认逻辑断言 |
| ReloadOptions 扩参传染 3 handler + adapter 链 | 全部调用点 grep 清单化；零值 Options 保持旧行为（空 scopes=全量） |
