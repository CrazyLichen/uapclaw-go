## 1. 在 Agent 会话中的流程位置（通俗）

23.9 是「跟 Agent 面对面视频通话」的旁路通道，不经过普通聊天输入框：

- **入口**：网关上另开的实时音视频 WebSocket 专线，由 `video-duplex` 应用插件装配；开关关闭时整条线不存在。
- **两层大脑**：
  1. **实时大脑（快嘴闲聊层）**：浏览器音频/画面帧 → 网关 WS 代理（qwen_omni_gateway）→ 上游实时多模态模型
     （vLLM Omni 或 JoyAI）。完全不经过 Agent/DeepAgent/会话门面，直接听看答，TTS 念出。
  2. **重型大脑（真干活层）**：背后就是普通聊天那套。实时模型通过 function calling 自主决定调用
     `jiuwen_delegate` / 任务管理五件套（感知机制），网关验货后转持久任务单；AgentTaskExecutor 经
     `agent_client.send_request` 发标准 `CHAT_SEND`（e2a 归一化，`channel_id="video_tool"`，
     `mode=agent`，`supports_user_interaction=True`）到 AgentServer——同一套会话体系、取消、交互问答恢复。
- **连接件（真正的增量）**：任务账本（持久化/并发 2/崩溃恢复/交互挂起）、ASR/TTS 适配器、
  搜索供给、遥测 JSONL 落盘、配置面板。
- **与 20.4 的区别**：20.4 是 process CLI 进程的双工输入通道，与本节无关。

## 2. 提示词拼接与工具感知机制（设计依据）

- **拼接（发请求前、网关侧烤进查询文本，不碰 Agent 记忆系统）**：
  - 攒上下文（task_adapter.py:120-146）：同会话已完成任务，普通任务取最近 6 条，`independent` 只取
    `depends_on`；revision 追加「上一版结果」；每条压缩为 `{question, result, files}`，结果上限
    `_MAX_DELEGATION_RESULT_CHARS=2400`。
  - `build_execution_prompt`（tasks/prompts.py:78-102）：任务要求 + 实时旁证 query + 视觉线索 +
    历史委派记录 + 「直接干完不汇报过程」+ 语言规则 + brief 标记协议（`_brief_markers(nonce)`，
    `_MAX_REALTIME_BRIEF_CHARS=180`）。
  - 画面帧走 `media_items` + `normalize_media_attachments`（23.8 附件归一化链，复用）。
- **感知**：配置 RPC 下发 `tools` 字段（qwen_omni_tools.py:38-121）——`jiuwen_delegate` +
  `jiuwen_task_query/cancel/modify/reorder/answer` 六个工具；实时模型 function calling 自主决策；
  网关 `parse_qwen_omni_tool_call` 验货（白名单 `_TASK_TOOLS` + delegate/research 旧名、call_id ≤200、
  arguments JSON 合法）。JoyAI 非标准 function calling：`JOYAI_TASK_INSTRUCTIONS` 教模型在
  `</delegation>` 后输出 JSON，同一解析器验货。
- **闭环**：任务完成后从答案尾部 brief 标记提取口头回执喂回实时模型播报；追问进度走 task_query 回执转述。

## 4. 四批划分

- **批 1 装配与配置**（~360 行）：extension.go + settings.go + connection_check.go。
  完成后配置面板与开关可用，其余 RPC 返回明确「未启用」错误。
- **批 2 ASR/TTS + 核心执行器**（~1670 行）：video_voice.go（端点配置读法 tts_model_config/asr_model_config
  环境变量优先级一比一、音频 MIME 白名单 `is_allowed_audio_data_url`、语气词过滤 `_ASR_FILLER_ONLY`、
  `clean_model_text` `<think>` 清洗）+ video_search.go（`execute_core_agent`：prompt 组装、media_items
  附件归一化、CHAT_SEND/流式事件解析 chat.delta/final/ask_user_question/chat.error、进度时间线
  `core_agent_progress`、brief 提取、`present_core_agent_result` 结果分型）。
- **批 3 实时编排 + 双 provider**（~2660 行）：video_live.go（RPC 编排、遥测 JSONL `_append_jsonl`
  + 写锁、`_REALTIME_TELEMETRY_EVENT` 正则与字段白名单、会话历史写入）+ qwen_omni_gateway.go（WS 代理
  `QWEN_OMNI_PROXY_PATH`）+ qwen_omni_tools.go + joyai_provider.go（477 行，帧问答/语音通道/响应语言归一）。
- **批 4 持久任务管理**（~2050 行）：tasks/ 全套（TaskService：并发 2、文件锁租约、启动恢复 running/
  cancelling/waiting_user/带 resume_answer 的 queued、交互挂起 InteractionPending/ExecutionUncertain
  双异常语义、通知超时降级）+ task_adapter.go（AgentTaskExecutor.run 上下文攒取、cancel 需 CHAT_CANCEL
  确认、answer 回填、`wait_settled` 轮询 execution_settled）+ bridge.go（网关绑定）。
