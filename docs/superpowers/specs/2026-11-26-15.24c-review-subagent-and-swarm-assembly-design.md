## 1. 流程位置与作用（背景）

15.24c 是把 15.24a（rail 检测新版）与 15.24b（工具/服务面）**接线成可运行系统**的装配批：

```
信号/审查触发（15.24a）
  → 15.24c 注册层：
      rail.init() → _register_evolution_tools（六主工具）
                 → _register_evolution_review_agent（审查子 agent 注入 deep_config.subagents）
                 → _prepare_evolution_review_scope（审查触发时创建 scope + 轨迹捕获解析）
  → 审查子 agent：五只读工具读证据 → submit_evolution_review 提交 proposals
  → 15.24c swarm 装配层：leader [EvolutionInterruptRail, SwarmTeamSkillEvolutionRail] 审批栈
      / teammate SwarmMemberSkillEvolutionRail（auto_save 直落）
      / init 自注册 TeamManager（live-rail 簿记 / 热重载 context / watcher 补建）
  → 15.24d：端到端 + host 层推送链（本批不做）
```

关键事实澄清（实施期不再疑问）：EvolutionInterruptRail **不是 team 专属**，挂执行
`evolve/simplify_skill_experiences` 的 DeepAgent；它是审批的消费者/决策者
（preflight→渲染审批消息→InterruptRequest→resume 裁决→落盘在 submission apply），
adapter 缓存它仅用于 configure/unconfigure 生命周期。
