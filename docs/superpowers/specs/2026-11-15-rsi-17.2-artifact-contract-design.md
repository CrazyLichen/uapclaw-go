# RSI 17.2 artifact 优化服务流（纯契约层）设计

日期：2026-11-15
状态：已批准（用户拍板：范围方案 A + 协议嵌入方案 ① + 子包延后方案 Ⅱ）

## 1. 背景与范围

RSI 领域 17 的 17.2 节对应 Python `openjiuwen/rsi/artifact_rsi/` 的**契约层**：统一的
Provider 服务协议、Provider 侧工单结构、公开请求校验与工单构建。17.2 本身不含任何
优化引擎——程序引擎（PUCT）在 17.3，论文流水线在 17.5/17.6，AgentServer 服务端在 17.9。

### 1.1 范围决策（已拍板）

| 决策点 | 结论 |
|---|---|
| 共用地基归属 | **方案 A**：`state.py/tree.py/bundle.py/restore.py/scorecard.py` 等约 2600 行共用地基**全部后移到 17.3**；17.2 只做纯契约（约 400 行） |
| 协议重复声明 | **方案 ①**：Go 用接口嵌入。`ProgramArtifactProvider`/`PaperArtifactProvider` 嵌入 `ArtifactProvider`，不逐字重复 9 个方法签名（Python 的重复是"让各模块可见完整实现面"的文档性质声明，嵌入等价且更短；子协议本身按方案 Ⅱ 延后） |
| 子包创建时机 | **方案 Ⅱ**：17.2 只建 `artifact_rsi/` 包（provider.go + request.go + doc.go）；`program_opt/`、`paper_opt/` 子包随 17.3/17.5 创建 |

## 4. 接口设计

```go
// ArtifactProvider 统一提供方契约，由 AgentServer 路由消费。
// 实现方拥有任务执行与 run_dir 下的持久化；不得自建事件队列或直接调
// WebSocket/Web 推送；回调须在对应快照持久化之后触发。
type ArtifactProvider interface {
    // ArtifactType 提供方处理的 artifact 种类（program/paper）。
    ArtifactType() ArtifactType
    // ValidateInput 启动任务前校验提供方专属输入，不创建任务快照。
    ValidateInput(artifactPath *string) *ArtifactValidationResult
    // Run 启动新任务并返回当前或终态结果；先发 running，再发节点/进度事件，终态最后。
    Run(ctx context.Context, req *ArtifactEngineRequest, onEvent OnEvent) (*EngineResult, error)
    // Pause 在安全检查点暂停；不支持的场景返回相应结果。
    Pause(ctx context.Context, taskID string, onEvent OnEvent) (*EngineResult, error)
    // Resume 从检查点恢复同一任务，不新建根节点。
    Resume(ctx context.Context, req *ArtifactEngineRequest, onEvent OnEvent) (*EngineResult, error)
    // ReadState 读取最新持久化状态（重启/丢事件后的恢复查询路径），不发事件不执行。
    ReadState(taskID string) *EngineState
    // ReadReport 读取当前/最终报告与完整 artifact 索引（含未采纳节点的可下载产物）。
    ReadReport(taskID string) *EngineReport
    // GetTree 读取完整持久化树（含被拒绝分支），不止最优链。
    GetTree(taskID string) *TreeResponse
    // LocateArtifact 定位任务或节点 artifact；artifactID 为 nil 表示任务最终产物。
    // 返回的是提供方本地路径，归属校验与 URL 投影由 AgentServer 负责；查找必须限定 taskID。
    LocateArtifact(taskID string, artifactID *ArtifactID) *ArtifactRef
    // Terminate 永久停止任务并返回 terminated 状态；终止后不可恢复。
    Terminate(ctx context.Context, taskID string, onEvent OnEvent) (*EngineResult, error)
}
```

### 4.1 契约语义（doc.go 记录，由 17.3/17.5 实现兑现）

- **artifact_type 字面量约束**：program 实现恒返回 program，paper 恒返回 paper
  （Python 由静态检查器约束；Go 由实现方保证 + AgentServer 运行时显式路由）。
- **事件纪律**：先持久化（状态/节点/报告/artifact）再发对应事件；`NodeStageEvent`
  只更新既有节点的阶段描述，不新建树节点。
- **Paper 不支持 Resume**：返回 `SCENARIO_NOT_SUPPORTED` 错误码且不改变任务状态
  （Python `paper_opt/provider.py` 明文）。
- **model 已解析**：工单中的 Model 是 AgentServer 初始化好的实例；实现方可调用其
  Invoke/Stream，但不得从任务配置解析模型 ID 或构造客户端。

## 5. 工单与校验

### 5.1 ArtifactEngineRequest

七字段：task_id / run_dir / artifact_path / model / max_iterations /
optimization_instruction / web_proxy。Go 映射：

- `artifactPath`/`optimizationInstruction`/`webProxy` → `*string`（Python `str | None`）
- `model` → `llm.Model`（已初始化实例，非 ID）
- 不可变结构：Python `frozen dataclass` → Go 全字段私有 + 构造函数/访问器
  （17.1 既有惯例：不可变契约不带 json tag）

### 5.2 ValidateArtifactTaskRequest

逐条复刻 Python 13 条校验规则（错误码逐字保留）：

1. `ARTIFACT_SCENARIO_REQUIRED` — scenario 必须为 "artifact"
2. `ARTIFACT_TYPE_REQUIRED` — artifact_type 必须为 "program"/"paper"
3. `WEB_PROXY_UNSUPPORTED` — web_proxy 仅 paper 支持
4. `NAME_REQUIRED` — name 非空（strip 后）
5. `MODEL_REFS_INVALID` — model_refs 必须为映射
6. `OPTIMIZER_MODEL_REQUIRED` — model_refs 必须含非空 "optimizer"
7. `MAX_ITERATIONS_INVALID` — 必须为整数（bool 不算）且 ≥1
8. `PROGRAM_ARTIFACT_PATH_REQUIRED` — program 必须给非空 artifact_path
9. `PROGRAM_INSTRUCTION_UNSUPPORTED` — program 拒收 optimization_instruction
10. `PAPER_INPUT_REQUIRED` — paper 须给 artifact_path 或 optimization_instruction 二者之一
11. `DATASET_FILE_UNSUPPORTED` — dataset_file 不支持
12. `SEARCH_WIDTH_UNSUPPORTED` — search_width 不支持

返回 `*ArtifactValidationResult`（valid + errors 列表，元素为 {code, message}）。

### 5.3 BuildRequest

- 校验失败 → 返回聚合 error（对齐 Python `raise ValueError(errors)`）；
  envelope 与 config 的 artifact_type 不匹配 → `ARTIFACT_TYPE_MISMATCH`；
  model 为 nil → `OPTIMIZER_MODEL_INSTANCE_REQUIRED`。
- `optimization_instruction` / `web_proxy` **仅 paper 保留**（program 置 nil）；
  web_proxy 取 `str(getattr(config, "web_proxy", "") or "").strip() or None` 语义
  （空串/纯空白 → nil）。
- 不读文件、不启动任何提供方工作（对齐 Python docstring 承诺）。

## 6. 错误处理

- Python `raise ValueError([error dicts])` → Go 单一 `error` 类型
  `ArtifactRequestError`（内含 `[]ArtifactError`），`Error()` 输出首条 code+message
  供日志使用，完整列表经 `Errors()` 暴露。
- 错误码字符串常量逐字对齐 Python（含下划线风格）。

## 7. 测试

- 12 条校验规则命中/未命中矩阵（含 bool-as-int 边界、strip 边界、paper 二选一边界）。
- BuildRequest 全拒绝路径（含 TYPE_MISMATCH / MODEL_INSTANCE_REQUIRED）与
  paper-only 字段置 nil 分支。
- fake 实现满足 `ArtifactProvider` 接口的编译期断言。
- 目标覆盖率 ≥85%；契约层无跨子系统行为，不涉集成测试。

## 8. 已知偏差

- Python 子协议（program/paper）重复 9 方法签名的声明 → Go 以接口嵌入 + doc.go
  记录替代（用户拍板方案 ①），子包文件延后到 17.3/17.5（方案 Ⅱ）。
- `runtime_checkable` 无 Go 等价物（Python 运行时 isinstance 检查），无消费方，
  不实现。
- Python async 方法 → Go `context.Context` 首参，属平台常规转换。
