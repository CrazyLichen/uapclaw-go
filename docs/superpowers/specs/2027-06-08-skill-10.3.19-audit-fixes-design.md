# 10.3.19-20 审查修复设计

## 背景

对 10.3.19-20（技能管理）章节进行 Go vs Python 对齐审查，发现 4 个需要修复的问题。

## 修复清单

### 修复 1：SkillManager 补充 4 个 enabled/disabled 导出方法 + DeepAdapter 调用点注释

Python 的 `SkillManager` 暴露了 4 个独立方法（`get_skill_enabled`/`set_skill_enabled`/`list_disabled_skills`/`list_execution_disabled_skills`），Go 的 `state_utils.go` 已有对应纯函数，但 `SkillManager` 上缺少方法级暴露。Python 中 DeepAdapter 通过 `self._skill_manager.list_execution_disabled_skills()` 调用。

**改动文件：**

1. `internal/swarm/server/runtime/skill/skill_manager.go` — 在导出函数区补充 4 个方法：
   - `func (sm *SkillManager) GetSkillEnabled(name string) bool` → 委托 `GetSkillEnabled(sm.state, name)`
   - `func (sm *SkillManager) SetSkillEnabled(name string, enabled bool)` → 委托 `SetSkillEnabled(sm.state, name, enabled)`
   - `func (sm *SkillManager) ListDisabledSkills() []string` → 委托 `ListDisabledSkills(sm.state)`
   - `func (sm *SkillManager) ListExecutionDisabledSkills() []string` → 委托 `ListExecutionDisabledSkills(sm.state)`

2. `internal/swarm/server/adapter/deep_adapter_rails.go` — 在 `buildSkillRail()` 和 `buildSkillEvolutionRail()` 中补充调用点注释：
   ```go
   // ⤵️ 10.6.3-10: 实现 SkillUseRail
   // 对齐 Python: disabled_skills=self._skill_manager.list_execution_disabled_skills()
   // 待 Rail 类型实现后: d.skillManager.ListExecutionDisabledSkills()
   return nil
   ```

### 修复 2：summarizeSearchPayload sample.summary fallback

Python：`first.get("skill_description") or first.get("summary") or ""`
Go：仅 `toString(first["skill_description"])`，缺少 `summary` fallback。

**改动文件：** `internal/swarm/agents/harness/tools/skill_toolkit.go`

改为：
```go
"summary": func() string {
    v := toString(first["skill_description"])
    if v == "" { v = toString(first["summary"]) }
    return v
}(),
```

### 修复 3：步骤9日志补充工具名列表

Python 记录 `skill_tool_names` 列表，Go 仅记录 "SkillToolkit 已注册"。按日志同步规则（规则3.1），Python 日志中的变量必须在 Go 日志中以结构化字段等价体现。

**改动文件：** `internal/swarm/server/adapter/deep_adapter_tools.go`

在 SkillToolkit 注册循环中收集工具名：
```go
var skillToolNames []string
for _, t := range skillToolkit.GetTools() {
    existing, _ := runner.GetResourceMgr().GetTool([]string{t.Card().ID})
    if len(existing) == 0 {
        _ = runner.GetResourceMgr().AddTool(t)
    }
    toolCards = append(toolCards, t.Card())
    skillToolNames = append(skillToolNames, t.Card().ID)
}
logger.Info(logComponent).Strs("tools", skillToolNames).Msg("getToolCards: SkillToolkit 已注册")
```
