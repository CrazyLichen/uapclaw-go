## 1. 流程位置与作用

### Agent 会话中的位置（非 E2A 链路）

```
TUI 客户端 (11.15，未实现)
   │  WS 请求 method="memory.list/edit/status/toggle/open"
   ▼
Gateway WebSocket（app_gateway.py 路由）
   │  route.local_handlers[method] 命中        ← 本地 handler，不进 E2A、不进 AgentServer
   ▼
tui_connect.py 注册的 5 个 wrapper（_memory_list 等，L1843-1907）
   │  workspace = get_agent_workspace_dir()
   │  project_dir = params.project_dir / trusted_dirs[0] / cwd 三级回退
   ▼
memory_rpc.py 5 个 handler（本章实现对象）
   ├→ swarm memory 包（get_memory_manager / is_memory_enabled / is_proactive_memory）
   ├→ external_memory_config（get_memory_engine / is_external_memory_allowed / get_external_memory_config）
   ├→ rails/project_memory（discover_and_load_memory_files / clear_project_memory_cache / get_large_memory_files）
   └→ common/config（get_config + YAML 写回 update_memory_forbidden_enabled_in_config）
   ▼
channel.send_response(ws, req_id, payload)  → 原路返回 TUI
```

作用：**TUI 记忆管理面板的后端方法集**（与同批注册的 config.*/models.list/session.*/hooks.list 同属 Gateway 进程内 RPC）。

| RPC | 作用 | 核心逻辑 |
|-----|------|---------|
| memory.list | 列出所有记忆文件 | project_memory 发现 + workspace/memory 自动记忆 + coding_memory 三路合并去重，每项 path/relative_path/kind/size/mtime/lines |
| memory.edit | 编辑记忆文件 | 路径白名单校验 → 存在则读前 20 行预览，不存在则 mkdir+touch 创建 |
| memory.status | 记忆系统总状态 | 基本配置块 + detailed 六块统计（索引/项目记忆/大文件/coding/auto/external） |
| memory.toggle | 开关切换并写回 config.yaml | 3 个 key：memory_forbidden_enabled（全局）/memory_enabled（mode 级）/memory_proactive（mode 级） |
| memory.open | 返回各记忆目录路径 | 纯路径计算，无 IO |

## 4. 函数清单与签名

## 5. 逐 handler 实现要点

### HandleMemoryList

- `include_project` 默认 true；`additional_directories`、`project_dir` 从 params 取
- 三路合并去重（去重键 path）：①project_memory 发现（DiscoverAndLoadMemoryFiles(ctx, discoverWorkspace, discoverWorkspace, additionalDirs)，discoverWorkspace=projectDir 或 workspace；行数用 strings.Count(f.Content, "\n")+1）②workspace/memory 扫描（scanMDFiles，kind=auto）③coding_memory 扫描（kind=coding）
- Go 签名差异适配：DiscoverAndLoadMemoryFiles 返回 ([]LoadedMemoryFile, error)，error 按空列表处理（对齐 Python 不抛）
- 返回 `{"files": files, "mode": mode}`

### HandleMemoryEdit

- validateEditPath 失败 → 返回 `{"path": raw, "exists": false, "content_preview": "", "kind": "unknown", "editable": false}`
- 成功且文件存在 → 读前 20 行 join，超 20 行追加 "\n... (truncated)"
- 成功且不存在 → MkdirAll(parent) + touch 创建
- 返回 `{"path": resolved, "exists": exists, "content_preview": ..., "kind": classify, "editable": true}`
- 路径归一化对齐：rawPath 反斜杠替换 "/"、ExpandUser、abs 相对 workspace 解析、project_dir 解析且白名单内优先

### HandleMemoryStatus

- 基本块：current_mode/storage_mode（config.memory.mode，缺省 "local"）/engine（GetMemoryEngine）/enabled/proactive（code 模式特判：`strings.HasPrefix(mode, "code")` → enabled=true, proactive=false，对齐 _is_code_mode）/forbidden_enabled
- detailed 分支六块（对齐 Python L310-387 顺序）：
  1. index：GetMemoryManager(ctx, "default", workspace, nil).Status() 提取 available/provider/model/files_count/chunks_count/dirty/fts/vector/cache
  2. ClearProjectMemoryCache(discoverWorkspace) + DiscoverAndLoadMemoryFiles 统计 → project_memory{files_count/total_chars/max_chars:60000/threshold:40000/(project_dir)}
  3. large_files：GetLargeMemoryFiles(projectFiles)
  4. coding_memory：scanMDFiles + 逐文件读字符统计
  5. auto_memory：workspace/memory 同上
  6. external_memory：engine ∈ {external, both} 时 {provider, enabled: IsExternalMemoryAllowed}
- 日志对齐（规则 3）：detailed 路径的 logger.info → logger.Info，字段 workspace/project_dir/discover_workspace/files/large_files

### HandleMemoryToggle

- key=memory_forbidden_enabled → 全局写回 + needs_restart:true + mode_affected:"global"
- key=memory_enabled → updateModeMemoryConfig(mode, "enabled", !old)，old=IsMemoryEnabled(mode, cfg)
- key=memory_proactive → updateModeMemoryConfig(mode, "is_proactive", !old)，old=IsProactiveMemory(mode, cfg)
- 未知 key → `{"key": key, "old_value": false, "new_value": false, "mode_affected": "", "needs_restart": false}`（对齐 Python 兜底）
- 写回失败（D6）：log.Error + new_value 置 old_value（如实上报未变更）

### HandleMemoryOpen

- 返回 `{"memory_dir": workspace/memory, "project_memory_dir": workspace, (project_dir), (coding_memory_dir 仅 isdir 时)}`
- 纯路径计算无 IO

## 6. 错误处理与日志

| 失败点 | 行为 |
|--------|------|
| validateEditPath 白名单外 | editable:false 结果（非错误，业务语义） |
| edit 读文件失败（OSError） | content_preview 留空，继续返回（对齐 Python try/except pass） |
| edit MkdirAll/touch 失败 | 日志 Error；结果仍返回（path 已解析，editable:true，对齐 Python 异常上抛由 wrapper 兜底——Go 侧 log 后返回） |
| status GetMemoryManager 失败 | index 块省略（对齐 Python manager None 时跳过） |
| toggle 写回失败 | log.Error + new_value=old_value（D6） |
| DiscoverAndLoadMemoryFiles error | 按空列表处理 |

日志组件：`ComponentAgentServer`（包内既有约定，对齐 memory 包 forbidden.go）。逐条对照 Python logger 调用（仅 status detailed 一处 logger.info）。

## 8. 实现注记（计划阶段展开）

- **config 路径注入**：Python `_CONFIG_YAML_PATH` 模块级常量 + monkeypatch 测试。Go 等价：包级 `var configPathProvider = func() string { ... }` 或复用 config.New("") 默认路径逻辑 + 测试用 t.Setenv 重定向数据目录（UAPCLAW_DATA_DIR，AgentWorkspaceDir 同款机制）。计划阶段定夺注入方式
- **touch 实现**：os.OpenFile(path, O_CREATE|O_WRONLY, 0644) + Close
- **Windows 分支**：isInAllowedDirs/validateEditPath/relativePath 三处 runtime.GOOS 判定。Windows 分支在 Linux 不可测，行数少；不抽接口（YAGNI），覆盖率由非 Windows 路径保证
- **os.scandir 排序**：Go 用 os.ReadDir（天然按 name 排序返回）
- **status 内 storage_mode**：cfg 为 nil 或非 dict → "local"（对齐 Python isinstance 判断）
