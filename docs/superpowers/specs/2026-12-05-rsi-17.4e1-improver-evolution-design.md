## 1. 背景与流程位置

RSI 演进闭环中，17.4d 单 harness 迭代循环（已落地）每轮产出实验记录本
（Candidate Feedback Ledger v1）：候选身份（确定性 fingerprint）、预测排名
（rank_frozen 冻结戳）、实测成绩（target_gain = candidate_target_score −
source_target_score，量纲由评估协议决定）、激活探针三态、回归计数、三个汇总
指标（best_of_k_gain / top_m_gain / selection_regret）。

17.4e1 是该闭环的**复盘与评审环节，纯计算零 LLM、零跨节依赖**（不吃 17.6
评估桩、不吃 17.7 取消桩、不吃 e2 schema）：

- `feedback_analysis`（复盘员）：读 1..N 份 ledger/cohort，做确定性统计，
  回答"哪些坏毛病在 ≥ min_support_cohorts 轮中反复出现"，输出稳定模式清单，
  每条附 recommended_policy_change（喂给 Improver 的改规则建议）。
- `meta_validation`（评审员）：对基线 Improver `I_t` 与候选 Improver 在
  成对 meta_test checkpoint 上的成绩做配对宏平均比较，产出晋升报告；
  任何配对不合法直接判 rejected，绝不给部分统计。

与同节已落地件的关系：`policy.py` 已随 17.4d 前置切片落地为
`improver_evolution/policy.go`（FrozenDict，D-d1），本节**保留不重做**，
doc.go 仅补充新文件条目。

### 3.3 MetaValidationThresholds 不可变设计

- 结构体字段非导出 + `NewMetaValidationThresholds(...)` / `DefaultMetaValidationThresholds()` 构造函数在构造时执行 `__post_init__` 的全部校验（min_unseen_checkpoints ≥1 且非 bool；其余 6 个容差字段有限非负数），非法即 error。
- 字段访问器 `MinUnseenCheckpoints()` 等逐字段提供（报告 `thresholds` 输出键用 Python `asdict` 字段名 snake_case）。
- 冻结语义：Go 无 frozen，构造后无非导出字段写路径即达成；不引入 setter。

## 4. 确定性细节（方案①）

### 4.1 training_ledger_digest

Python：`json.dumps(ordered, ensure_ascii=False, separators=(",", ":"), sort_keys=True)` → utf-8 → sha256 → `f"sha256:{hexdigest}"`。

Go 等价实现要点：

1. `ordered`：cohorts 按 `cohort.cohort_id` 排序（与 Python `sorted(key=...)` 一致）。
2. 键排序 + 紧凑分隔符：`encoding/json.Marshal` 天然满足（map 键排序、无空格分隔符）。
3. **float 序列化差异点（唯一已知风险）**：Python json 对 float 用 `repr`（如 `0.3333333333333333`、整数分值输出 `1.0`）；Go 输出短格式（`0.3333333333333333` 一致，但 `1.0` 会输出 `1`）。处置：ledger 数值多为计算产物，黄金样例阶段逐字段比对；若出现不一致，digest 序列化走自定义 float 编码路径（仅 digest 用，输出报告仍用 `map[string]any` 直序列化），并在偏差区登记 D-e1-3。
4. ensure_ascii=False 与 Go UTF-8 原文输出天然一致（中文/Unicode 不转义）。

### 4.2 其他格式语义

- `_rounded(x) = round(float(x), 12)`：实现 `roundTo12(x float64)`（`math.Round(x*1e12)/1e12` 的等价物，注意负零与 1e12 边界；黄金样例实证）。
- `_counter_dict`：Counter 输出为键排序后的 map（Python `{key: counter[key] for key in sorted(counter)}`）。
- `_rate`：分母 0 → Python `None` → Go `nil`（map 值为 nil）。
- 组合枚举 `combinations(candidates, 2)`：双层循环复刻，保持 (first, second) 顺序语义。
- `Counter`、`defaultdict` 语义用 map + 显式零值初始化复刻。
- `itertools.combinations`、`hashlib`、`math.isfinite` 对应 Go 标准库；YAML 解析用项目既有 yaml 库（与 Python `yaml.safe_load` 对齐：非 .json 后缀按 YAML 解析，`.json` 后缀按 JSON 解析，后缀比较 casefold）。
