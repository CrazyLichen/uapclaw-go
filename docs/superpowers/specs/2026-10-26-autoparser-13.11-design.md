## 1. 背景与定位

Parser 层收口组装节：把 13.12-13.16 五节具体解析器 + 13.16 带出的 registry 骨架，组装成对外一站式入口。三件套关系：AutoParser（顶层：URL 或文件二选）→ AutoLinkParser（URL 模式路由，先匹配先赢）/ AutoFileParser（扩展名路由 + metadata 增强）。

Agent 会话流程位置（**不在会话主链路**，仅知识库构建期被调用）：

```
【入库管线】文件/链接 → AutoParser（★13.11 顶层路由）
  → Chunker（13.5-13.9 ✅）→ ComputeChunkEmbeddings（13.4 ✅）
  → Chroma/Milvus Indexer.BuildIndex（13.2/13.3 ✅）
【查询管线】KnowledgeRetrievalComp（8.25 ☐）→ retrieve → rerank → 注入 prompt
  （查询路径不经过 Parser）
```

Python 侧运行时消费方为 `KnowledgeBase.parse_files/parse_urls` 模板方法（parser 构造参数注入；`knowledge_retrieval_comp.py` 生产代码创建 SimpleKnowledgeBase 时 parser 传 None——三件套无硬编码消费点，属公开 API 收口面，KB 层装配留 8.25）。

}

//   1. os.Stat 不存在 → 155103 WithMsg "File %s does not exist"（%s 非逐字符 repr 对齐 Python f-string）

### 4.2 auto_link_parser.go

```go
// ── 结构体 ──
// docMatcher 路由匹配器（Python Union[re.Pattern, Callable] 对应物，非导出）。
type docMatcher interface {
    // MatchDoc 匹配文档源。
    MatchDoc(doc string) bool
}

// regexpMatcher 正则形态：MatchDoc = re.MatchString(strings.TrimSpace(doc))
// （对齐 Python pattern.match(doc.strip())）。
type regexpMatcher struct{ re *regexp.Regexp }

// funcMatcher 可调用形态：MatchDoc = fn(doc)（原样传入不 strip，对齐 Python callable 直调）。
type funcMatcher struct{ fn func(string) bool }

// linkRoute 单条路由。
type linkRoute struct {
    // matcher 匹配器
    matcher docMatcher
    // parser 命中后委托的解析器
    parser Parser
}

// AutoLinkParser URL 模式路由解析器（先匹配先赢）。
type AutoLinkParser struct {
    *BaseParser
    // routes 路由表
    routes []linkRoute
}

// NewRegexpMatcher/NewFuncMatcher 导出包装：外部注入自定义路由入口（决策 2）。

// NewAutoLinkParser 构造。零参 → defaultRoutes() 两条（微信优先）；
// 有参 → 字面使用调用方路由表（对齐 Python routes=None 默认语义）。
func NewAutoLinkParser(routes ...linkRoute) (*AutoLinkParser, error)

// defaultRoutes 默认路由（每次构造新解析器实例，对齐 Python _default_routes()）：
//   (NewRegexpMatcher(wechatMPURLPattern), NewWeChatArticleParser()),
//   (NewRegexpMatcher(httpURLPattern), NewWebPageParserWithDefaults()),
// 两构造 error 聚合上抛。

// Parse 覆写——Python AutoLinkParser.parse：
//   遍历 routes 首个 MatchDoc 命中 → Debug 日志 "AutoLinkParser delegating to %s"
//   → parser.Parse(ctx, doc, 剔除LLMClient后的opts...)（决策 3：显式剔除机制——
//     构造新 ParseOptions 保留 DocID/Extra/Timeout/UserAgent/Verify/HTTPClient 置空 LLMClient）
//   无命中 → 空切片
// Supports 覆写：doc 非空 && httpURLPattern.MatchString(TrimSpace(doc)) && 任一路由 MatchDoc 命中

// matchDoc 包内辅助：dispatch 双形态（Python _match_doc 对应物）。
func matchDoc(m docMatcher, doc string) bool
```

### 4.3 auto_parser.go

```go
// AutoParser 顶层路由解析器：URL → AutoLinkParser，否则 → AutoFileParser。
type AutoParser struct {
    *BaseParser
    // linkParser URL 路由解析器
    linkParser Parser
    // fileParser 文件路由解析器
    fileParser Parser
}

// NewAutoParser 构造。link/file 为 nil 时各自默认构造（对齐 Python None 默认参数）。
func NewAutoParser(linkParser, fileParser Parser) (*AutoParser, error)

// Parse 覆写——Python AutoParser.parse（含 fall-through 控制流字面保留）：
//   isLikelyURL(doc)（doc 非空 && httpURLPattern.MatchString(TrimSpace(doc))）
//   if isLikelyURL && linkParser.Supports(doc) → Debug "AutoParser delegating to link parser"
//       → linkParser.Parse(ctx, doc, opts...) 全量透传（含 LLMClient——对齐 Python 传递）
//   if fileParser.Supports(doc) → Debug "AutoParser delegating to file parser"
//       → fileParser.Parse(ctx, doc, opts...) 全量透传
//   都不中 → 空切片
//   （URL-but-unsupported fall-through 到 file 分支——Python 真实控制流）
// Supports 覆写：isLikelyURL → linkParser.Supports(doc)；否则 fileParser.Supports(doc)

// isLikelyURL 包内辅助（Python _is_likely_url 对应物，AutoParser 复用 13.14 httpURLPattern）。
func isLikelyURL(doc string) bool
```

### 4.4 Python→Go 语义对齐表

| Python | Go | 边界语义 |
|---|---|---|
| `parse` 工厂取实例 | `factory()` 每次新实例 | registry 工厂语义 |
| `parser.parse(doc, doc_id, llm_client=..., **kwargs)` | `parser.Parse(ctx, doc, opts...)` | 全量透传（AutoFileParser/AutoParser 两处） |
| `parser.parse(doc, doc_id=doc_id, **kwargs)`（无 llm_client） | 剔除 LLMClient 的新 opts | 决策 3 字面丢弃 |
| `metadata.update` 四键 | Metadata 逐键赋值（nil 先建） | 覆盖语义 + 决策 6 防御 |
| `kwargs.get("file_name", basename)` | Extra 断言 + Base 兜底 | 决策 5 |
| `os.path.basename` | `filepath.Base` | Unix 同语义；win 分隔符差异归档（测试全 Linux） |
| `re.Pattern.match(doc.strip())` | `re.MatchString(TrimSpace(doc))` | strip 语义对齐 |
| callable 直调 `pattern_or_callable(doc)` | `fn(doc)` 不 strip | Python 原样传入字面对齐 |
| `list(_PARSER_REGISTRY.keys())` 插入序 | sort + Join ", " | 决策 4（chunker 先例） |
| `register_new_parser` last-wins | RegisterNewParser 无条件覆盖 | 与 first-wins 并存 |
| `except ImportError` warn | 无对应物 | 决策 8：Go 编译期不可能 |
