## §2 薄壳（一比一要点）

- `ReActAgentCompConfig` 嵌入 `saconfig.ReActAgentConfig`（6.3 已迁），零新字段
  （对齐 Python 纯继承 + `pass`）。
- 构造期 `NewReActAgent(AgentCard{id:"react_agent_workflow_executable",
  name:"ReAct Agent Workflow Executable", description:"ReAct agent for workflow execution"})`
  + `Configure(config)`。Python lazy import 是破环注释（react_agent→ability_manager→
  workflow/__init__ 循环），Go 无此循环直接 import，注释保留说明。
- `invoke`：委托 `ReActAgent.Invoke(inputs, session)`；异常吞掉转
  `{"output": "Error in ReAct execution: <err>", "result_type": "error"}`（文案逐字）。
- `stream`：
  1. `session.CreateAgentSession(session.GetSessionID(), card)` 新建 agent session
     （注意：Python 传 workflow session 的 session_id，非自造）；
  2. 逐块消费 `ReActAgent.stream(inputs, agent_session)`；
  3. OutputSchema 解包：`chunk.Type == "llm_output"` 且 payload 含 `content` 键 →
     重包装 `{"output": payload["content"]}`；其余 OutputSchema → yield `chunk.Payload`
     （剥信封不改键）；非 OutputSchema → 原样 yield；
  4. 异常 yield `{"type": "error", "payload": {"output": "Error in ReAct streaming: <err>",
     "result_type": "error"}}`（结构与 invoke 分支不同：外层带 type 键，逐字对齐）；
  5. 上游死注释（shared_state 同步示例段）照搬保留。
- 组合面：`ReActAgentComp` 实现既有 ComponentComposable 槽位模式（8.17/8.18 先例：
  executable 懒加载共享 + `AddComponent(graph, nodeID, waitForAll)` → `graph.AddNode`）。
- 键位兼容性已核实：Go ReActAgent 流块 `llm_output` payload 用 `content`
  （react_model_call.go:519）、`answer` payload 用 `output`（react_invoke.go:290），
  与 Python `_inner_stream` 逐处一致，薄壳不改 ReActAgent 本身。

## §4 五接缝回填（react_invoke.go）
