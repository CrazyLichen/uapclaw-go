## 2. 架构（方案 α）

### 2.1 数据流

```
浏览器 ──RPC──▶ Gateway(app_web_handlers.go，转发形)
   ──E2A(ReqMethod 白名单)──▶ AgentServer ConfigAdapter（方法分派表）
      ├─ 读：control/config_service.GetPanel()  ← 现场读 config.yaml + .env 文件
      ├─ 写：control/configpanel/  → 写 .env + yaml（crypto 加密敏感键）
      └─ 写后：ReloadRuntimeAfterConfigSave → agent 重载(AGENT_RELOAD_CONFIG)
```

单机部署共享磁盘目录 → 一致性由「每次读都重读文件」保证。Python 原注释记载的跨进程时序 bug（os.environ 过期导致设置页显示旧模型）即本设计读文件不读内存的原因。

## 3. 模型选择的汇合语义（设计约束，不新实现）

选择与模型实体的关系（23.4d 已建，本批仅接 zen 源）：

- 解析优先级（`ModelSelectionResolver.choose` 五级）：显式（chat.send 参数 model_selection / 旧格式 `model:` 前缀）> 会话保存选择（metadata，落 store 不写 yaml）> spec 选择 > 默认模型组（catalog `is_default`）> 旧名匹配 > 默认模型 > 首个可用；
- 「选择」是引用（`{type,id}`），装配时经 ModelCatalog 换出调用参数（model_name/api_base/api_key）成为 `llm.model`；配置模型参数源自 config.yaml+`.env`，**免费模型命中后直接复用预热时造好的缓存成品 Model（零创建，`api_key="public"`）**；
- 显式选择会话空闲时顺手写入会话元数据（`update_session_model_selection`）；**会话执行中换模型报错**（cannot change while executing）；保存的选择失效（模型被删）回落全局默认（restore）。

## 6. 测试与验收

### 6.1 单元测试（各包 ≥85%，真实链路纪律——禁窄接口替身）

- `config_service`：GetPanel env 回读（**读文件非内存**的时序语义实证）、yaml merge 失败 setdefault 兜底、每个开关 `_bool_text`/`_depth_switch_text` 边界、四只读方法分派与 BAD_REQUEST；
- `configpanel`：ConfigChangeSet 记账与 reload_scopes、yaml 嵌套键写入、`.env` 写入 crypto 加密/明文双分支、models_replace_all 差异合并、config_validate_model 探活参数装配；
- zen：幂等 warm 并发防重入、拉取失败缓存为空、entries 追加进 models.list 形状；
- 转发 handler：请求拼装与错误透传。

### 6.2 集成测试（`tests/integration/swarm/web/`，suite.Run 形状）

1. **配置全链 e2e**：Gateway `config.set`/`config.save_all` → 转发 → Runtime 写盘（临时目录 .env+yaml）→ 断言磁盘实际变更 → `config.get` 回读断言开关墙反映新值（读文件非内存的实证）；
2. **模型变更后重载 e2e（用户点名硬用例）**：`models.replace_all` 改模型 → 断言 AGENT_RELOAD_CONFIG 经真实会话管线收到（非替身）→ 重载后新会话 `llm.model` 装配反映新模型（断言到 ModelCatalog 解析层）；**会话执行中换模型被拒**同链钉住；
3. **zen e2e**：warm 触发 → `models.list` 追加免费条目 → `session.selection.set` 选免费模型 → 会话解析命中缓存成品 Model（`api_key="public"`）→ **真模型交互冒烟（`integration && llm` 双标签，27.10 先例）**：选中的免费模型经真实 LLM 客户端发起一次真实对话往返，断言非空回复——免费链路不只是"能选上"，而是真能用；
4. **契约快照**：18 方法请求/响应字段形状，与 27.2/27.10 同目录合流。
