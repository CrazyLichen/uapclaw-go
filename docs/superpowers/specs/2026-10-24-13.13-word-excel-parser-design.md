## 二、WordParser 设计（word_parser.go，~800 行）

### 2.1 文件内部结构

```
docx 解析（自研内嵌实现，全部非导出）
  ├─ zip 解包 → 部件表（document.xml / styles.xml / document.xml.rels / media/*）
  ├─ rels 解析（rId → target 映射）
  ├─ styles.xml 解析（styleId → w:name 表）+ BabelFish 11 对别名
  ├─ document.xml 块遍历（保序，w:p / w:tbl 交替）
  ├─ paragraph.text 语义拼装（runs + hyperlink 子 runs + w:tab→"\t" + w:br→"\n"）
  ├─ row.cells 网格展开（gridSpan 横向重复 / vMerge 纵向回填 master）
  └─ 图片链（a:blip → r:embed rId → rels target → media bytes → 解码 → RGB → PNG 落盘）

WordParser（导出，Parser 接口实现）
  ├─ Supports：不覆写，继承 base 默认 false（Python 同款；路由靠 registry 装饰器注册，
  │   supports() 在 Python 里仅是查询接口，AutoFileParser.parse 用 _PARSER_REGISTRY 路由）
  ├─ Parse：构造 captioner → 逐块 → "\n".join(strip 过滤行) → 空则 nil → 整体软失败
  ├─ parseBlock → parseParagraph / parseTable
  ├─ parseParagraph → paragraphToMarkdown（Title→"#"、Heading N→N+1 个"#"）+ 图片提取 + captioner
  └─ parseTable → tableToMarkdown（首行表头 + "---" + cell strip + "\|" 转义 + 尾空行）
```

### 2.2 四保真点实现要点

1. **保序块遍历**：xml.Decoder 流式扫 w:body 直接子元素，遇 w:p 解段落、遇 w:tbl 解表格，按出现顺序产出块序列
2. **样式名**：`w:pStyle@w:val` → styles 表查 `w:name` → babelFishInternal2UI（11 对硬编码：`heading 1..9`/`caption`/`footer`/`header` → Title-case；其余原样）。解析失败 Error 日志回落原文（对齐 Python except 分支）
3. **合并单元格**：`w:tcPr/w:gridSpan@w:val` 横向重复 cell N 次；`w:vMerge`（`restart`=master 起点、无 val=续格）续格回填同行上方最近 master 的已拼装文本
4. **paragraph.text**：遍历 w:p 直接子节点——w:r 下 w:t（字面）、w:tab（`\t`）、w:br（`\n`）保序拼装；w:hyperlink 递归进其子 runs

### 2.3 图片链（对齐 Python 逐字语义）

- 段落元素内后序遍历找所有 `a:blip`（≈ XPath `.//a:blip`）
- `r:embed` rId → rels target → zip 内 `word/media/{target}` 字节
- 解码（png/jpeg/gif/webp）→ 非 RGBA 时 draw.Draw 到 RGBA 画布（≈ PIL convert("RGB")）→ png.Encode 落盘
- 命名：`images/{filename}__para_{块序号}__img_{页内序}.png`
- **坏图炸整篇**：Python 无局部 try，解码失败冒泡到外层 except → 整篇 None。Go 对齐：不做局部 recover，error 向上传播触发软失败

### 2.4 软失败与异步

- 软失败：整体 error 传播 → `logger.Error("Failed to parse DOCX ...")` → 返回 `nil, nil`（nil Document 不带 error，对齐 return None）
- Python asyncio.to_thread → Go 纯同步实现（13.15 ImageParser 同款先例）
- 空结果判定：`"\n".join` 后空串 → nil（对齐 `result if result else None`）

## 三、ExcelParser 设计（excel_parser.go，~250 行）

### 3.1 方法映射

| Python | Go | 保真要点 |
|---|---|---|
| `_cell_str` | `cellStr(v any) string` | nil→""；str(v).strip() 逐类型模拟 |
| `_rows_to_documents` | `rowsToDocuments` | 黄金基准实测锁定（§3.2） |
| `_sheet_to_documents` | `sheetToDocuments` | iter_rows(values_only=True) → adapter 产出 [][]any |
| `_load_delimited_rows` | `loadDelimitedRows` | utf-8-sig → BOM 剥离 + encoding/csv；TSV \t |
| `parse`（整体覆写） | `Parse` 整体覆写 | exists→155103；分支失败→155104（cause 链）；成功 Info 日志 |
| `supports`（覆写） | `Supports` 覆写 | 空串 false；小写后缀 ∈ {.xlsx,.csv,.tsv} |

### 3.2 rowsToDocuments 精确语义（黄金基准实测锁定）

```
row docs（row_idx 从 2 起）:
  include_header=true && h≠"":  append "h: v"   ← h 非空无条件 append（值空也产出 "Name: "）
  include_header=true && h=="": 整格跳过
  include_header=false:          v≠"" 才 append
  parts 空 → continue
  text = ", ".join(parts)；id = {base}_s{si}_r{row_idx}；metadata: sheet_name/row_index/source_type="row"

column docs:
  空表头列 col_name 回落 "Column {i+1}"
  values = 非空过滤；include_header=true → "Column name: X. Values: ..." 或 "(empty)"
  include_header=false → ", ".join(values)，空列 text=""
  id = {base}_s{si}_c{col_idx}；metadata: column_name/source_type="column"
```

黄金基准样例（include_header=true，headers=('Name', None, 'Age')）：
```
base_s0_r2 | 'Name: alice, Age: 30'
base_s0_r3 | 'Name: bob, Age: '
base_s0_r4 | 'Name: , Age: '            ← 全空值行仍产出（h 非空即 append）
base_s0_c0 | 'Column name: Name. Values: alice, bob'
base_s0_c1 | 'Column name: Column 2. Values: x'   ← 空表头列回落
base_s0_c2 | 'Column name: Age. Values: 30'
```

**纠正项**：全空值行（表头非空）仍产出文档；"空 parts 行 continue"仅发生在所有格均为空表头时。

### 3.3 excelize adapter（[][]any 类型语义还原）

| xlsx cell | openpyxl 返回 | _cell_str 期望 | Go adapter 产出 |
|---|---|---|---|
| `<v>30</v>` 数字无小数 | int 30 | "30" | strconv.FormatInt |
| `<v>3.5</v>` | float 3.5 | "3.5" | float64 → pyFloatStr |
| `<v>1</v>` t="b" | bool True | "True" | "True"（非 excelize 默认 TRUE） |
| 日期样式 | datetime | "2025-01-01 00:00:00" | ExcelDateToTime → Format("2006-01-02 15:04:05")（微秒非 0 时再补 ".000000"；Excel 日期微秒恒 0，实测 str() 省略） |
| shared string | str | 原文 strip | 原样 |
| 空 cell | None | "" | nil |

### 3.4 pyFloatStr（Python str(float) 记法还原）

`abs ∈ [1e-4, 1e16)` 普通记法（整数值补 `.0`），否则 `'e'` 最短记法。
实测锚点：`1e15→"1000000000000000.0"`、`0.1+0.2→"0.30000000000000004"`、`3.5→"3.5"`。

### 3.5 七个保真陷阱（测试逐一锁定）

1. 空表头整格丢弃 + 全空值行仍产出（§3.2 纠正项）
2. zip 短边截断：行文档按 min(headers,row) 截断；列文档越界保护 col_idx < len(row) 分开处理
3. pyFloatStr 记法（§3.4）
4. bool 大小写："True"（非 TRUE/true）
5. CSV utf-8-sig：BOM 剥离；GBK decode 失败 → 155104
6. 空 xlsx/无 sheet：返回 [] 非 error；"Parsed %s: 0 documents" 照打
7. excelize/openpyxl 日期边界对拍：1904 时钟、1900-02-29 闰年 bug、序列数 60
