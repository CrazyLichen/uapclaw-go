## 0. 在 Agent 会话中的流程位置与作用

15.16b 是「一条团队消息 → 成员执行」主链路的**分叉点**：SpawnManager.SpawnTeammate 判 `ctx.cli_agent` 非空 → external_cli_spawn。它把 15.13 造的所有零件（BuildCliRuntime、ExternalHarnessMemberRuntime、tracker 绑定缝）装配进团队 spawn 主链路——TeamAgent 壳（协调/信箱/成员句柄）跑在本进程，成员的「大脑」是 CLI 子进程。

## 2. 通信机制（与用户对齐的结论）

```
CLI ──① MCP stdio──▶ uapclawmcpserver ──② WS RPC team.mq.publish──▶ gateway
                                                            → 壳进程总线
团队 → CLI：壳进程协调层经 CLI stdin 直推（15.13 已移植），不经 server
server 与团队：descriptor（OPENJIWEN_TEAM_JOIN env）→ 共享 DB + messager
生命周期：CLI 拉起 server（孙进程），stdio 断开即退出，宿主零监控
```
