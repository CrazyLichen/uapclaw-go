## 1. 流程位置与作用

23.4b 不在 agent 单轮 ReAct 循环内，位于 **agent 启动前的「选哪个模型可用」前置链**，是选择结果到运行时配置的编译层 + 执行壳：

```
① 网关 ModelSelectionResolver.resolve            (23.4d)
② 团队 pool/allocator 摊分                       (23.4c)
        ↓ ResolvedModel / ResolvedModelGroup（纯 DTO）
   routing.CompileModelSelection / GetModelGroupModels   ← 本批（编译器）
        ↓ ModelClientConfig{client_provider=intelli_router, intelli_router=IntelliRouterConfig}
   IntelliRouterModelClient                              ← 本批（客户端包装）
        → intellirouter.ReliableRouter（23.4a 已交付）
        ↓ 失败
   intelli_router_errors.ToModelError 失败四分类          ← 本批（错误翻译层）
        ↓ 驱动
   重试 rail（switchable→1.0s 后重调 router）/ ReAct 上下文恢复（request_rejected→压缩一次）
   / team 可靠性检测器（user_action→CRITICAL）
```

**作用**：①组→IntelliRouterConfig 编译；②no-routing 短路（组未配 strategy 取第一条启用路由当普通模型）；③context_window 取启用路由最小值、reasoning 编译期展开（复用 23.3）、extra_body 拍平；④失败四分类（switchable=181001；三种 exhausted 共用 181010）驱动上层三条恢复通道。

### 4.1 compiler.go 五个关键步骤（逐行对齐，禁止合并/搬移）

1. `_compile_model_group`：no_routing → `_compile_route_as_model(enabled_routes[0], request_config)`；`num_retries is None → max(len(deployments)-1, 0)`；异常包 `MODEL_GROUP_INVALID`。
2. `_min_context_window`：跳 bool，取正 int 最小，空则 nil。
3. `_apply_reasoning_controls`：pop reasoning → 构造临时 client_config/request_config → `ResolveReasoningPlan` + `ApplyReasoningPlan`（23.3 已交付包）；anthropic 强制补 `api_mode=anthropic-messages`（`_reasoning_client_config_data`）。
4. `_flatten_extra_body`：Mapping 展开 deepcopy，非 Mapping 原样保留。
5. `_router_provider`：显式 `intelli_router_provider` → anthropic 特判（api_mode 或 core 映射）→ endpoint_profile 映射 → core provider 映射 → 原样。

## 4. 错误翻译层（errors.go）关键语义

- **分类**：`_TRANSIENT_ERROR_TYPES`（Server/RateLimit/Timeout/Network）→ transient；状态码 ∈ {401,403,404} → deterministic；其余非 429 4xx → request_rejected；默认 transient。`output_emitted=true` 强制 stream_interrupted 且 message 前缀 "stopped in the middle of its answer"。
- **进程级失败记录**：`map[key]RouteFailure` + `sync.Mutex`；`record_routing_event`（成功事件清记录）/`_record_exception`（AllDeploymentsFailed 的 errors 列表逐条解析）。
- **ToModelError 四分支**（顺序不得调整）：无候选（tag_not_found）→ usable+流中断（switchable/stream_interrupted）→ usable（switchable，retry_after=1.0）→ 全耗尽依次判 stream_interrupted / 全 rejected（释放冷却 + request_rejected）→ 全 deterministic（fix_hint）→ transient_repeated（阈值 2）→ has_transient（wait=min 冷却+0.5，夹 [1,60]，retry_after）。
- **details 契约**（前端消费，逐字不本地化）：`route_case/reason/should_retry/retry_after_seconds/user_action_required/output_emitted/model_group_id/pinned_model/failures[]/usable[]/status_code`；`failures[].message` 携带 provider 原始响应文本（`_provider_detail` 截 200 字符）。
- **依赖 23.4a 契约面**（已在 a 批导出）：`State.ConsecutiveFailures/CooldownUntil/DeploymentStatuses/ResetDeployment`、`Strategy.FallbackTag`、`observability.SupportedEventTypes()`、错误判型 `IsDeploymentNetworkError/RateLimit/ServerError/Timeout` + `StatusCodeOf` + `ErrorTypeName`。

### 4.2 与上层三条恢复通道的衔接（信号通道各不相同，不冲突）

| 通道 | 消费的信号 | 语义 |
|---|---|---|
| 重试 rail（9.86 model_anomaly rail） | `details.should_retry/retry_after_seconds`（异常链上找到即优先于状态码推断） | switchable→1.0s 延迟重调 router；exhausted_retryable→min 冷却+0.5s 夹 [1,60]；request_rejected→should_retry=False 放行 |
| ReAct 上下文恢复 | **异常文本短语匹配**（非 route_case）：`ContextEngine.is_context_overflow_error` 遍历 details 字段与 cause 链匹配 "context length"/"prompt is too long" 等（context_engine.py:47-75） | 命中→压缩一次（`_model_exception_recovery_attempted` 只允许一次）→重试同一步。**Go 侧 ToModelError 必须把 provider 原始响应文本放进 details/cause，否则整条恢复静默失效** |
| team 可靠性检测器 | `route_case`/`user_action_required` | switchable→MEDIUM 通知（每 deployment+reason 一次）；request_rejected→按普通错误计数；user_action→CRITICAL |

## 5. 客户端包装（model_clients/intellirouter 重写）

- 注册 `__client_name__="intelli_router"`（沿用 `model_clients_register.go` blank import 位）。
- `IntelliRouterClientConfig`：11 字段 + `FromModelClientConfig`（含 intelli_router 结构路径与 extra 兜底路径两条）；num_retries 缺省 max(len-1,0) 在此再兜一次（编译器已填）。
- **routed_model**：`RoutedModelLabel`（fallback_tag 优先，回退 model_name，`*` 是逻辑名不下发）/`HasRoutedModelPlaceholder`/`fillRoutedModel`（string 与 []ContentPart 两形态，只拷贝含占位符的消息）；`_RoutedModelAdapter` + `_RoutedModelRouterMixin` 动态类继承 → **构造期函数指针注入**（偏差 D-5；hookTransformRequest/hookRouteMetadata/hookAnnounceRouteAttempt/hookMakeRequest，绝不 embedding 覆盖）。
- router 缓存：md5 key + double-check locking；loop 绑定防御不移植（偏差 D-4，Go net/http.Client 并发安全）。
- `_CoreRoutingEventBridge`：路由器事件总线 → core 回调框架；`_log_route_failover` 日志字段逐条对齐。
- Invoke/Stream + `_to_ow_assistant_message/_to_ow_chunk/_to_ow_usage_metadata`（reasoning_tokens 入 usage）；多模态三件套 `_generate_image/speech/video_dashscope` 全量移植（~430 行，DashScope 端点直调）。
