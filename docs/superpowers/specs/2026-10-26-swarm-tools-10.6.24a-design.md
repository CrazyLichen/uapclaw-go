## 三、wiki_tools.go 组件设计

### 3.1 结构体

```go
// sourceManifest 已摄取源清单，按 SHA-256 内容哈希去重
// Python: _SourceManifest (wiki_tools.py L89-158)
type sourceManifest struct {
    path  string                                 // sources/manifest.json 绝对路径
    sysOp sysop.SysOperation                     // nil → 本地 FS 分支
    data  map[string]map[string]string           // sha256 → {name, destination, ingested_at}
}

// llmWiki Wiki 引擎：目录初始化 + 摄取/查询/巡检委托内嵌 DeepAgent
// Python: LLMWiki (wiki_tools.py L161-350)
type llmWiki struct {
    workspace   string
    sourcesDir, wikiDir, schemaDir string
    manifest    *sourceManifest
    agent       *harness.DeepAgent
    sessionID   string    // workspace 绝对路径 SHA-256 前 16 位
    session     *session.Session
}
```

### 3.2 关键行为

**SourceManifest 四方法**：sha256Of（64KB 块流式，非文件报错）；ensureInitialized（load，JSON 损坏/OSError → 空 map 吞错）；record（已存在跳过；MarshalIndent 写回）；allEntries。文件读写双分支：sysOp 非 nil 走 `sysOp.Fs().ReadFile/WriteFile`（code==0 判定），nil 走 os 包。

**ensureInitialized**：三目录 MkdirAll → manifest 初始化 → 三模板文件“不存在则写入”（AGENT.md 7 条规则 / index.md 四段骨架 / log.md grep 友好头，内容逐字）→ agent.EnsureInitialized。

**ingest(source, force)**：sha256 → 非 force 已知 → skipped 结果 + Warn 日志；复制 `sources/{sha[:8]}_{filename}`（shutil.copy2 → io.Copy 保留 mtime；resolve 相同跳过）；固定 query 模板（逐字）→ `agent.Invoke({"query":...}, WithSession)`；result 含 error 键或 output 前缀 `[ERROR` → 不记哈希返回；成功才 record。

**query/lint**：固定模板 query + Invoke，无清单副作用。

**resolveWorkspace**（分支序照抄）：空/".llm_wiki" → `AgentWorkspaceDir()/.llm_wiki`；相对路径 → 基于 AgentWorkspaceDir；expanduser（`~/x` → os.UserHomeDir 前缀替换）；末段非 .llm_wiki → 追加；EvalSymlinks 失败回退 Abs。

**getDefaultModel**：GetDefaultModels(nil) → is_default 首项（无则 [0]，空则零值）→ custom_headers=="" 删除 → api_key/api_base/client_provider="OpenAI"/model_name="default" 四 setdefault → llm.NewModel。

### 3.3 三个工具函数

```go
type wikiIngestInput struct {
    Source    string `json:"source"`
    Workspace string `json:"workspace,omitempty"`
    Force     bool   `json:"force,omitempty"`
}
```

- wiki_ingest：目录模式 WalkDir 收集 .pdf/.md/.txt，跳过 .llm_wiki 内部（protectedRoot 前缀大小写不敏感）；结果 `"Wiki Ingestion Results:\n"+jsonIndent`，每文件 [Failed]/[Skipped]: Deduplicated/[Success] 三态；顶层异常 → `"Wiki Ingest Error: %s"`
- wiki_query：空 query → `"Error: Query cannot be empty."`；workspace 不存在 → 引导文案（逐字）
- wiki_lint：同防御；错误前缀 `"Wiki Query/Lint Error: %s"`

### 3.4 内嵌 agent 构造（对齐 LLMWiki.__init__ 默认值）

CreateDeepAgentParams：Model=getDefaultModel()、Card=wiki_agent（cn/en 描述常量逐字）、SystemPrompt=cn/en 双语常量逐字、Rails=[SysOperationRail()]、EnableTaskLoop=true、MaxIterations=15、Workspace=NewWorkspace(w.workspace, lang)、Language=ResolveLanguage、SysOperation=sysOp（nil → 内部默认）。

## 十、偏差登记表

| # | 偏差 | 理由 |
|---|---|---|
| 1 | todo_compat 的 list 校验防御在 Go schema 层天然存在 | 层级不同非缺失 |
| 2 | cancelPendingTodos：Go cancelTodos 不含 save（Python _cancel_todos 含），外层显式两步 | Go 原生分派结构，语义等价 |
| 3 | Python monkey-patch → Go 显式工厂注入 | 机制差异，行为等价 |
| 4 | mcp_command 的 context 三函数（cwd/project_root/workspace_root）复用 agentcore cwd 包既有导出（GetCwd/GetProjectRoot/GetWorkspace），不依赖 uapswarmProjectDir | Python 从 SDK sys_operation.cwd 导入，Go 有直接对应物 |
| 5 | mcp_search/mcp_web_fetch 代理链 Python 双份拷贝，Go 双份复刻不合并 | 一比一文件边界 |
| 6 | image_gen 无 strict/embed 回退 | Python 本身如此，非缺失 |
| 7 | generate_image 的 size/quality 参数 Python 透传未用（_invoke 内不消费），Go 同样透传不消费 | 忠实复刻冗余参数 |
| 8 | ApplyImageGenModelConfigFromYAML 落位 tools 包 image_gen.go（Python 在 multimodal_config.py） | adapter/multimodal_config.go 落位会形成 tools→adapter 循环依赖（adapter 已 import tools 取 GenerateImage）；函数随工具走，语义不变 |
