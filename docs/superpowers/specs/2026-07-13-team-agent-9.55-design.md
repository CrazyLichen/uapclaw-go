# 9.55 TeamAgent 生产级团队 Agent 设计

> 对应 Python：`openjiuwen/agent_teams/agent/team_agent.py` + `jiuwenswarm/server/runtime/agent_adapter/team_helpers.py`

## 1. 概述

TeamAgent 是多 Agent 协作系统的核心编排节点，既可充当 Leader 也可充当 Teammate。采用组合式架构包裹 DeepAgent，委托给专职 Manager 管理配置/生成/恢复/会话/流式/协调。

本章节范围包括：
- TeamAgent 主体方法实现（约 20+ 方法当前为桩/空操作）
- CoordinationKernel 完整生命周期编排（Start/Pause/Stop）
- 回调链接通（onTeammateCreated/onTeamCleaned/onTeamBuilt/registerTeamCompletionCallbacks）
- 遗漏依赖补齐（CoordinationKernel 构建、Runner.TeamRuntimeManager 接入等）
- 其他章节预留的 15 处回填点
- deep_adapter team 模式分流（对齐 Python team_helpers.py 1393 行）

## 6. CoordinationKernel 完整生命周期（D 层）

### 6.1 Start(ctx, session)

对齐 Python `CoordinationKernel.start(session)`：

1. `setMemberID(memberName)` — 设置成员 ID 上下文
2. `infra.TeamBackend().DB().Initialize(ctx)` — 数据库初始化
3. `sessionManager.BindSession(ctx, session)` 或 `ReleaseSession(ctx)` — 会话绑定/释放
4. `[Leader]` 检查全部 SHUTDOWN → `cleanTeam()` 或 `recoverTeam()`
5. `[Workspace]` `workspaceManager.Initialize(remoteURL)` — 工作空间初始化
6. `[Memory]` `memoryManager.InitToolkit()` → `harness.RegisterMemberTools()` → `harness.InjectMemberMemory()`
7. `host.UpdateStatus(ctx, MemberStatusReady)` — 状态更新
8. `eventBus.Start(ctx, dispatcher.dispatch)` — 事件总线启动
9. `host.SubscribeTransport(ctx)` — 传输订阅
10. `dispatcher.TeamCompletion.Rearm()` — 重新装备完成检测
11. `lifecycleState = "running"`

### 6.2 Pause(ctx)

对齐 Python `CoordinationKernel.pause()`：

1. `host.DrainAgentTask(ctx)` — 等待当前 agent round 完成
2. `host.PersistAllocatorState()` — 持久化模型分配器
3. `[Leader]` `host.MarkLiveTeammates(ctx, MemberStatusPaused)` — 标记活跃成员
4. `[Leader]` 取消恢复任务 + `spawnManager.ShutdownAllHandles()`
5. 持久化生命周期状态 "paused"
6. `[Leader]` `messager.Publish(TEAM_STANDBY)`
7. `host.UnsubscribeTransport()` — 取消传输订阅
8. `eventBus.Stop()` — 停止事件总线
9. `host.CloseStream()` — 关闭流
10. `sessionManager.ReleaseSession(ctx)` — 释放会话
11. `lifecycleState = "paused"`

### 6.3 Stop(ctx)

对齐 Python `CoordinationKernel.stop()`：

1. `host.DrainAgentTask(ctx)` — 等待当前 agent round 完成
2. `host.PersistAllocatorState()` — 持久化模型分配器
3. `[Leader]` `host.MarkLiveTeammates(ctx, MemberStatusStopped)` — 标记活跃成员
4. `host.UnsubscribeTransport()` — 取消传输订阅
5. `spawnManager.ShutdownAllHandles()` — 关闭所有生成句柄
6. `memoryManager.Close()` — 关闭记忆管理器
7. `eventBus.Stop()` — 停止事件总线
8. `host.CloseStream()` — 关闭流
9. `sessionManager.ReleaseSession(ctx)` — 释放会话
10. `lifecycleState = "stopped"`

## 7. Invoke/Stream 实现（E 层）

### 7.1 Invoke

```go
func (a *TeamAgent) Invoke(ctx context.Context, inputs map[string]any, opts ...AgentOption) (map[string]any, error) {
    a.streamController.streamQueue = make(chan stream.Schema, 64)
    query := inputs["query"]
    a.state.PendingUserQuery = query
    a.coordination.Start(ctx, session)
    defer a.coordination.FinalizeRound(ctx)
    a.coordination.EnqueueUserInput(query)
    a.coordination.EnqueueMailboxAfterFirstIteration()
    var lastResult map[string]any
    for {
        chunk, ok := <-a.streamController.streamQueue
        if !ok || chunk == nil { break }
        lastResult = chunk
    }
    return lastResult, nil
}
```

### 7.2 Stream

与 Invoke 相同的初始化流程，但返回 channel 而非收集：
```go
func (a *TeamAgent) Stream(ctx context.Context, inputs map[string]any, opts ...AgentOption) (<-chan stream.Schema, error) {
    a.streamController.streamQueue = make(chan stream.Schema, 64)
    // ... 同 Invoke 初始化
    ch := a.streamController.streamQueue
    return ch, nil
}
```

### 9.6 removeSelfFromPool

TeamAgent 私有方法，对齐 Python `_remove_self_from_pool`：

```go
func (a *TeamAgent) removeSelfFromPool(ctx context.Context, sessionID string) {
    teamName := a.TeamName()
    if teamName == "" || sessionID == "" { return }
    mgr := runner.GetTeamRuntimeManager()
    if mgr == nil { return }
    pool := mgr.Pool()
    entry := pool.Get(ctx, teamName)
    if entry == nil || entry.CurrentSessionID != sessionID { return }
    pool.Remove(teamName)
}
```
