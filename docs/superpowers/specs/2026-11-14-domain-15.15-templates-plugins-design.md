## 5. 回归清单（本批新增用例）

1. **插件热绑存活**：load_plugin → adapter 模式切换（buildAgentRails 重建）→ 插件 rail 仍在、工具仍可用。
2. **热换模型不丢工具**：load_plugin_ability(工具) → configure 换 model → 工具仍在（部分更新保留语义）。
3. **卸载闭环**：unload_extension 后 ref 全部移除、`_load_records` 出账、`_active_agent_template` 清位。
4. **失败回滚**：binder 中途失败（如 rail 同名冲突）→ 已绑 refs 逆序全部撤销。
5. **skill 热绑**：load_plugin 含 skill → skills_dir 追加 + `DeepAgentConfig.Skills` 记账 + D-5 数据源生效。
6. **legacy yaml 三形态**：各形态 fixture 包 load_plugin 成功且与 manifest.json 等价归一。
7. **rail 注册数回归锚点**：每次 load/unload 断言 rail 注册数变化（15.5 教训：装配型函数必须配注册数锚点）。

集成测试落 `tests/integration/agentcore/harness/extension/`（真文件型 plugin 包 fixture，跨 schema/resources/binder/deep_agent ≥4 子系统，满足审计两层门禁）。
