## 一、在 agent 会话中的流程位置与作用

### 1.1 流程位置

```
用户链路:  用户 → WebChannel → MessageHandler.forward_loop → AgentClient ──E2A──→ AgentServer

心跳链路（11.11 新增的旁路定时器，不经 MessageHandler 入站）:
  AppGatewayServer.Start()
     └─ GatewayHeartbeatService.Start()   ← goroutine 循环
          └─ 每 interval_seconds 一次 tick():
               ① isActiveNow()            活跃时段判断（跨午夜区间支持）
               ② E2AFromAgentFields( channel_id="__heartbeat__",
                                     session_id="heartbeat_{hex时间}_{6hex}",
                                     params={heartbeat: HeartbeatPrompt,
                                             run:{kind:"heartbeat",
                                                  context:{reason:"interval",
                                                           session_id:...}}} )
               ③ AgentClient.SendRequest(ctx, envelope)   ← 可带 timeout
               ④ 解析 resp.payload["heartbeat"] 或 payload["content"].output
               ⑤ RelayChannelID 非空 → EventType.HEARTBEAT_RELAY 事件 Message
                  → MessageHandler.PublishRobotMessages → 出站派发 → WebChannel → 前端弹窗
```

心跳是 Gateway 内的旁路定时器：自造请求、自收响应，仅在 relay 阶段借用 MessageHandler 出站通道。AgentServer 侧接收端（HandleHeartbeat query 注入、build_user_prompt heartbeat 分支、HEARTBEAT.md 读取、agentcore RunKindHeartbeat→HeartbeatRail 注入链）Go 已全部就绪——11.11 补的是"发令枪"。

### 1.2 作用

1. **数字分身"活着"的载体**：Agent 收到心跳 prompt 后读 workspace 的 HEARTBEAT.md（用户预写的周期任务），有文件就执行任务，没有就只回 HEARTBEAT_OK 安静待着。
2. **探活 + 状态观察**：`lastTickOK/lastTickAt` 暴露 Agent 存活状态；HEARTBEAT.md 任务产出经 relay 回传，前端 HeartbeatMessageModal（已实现）弹出心跳消息。
3. **配置动态化**：web 端 `heartbeat.get_conf/set_conf/get_path` 三个 RPC 运行时改间隔/目标/活跃时段，写回 config.yaml（round-trip 保注释）+ 清 Agent 侧配置缓存。

## 三、核心类型

```go
// ─── 结构体 ───

// HeartbeatConfig 心跳配置（对齐 Python HeartbeatConfig dataclass）
type HeartbeatConfig struct {
    // IntervalSeconds 心跳间隔（秒），MUST > 0
    IntervalSeconds float64
    // TimeoutSeconds 单次心跳请求超时（秒），nil 表示不限
    TimeoutSeconds *float64
    // ChannelID 心跳请求 channel_id，默认 __heartbeat__
    ChannelID string
    // RelayChannelID 心跳响应回传的 channel_id（如 "web"），nil 不回传
    RelayChannelID *string
    // ActiveHours 生效时间段 {"start":"HH:MM","end":"HH:MM"}，nil 始终生效
    ActiveHours map[string]string
}

// AgentRequester 心跳服务所需最小 AgentClient 接口（复刻 cron.SchedulerAgentClient）
type AgentRequester interface {
    SendRequest(ctx context.Context, envelope *e2a.E2AEnvelope) (*schema.AgentResponse, error)
}

// MessagePublisher 消息发布接口（复刻 cron.MessagePublisher）
type MessagePublisher interface {
    PublishRobotMessages(msg *schema.Message)
}

// IHeartbeat 心跳接口（对齐 Python IHeartbeat ABC）
type IHeartbeat interface {
    Start(ctx context.Context) error
    Stop()
    IsRunning() bool
}

// GatewayHeartbeatService 周期性向 AgentServer 发送探活请求
type GatewayHeartbeatService struct {
    agentClient AgentRequester
    config      *HeartbeatConfig   // 可变（set_conf 修改），mu 保护
    publisher   MessagePublisher   // relay 回传用，可为 nil
    nowFn       func() float64     // 时钟注入（偏差①）
    mu          sync.Mutex
    running     atomic.Bool
    cancel      context.CancelFunc
    wg          sync.WaitGroup
    lastTickOK  *bool              // nil=尚未执行（对齐 Python None 三态）
    lastTickAt  *float64
}

// ─── 常量 ───
const (
    HeartbeatChannelID = "__heartbeat__"
    HeartbeatOK        = "HEARTBEAT_OK"
)
// HeartbeatPrompt 逐字复制 Python L26（含半角逗号空格）：
const HeartbeatPrompt = "如果你的workspace目录存在HEARTBEAT.md文件, 读取文件内容并且根据文件内容执行任务. 如果没有HEARTBEAT.md文件, 仅回复HEARTBEAT_OK"
```

**normalizeActiveHours** 包级导出函数：入参 `map[string]any`（config 原始值），出参 `map[string]string`。int/int64/float64 → `int(v)` 分钟数 → divmod 60 → "HH:MM"；string 直通；其他非 nil → str 化；nil/空 → 原样返回 nil。对齐 Python L29-46 逐分支。

**SessionID/RequestID 生成**（对齐 L179-182）：
```go
ts := fmt.Sprintf("%x", time.Now().UnixMilli())        // format(int(time.time()*1000), "x")
suffix := generateRandomHex(3)                          // secrets.token_hex(3)，6 hex 字符
requestID := fmt.Sprintf("heartbeat-%s_%s", ts, suffix)
sessionID := fmt.Sprintf("heartbeat_%s_%s", ts, suffix)
```
`generateRandomHex` 复制 routing/session_map.go L250 同款实现（crypto/rand + 失败降级时间戳切片）——包私有复制，不跨包引用（routing 是兄弟包，提取公共会引入额外重构，超出本节边界）。

## 四、生命周期与循环时序（逐字对齐，已拍板）

### 4.1 Start

```go
func (s *GatewayHeartbeatService) Start(ctx context.Context) error {
    if s.running.Load() { return nil }            // 幂等，对齐 L130-131
    s.running.Store(true)
    loopCtx, cancel := context.WithCancel(ctx)
    s.cancel = cancel
    s.wg.Add(1)
    go s.runLoop(loopCtx)
    // Info "Gateway heartbeat started" + every_seconds 字段（对齐 L134-137）
}
```

### 4.2 Stop

```go
func (s *GatewayHeartbeatService) Stop() {
    s.running.Store(false)
    if s.cancel != nil { s.cancel() }              // 中断 sleep 与 in-flight SendRequest
    s.wg.Wait()                                    // 对齐 await self._task（CancelledError 吞掉）
    // Info "Gateway heartbeat stopped"（对齐 L149）
}
```

tick 内 SendRequest 被 ctx cancel 中断 → err 分支 Warn（对齐 Python cancel 打断 wait_for）。

### 4.3 runLoop（先睡后跳）

```go
func (s *GatewayHeartbeatService) runLoop(ctx context.Context) {
    defer s.wg.Done()
    for s.running.Load() {
        select {
        case <-ctx.Done():
            return
        case <-time.After(time.Duration(s.config.IntervalSeconds * float64(time.Second))):
            // 先睡 interval 再 tick（对齐 L159），启动后首跳等一个完整间隔
        }
        if s.running.Load() {
            s.tick(ctx)   // tick 内部 recover；异常仅 Error 日志（对齐 L164-165）
        }
    }
}
```

`time.After` 每轮重新读 `s.config.IntervalSeconds`（mu 保护读）——对齐 Python 每轮 sleep 读最新值（set_conf 改间隔下轮生效）。

## 五、tick 六步

```go
func (s *GatewayHeartbeatService) tick(ctx context.Context) {
    defer func() { if r := recover(); r != nil { /* Error "Gateway heartbeat loop error" */ } }()

    // ① 活跃时段判断（对齐 L172-177）
    if !s.isActiveNow() { /* Debug "skipped due to inactive hours" + active_hours */ return }

    // ② 构造标识与 envelope（对齐 L179-197，见 §三）
    envelope := e2a.E2AFromAgentFields(requestID,
        e2a.WithFieldChannelID(s.config.ChannelID),
        e2a.WithFieldSessionID(sessionID),
        e2a.WithFieldParams(map[string]any{
            "heartbeat": HeartbeatPrompt,
            "run": map[string]any{
                "kind":    "heartbeat",
                "context": map[string]any{"reason": "interval", "session_id": sessionID},
            },
        }),
    )

    // ③ 发送（对齐 L199-205 双分支）
    tickCtx := ctx
    var cancel context.CancelFunc
    if s.config.TimeoutSeconds != nil && *s.config.TimeoutSeconds > 0 {
        tickCtx, cancel = context.WithTimeout(ctx, time.Duration(*s.config.TimeoutSeconds * float64(time.Second)))
        defer cancel()
    }
    resp, err := s.agentClient.SendRequest(tickCtx, envelope)

    // ④ 成功路径（对齐 L206-226）
    //    lastTickOK=true / lastTickAt=nowFn()
    //    heartbeatContent 三级提取：
    //      payload["heartbeat"] 为 string → 取之
    //      否则 payload["content"] 为 map 且 output 为 string → 取 output
    //      否则 payload["content"] 为 string → 取之
    //      皆不中 → ""
    //    Info "Gateway heartbeat content" + content
    //    strings.Contains(strings.ToUpper(content), HeartbeatOK)
    //      → Info "Gateway heartbeat OK"（request_id + last_tick_at）
    //      : Info "Gateway heartbeat complete"（request_id + last_tick_at）

    // ⑤ relay（对齐 L229-243）：RelayChannelID 非空 && publisher 非空
    //    直接构造 &schema.Message{...}（不走 NewEventMessage——其 ID 自动 UUID 不可控）：
    //    ID="heartbeat-relay-{requestID}" / Type=event / ChannelID=relay / SessionID=sessionID
    //    Params=json.RawMessage(`{}`)（channel_manager.go L462 同款先例）/ Timestamp=nowFn() / OK=true
    //    Payload={"heartbeat": heartbeatContent} / EventType=EventTypeHeartbeatRelay
    //    publisher.PublishRobotMessages(relayMsg) + Debug "relay to channel"

    // ⑥ 失败路径（对齐 L245-256）
    //    lastTickOK=false / lastTickAt=nowFn()
    //    errors.Is(err, context.DeadlineExceeded) → Warn "Gateway heartbeat timeout"（request_id + timeout_seconds）
    //    其他 → Warn "Gateway heartbeat request failed" + Err(err)
}
```

### 5.1 isActiveNow（对齐 L268-301）

- `normalizeActiveHours(config.ActiveHours)` 为空 → true
- start/end 非字符串 → true
- parseHM："HH:MM" `strings.Split(s, ":")`，长度≠2 或 int 解析失败 → error
- `now := time.Unix(int64(s.nowFn()), 0).Local()`；nowMinutes = hour*60+min（偏差⑤：nowFn float64 秒经 Unix 转本地时区，等价 Python time.localtime()）
- `start <= end`：`start <= now < end`；跨午夜：`now >= start || now < end`
- 任何 error → Warn "Invalid heartbeat active_hours config" + return true（配置非法时始终生效）

## 八、偏差归档

| # | 偏差 | 理由 |
|---|---|---|
| ① | nowFn `func() float64` 时钟注入（构造第 4 参，nil 兜底 time.Now） | 主动增强：测试确定性（isActiveNow 跨午夜分支/lastTick 断言）。Python heartbeat.py 无 now_fn 参数。形态对齐 cron 11.10 先例 |
| ② | yaml.v3 解析裸 `22:00` 得字符串；PyYAML 得 sexagesimal 整数 1320 | 解析器行为差异，实测验证。normalizeActiveHours 数字回转逻辑仍保留（web set_conf 传数字等路径语义完整） |
| ③ | Go 显式并发保护（mu + atomic + wg） | Python asyncio 单线程无竞态；Go goroutine 必须。行为语义不变 |
| ④ | lastTickOK/lastTickAt 用 `*bool/*float64` | 模拟 Python None 三态（nil=尚未执行） |
| ⑤ | isActiveNow 经 `time.Unix(nowFn(),0).Local()` 取本地时分 | nowFn 为 float64 Unix 秒（cron 先例形态），需还原本地时区对齐 Python time.localtime() |
| ⑥ | relay 消息直接构造 `&schema.Message{}` 而非 NewEventMessage | NewEventMessage ID 自动 UUID；Python 显式 `id=f"heartbeat-relay-{request_id}"` 需自定义 ID |
| ⑦ | web set_conf 清缓存 agentClient==nil 分支跳过 | Python else get_config() 本地重读；Go 装配中 web bind 总有 agentClient，该分支为防御性存在 |
| ⑧ | 装配处 `str(cfg_every)` 字符串中转省略 | Python `float(str(30))`；Go 数值直转 float64，语义等价 |
| ⑨ | handleSessionList 用 "heartbeat" 前缀（非 "heartbeat_"） | 与 dreaming sweeper Go 先例一致，对齐 Python startswith("heartbeat") |
