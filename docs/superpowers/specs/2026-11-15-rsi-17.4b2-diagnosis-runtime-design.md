## 3. 关键实现点

### 3.1 agent_runtime.go

- **BuildAgent**：ref = `diagnosis_agent_model_config_ref`（空则 `model_config_ref`，空报错）→ `LoadModelConfigRef` + `WithoutInnerSdkRetries`（b1 已有）→ `TeamModelConfig` 校验 → 经 `BuildDeepAgentFromModelConfig` 桩取 Model → `harness.CreateDeepAgentParams`：`RestrictToWorkDir=true`、`AutoCreateWorkspace=false`、`MaxIterations=config.DiagnosisAgentMaxIterations`、`InvocationLogDir`（§1.3-A）、`Rails=[RSISysOperationRail(只读+pipefail+_DIAGNOSIS_BASH_DENY_PATTERNS 两条正则), _DiagnosisBudgetRail]`
- **_DiagnosisBudgetRail**：`BeforeModelCall` 计轮次；未末轮注入"Investigation turn x/N …"提示消息；末轮 `ctx.inputs.tools = None`（收走工具）+ 注入"final turn…Preserve uncertainty explicitly"提示
- **RunDeepAgentText**：每次重试全新随机 session（`diagnosis_<uuid>`，防污染会话重放）；result dict 取 `output`/`answer`/整 dict JSON 兜底；`result_type == "error"` 抛 `DiagnosisAgentExecutionError`（带 `termination_reason`）；外层 `RunModelCallWithRetries`（harness_rsi/model_call.go 已有）
- **bash 禁令正则**：两条逐字照抄（根目录 find/du/ls/tree 禁令、`..` 上跳禁令）

### 3.2 analyzer.go

- **DiagnosisAgentStrategy.Analyze**：逐案稳定确定性顺序；每案临时工作区（`ach_analyzer_` tmpdir）+ 仓库快照隔离拷贝（复用 b1 repository_snapshot）→ 证据包（复用 task_contract / evidence_compactor / runtime_evidence）→ 造 agent → RunDeepAgentText → 诊断 JSON 解析（失败 `_DiagnosisOutputFormatError` 重试链）→ 归一化逐案病历
- **聚合**：独立聚合 agent（AGGREGATION_SYSTEM_PROMPT，禁止翻文件）→ 相似病历聚类去重（`_diagnoses_are_duplicate` 归一化文本比对）→ 结构化聚合 → `_diagnosis_unavailable_result` 兜底
- **TeamIssue 产出**：G5 映射（`_apply_g5_mapping`）、coordinator→team_skill 改道（`_coordinator_member_issue_as_team_skill`）、target_ref 归一化、evidence pipeline failure 判定等后处理链全量对齐
- **提示词**：DIAGNOSIS_SYSTEM_PROMPT / AGGREGATION_SYSTEM_PROMPT / _build_diagnosis_prompt / _build_diagnosis_input_json / _build_aggregation_prompt 逐字复制（一比一纪律），品牌键 jiuwenswarm→uapclawswarm 映射

### 3.3 evidence_investigation.go
> **回填（2026-11-16，用户拍板"引库对齐"）**：Python 实用 openpyxl/python-docx/pdfplumber 第三方库，原零依赖结论与 Python 事实不符。Go 落法：xlsx=excelize（GetCellFormula 对齐 data_only=False 公式串）、docx=fumiama/go-docx、pdf=ledongthuc/pdf、pptx=zip+xml 手拆（Python 同款 zipfile+ElementTree）。

- 常量面板：_MAX_HYPOTHESES=6 / _MAX_REQUESTS=12 / _MAX_SEARCH_RESULTS=5 / _MAX_EVENT_CHARS=12,000 / artifact 族预算（200K/100 个/12K 窗口/自动 12 窗 4 源 96K）等，逐字对齐
- `normalize_causal_investigation`：假设语义去重（claim+falsified_if 归一化语义）、hypothesis_id 冲突回退 h{n}、requirement 白名单过滤、numeric_change 强制检测（显式声明 OR 双正则 OR 计划含 compare_numeric_change，显式 false 不能关闭——控制面决策）、覆盖校验（min_hypotheses_per_requirement）
- `execute_causal_investigation`：10 种操作分发——check_relation / compare_numeric_change（AST 白名单求值）/ compare_runs / inspect_artifact / inspect_evaluation / read_artifact_window / read_repository_file / read_event / search_repository / search_trace
- 结构化 artifact：Python `zipfile+ElementTree` 自拆 XML → Go `archive/zip + encoding/xml` 零第三方依赖复刻（docx/pdf/pptx/xlsx 后缀集与查询提示词双轨）
