## 1. 流程位置与作用（对齐结论）

单会话（chat.send）请求链路中：

```
chat.send
 ├─ ① interface._resolve_runtime_binding_for_request → resolve_runtime_binding
 │    └─ resolveExternalHarnessBinding：manifest 卡片读取 + 会话元数据比对，
 │       裁决 deep_agent vs external_harness；换模板冲突报错
 ├─ ② reconcile_session_mcp：external 会话跳过 MCP reconcile，binding 传入会话子适配器
 ├─ ③ 会话子适配器创建：binding 挂载 + persistExternalHarnessBinding 持久化
 ├─ ④ 每次发消息：processExternalHarnessStream
 │    ├─ ensureExternalHarness 懒启动（mergeHostExternalCliConfig → CreateHarness
 │    │   → checkpoint 加载 → BuildHarnessContext(ResumePolicy) → IOAdapter.Start）
 │    ├─ Send → streamTurnOutput（turn_id 圈定本轮输出边界）
 │    ├─ 投影：user_input 中断→ask_user 卡片；其余走提取后的 parseStreamChunk
 │    ├─ TURN_LIFECYCLE 终态→checkpoint 持久化 + chat.final/error 收口
 │    └─ INTERACTION 挂起→runtime_completion="suspended"
 ├─ ⑤ 中断：processExternalHarnessInterrupt（cancel→graceful abort）
 └─ ⑥ 会话关闭：stopExternalHarness（checkpoint 导出落盘→io.Stop）
```

作用：让单 agent 会话把整个运行时换成三方专家模板包（外部 harness provider），会话级
不可变绑定（绑定后不能换专家），harness 协议事件流投影成网关聊天流
（delta/final/error/ask_user/suspended），checkpoint 跨进程重启恢复。
