本节是 **config → 成员 DeepAgentSpec 的唯一装配层**（Python `enrich_team_spec_for_swarm`，assembly.py:391，在 agentserver 会话链的位置）：

      │    + _with_project_cwd                                        ← T2

  → 外部 CLI 成员由 spawn 侧拉起（15.16b）

关键口径（讨论已澄清，写入 spec 供实施者核对）：

- **rail 只进 native 成员**：装配循环 `_MEMBER_ROLES = ("leader","teammate")`（assembly.py:76）只处理 `spec.agents` 两个内置角色。外部 CLI 成员能力 = team-mcp 动态工具（15.16b）+ provider config（15.16d），不经 rail。`mcp_configs` 只注入 native 成员。
- **`_apply_agent_group` 是团队级 roster 装配**，不是单成员能力装配：改写 `spec.leader.prompt` / `spec.agents` / `spec.predefined_members` / `team_mode=hybrid`；scheduled dispatch 下只装 leader 提前 return。其上游供给是 experts 包体系，消费点是 enrich 尾段。
- **TeamBackend 是每成员一份的运行时对象**（native: agent_configurator.py:1193；external: external/client.py:221），不进 spec、不序列化；本批只负责 spec 蓝图层，运行时接线归既有章节。
- **跨包访问机制**：Python `_runner_team_runtime_manager(GLOBAL_RUNNER)` 反射懒建 + TeamManager 主动 `pool.get(team_name)` 拉取 ActiveTeam.agent 缓存进 `_runner_team_agents`（非回调通知）。Go 侧偏差 D-15.16-e3。

## 3. 落成后的 enrich 数据流

见 §1 位置图。新链要点：

1. `build_enabled_mcp_server_configs(config, server_id_scope="team:<name>", resolve_credentials=True)` → mcp_configs（仅 native 成员消费）。
2. 成员循环逐 role 折能力 + `_with_project_cwd`（cwd/project_root 无条件指向请求 project_dir，注释语义：worktree 隔离开启时 AgentConfigurator 会再次覆盖）→ 回写 `spec.agents[role]`。
3. `spec.reviewer_agent = build_reviewer_deep_agent_spec(mode, spec.agents["teammate"])`（薄壳组合 reviewer_spec 收窄变换；文件工具只读化、去 todo planning、去 subagents、1200s 硬超时 + host allow-list）。
4. `agent_group_name` 非空：design 模式走 `_apply_design_agent_group`（**分支体留缝 D-15.16-e1**）；否则 `_apply_agent_group`（懒加载包：package 形参为 nil 时经 experts loader 按 resolve_agent_group_dir 加载；leader persona 合并；predefined_members 装配含外部模板成员 ExternalCliMemberSpec 分支；scheduled 提前 return）。
5. `group_members` 段保留步骤位置与分支结构，group_chat 未迁时报错路径（偏差 D-15.16-e2）。
6. 上游 `_load_session_team_spec` 恢复段：`get_team_binding_store().get_team_selection(team_name)` → 命中 `spec.team_name=team_name` 返回 has_binding=true；未命中回落 `get_session_model_selection(session_id)`（model_selection_store 已落）；`_default_if_deleted` 语义照抄。
