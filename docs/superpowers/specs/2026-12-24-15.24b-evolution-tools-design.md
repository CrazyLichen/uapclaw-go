## 4. 关键契约

### 4.1 ToolOutput（harness/tools/base_tool.go）

对齐 Python `ToolOutput(success, data, error)` 三字段；`RenderFields`（跳过 None/空串、非字符串 JSON 编码）。失败渲染规则（BaseEvolutionTool.RenderForLLM）：`error + "\n" + payload 文本`——partial 提交时 error 是通用信息，status/counts/retry_request_id 活在 payload 里。

### 4.2 ExperienceQueryService（query.go）

`SplitExperienceIndexQueryTerms`（`|` 分隔 OR 词袋、去重、小写）/ `FilterExperienceIndexRecords`（target/section/query 三过滤 + score_desc/updated_desc 双排序，非法 sort 报错）/ 游标分页（cursor 零基、next_cursor=None 结束）/ list（limit 1..100、skill_exists 校验）/ read（record_ids 非空、max_content_chars 1..20000、缺失 id 报 unknown record_ids）。index item：record_id/summary/target/section/score/updated_at；read item 加 content 截断与 content_truncated。

### 4.3 ExperienceSubmissionService（submission.go）

- `ApplyExperienceDrafts`（直接路径）/ `ApplySimplifyActions`
- 两段式：`PrepareEvolveSubmission`（resolve_selected_proposals + validate，不消费 ref）→ `ApplyPreparedEvolveSubmission`（records→pending→commit；record_source 覆写）
- `BindPendingApprovalSnapshots`（调用方持有 pending 快照表——15.21 rail/将来 c 批装配注入）
- 状态语义：applied（pending_count==0 且无 errors）/ partial；retry_request_id 仅 partial 时返回

### 4.4 工具面（tools/skill.go 六 + tools/review.go 五）

主 agent 六工具：PrepareSkillEvolutionReviewTool（user_confirmed 必须 true）/ EvolveReviewTaskTool（经 TaskTool 拉 evolution_reviewer；render_for_llm 只渲染 JSON）/ List/ReadSkillExperiencesTool / EvolveSkillExperiencesTool（selected_proposal_ids 非空、无重复、全字符串校验；成功才 consume_prepared_submission）/ SimplifySkillExperiencesTool（无 rail 时先 normalize 校验兜底直连）。session 定位：`_session_id`/`_session_scope` 从 kwargs（conversation_id/session.get_session_id/get_agent_id/get_team_id）。

审查五工具：List/ReadSkillExperiences（ref 绑定 scope.subject，默认 limit 50）/ List/ReadTrajectorySpans（ref=`span:traceId:spanId`；list 过滤 kind/name_contains/tool_name/has_error + 游标，默认 25 上限 50；read 上限 8 refs、unknown 报错、record_trajectory_read 记账）/ SubmitEvolutionReviewResultTool（outcome enum、proposals ≤ MAX_EVOLUTION_REVIEW_PROPOSALS、返回 proposal_selection_for_submission 载体）。

安全/截断常量照抄 review.py：`_review_safe`（data:image 脱敏、base64/image_url/bytes 键剔除）、bounded 截断（240/1200/800/500/3）+ original_chars、27 个 context 属性键白名单。

### 4.5 prompts/tools（evolution.go）

## 8. 裁决时的流程事实存档（防止后续实施误读）

1. prepare_scope 是审查启动前登记（轨迹快照 + scope），不写库；落盘唯一写点在 submission 的 commit_pending_change。
2. 被动路径协程即 rail 自己的方法（闭包捕获 self），生成结论进 `rail._pending_approval_snapshots`（本体）+ `_pending_host_events`（通知）；取走方是 host adapter 的 per-request watcher（单 agent 条件 `signal_trigger && !auto_save`），rail 永不主动取。
3. 审批路由靠 request_id 前缀（`skill_evolve_`/`evolve_simplify_`/`team_skill_evolve_`），不走 agent 循环；watcher 退出不影响已送达审批卡补答；pending 无自动过期。
4. 成员/团队角色策略：成员 auto_save=true 静默直落+sharing 上传；leader 侧审批走 watcher/汇流。
