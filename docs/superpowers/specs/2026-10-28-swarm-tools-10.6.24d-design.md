## 1. 目标与流程位置

10.6.24 Swarm 内置工具集 d 子节——ACP（Agent Client Protocol）工具组，两条独立链路：

1. **出站链路（acp_chat）**：主 agent 把外部 ACP CLI（Codex CLI / Gemini CLI 等）当子代理雇佣。LLM 调 `acp_chat(agent, message, new_session)` → 按 profile 查 `acp_agents` 配置 → spawn 子进程（stdio JSON-RPC）→ `session/prompt` → 聚合 `session/update` 文本 → 返回最终回复。profile 级 client 缓存 + 每 profile 互斥锁 + `new_session=true` 重启语义。
2. **入站链路（acp_output_tools 6 工具）**：ACP 会话下，agent 自身默认文件/终端工具被屏蔽，改借 IDE 之手执行——LLM 调 `read_text_file` 等 → `AcpOutputManager.sendJsonrpcRequest` 构造 E2AResponse（response_kind=acp.output_request）→ server_push 经 Gateway → IDE 执行 → IDE 回 `acp.tool_response` RPC → `completeJsonrpcResponse` 唤醒 future → 工具返回。30s 超时，wait_for_terminal_exit 软超时。
3. **权限确认桥**：ASK 级工具在 channel=="acp" 下不弹本地确认，改发 `session/request_permission` JSON-RPC 给 IDE 弹窗，允许/拒绝回流唤醒。

**agent 会话流程位置**：出站链在 getToolCards 步骤 10（deep_adapter_tools.go，配置检查注册）+ code 模式工具构建 case；入站链在 _refresh_acp_runtime_tools（每请求 tools 装卸，code_adapter.go:661）+ handleACPToolResponse（AgentServer RPC 层）；权限桥在 deep_adapter_rails 权限确认处（L1151）。

## 3. AcpStdioClient 设计（swarm/acp/）

### 3.1 结构体与并发模型（方案1 定案：读写分离 goroutine + sync 原语）

```go
type AcpStdioClient struct {
    command string
    args    []string
    cwd     string
    env     []string          // build_acp_subprocess_env 产物

    mu        sync.Mutex      // 保护 cmd/connected/nextID
    cmd       *exec.Cmd
    stdin     io.WriteCloser
    connected bool
    nextID    int64

    pendingMu sync.Mutex
    pending   map[int64]chan *rpcResult    // jsonrpc ID → 等待者

    updateMu sync.Mutex
    updates  chan string                   // session/update 文本流（chat 消费）
    stdoutBuf []byte                       // raw_decode 缓冲（对齐 _stdout_buf）

    stderrDone chan struct{}
    wg         sync.WaitGroup
    closed     chan struct{}               // Close 幂等
}
```

### 3.2 goroutine 拓扑

```
Connect() 启动：
  ├─ readerLoop goroutine：64KB chunk 读 stdout → consumeOneJSON 循环
  │     每解析一条按 jsonrpc 语义分派：
  │       · 有 id + result/error → pendingMu 查 pending[id] → 非阻塞投递
  │       · 有 id + method（peer request）→ go handlePeerRequest（回写响应）
  │       · 无 id（notification）→ session/update 提取文本 → updates chan
  └─ stderrDrain goroutine：逐行读 stderr → logger.Debug（对齐 Python debug 日志）
```

### 3.3 方法映射

| Python | Go | 语义 |
|---|---|---|
| `connect()` | `Connect(ctx)` | spawn 子进程 + 起两 goroutine + 发 `initialize` + `session/new`，记录 sessionID |
| `chat(text)` | `Chat(ctx, text)` | 发 `session/prompt` → 读 updates 聚合文本 → 等 stopReason（默认 600s，env `ACP_CHAT_TIMEOUT`） |
| `close()` | `Close()` | 三段优雅关闭（3.5） |
| `is_connected` | `IsConnected()` | mu 下读 bool |
| `_is_peer_jsonrpc_request` | `isPeerJSONRPCRequest(msg)` | jsonrpc=="2.0" + method str + id 非 nil + 无 result/error |
| `_extract_session_update_text` | `extractSessionUpdateText(msg)` | method==session/update → params.update.content.text |
| `_jsonrpc_error_message` | `jsonrpcErrorMessage(err)` | code/message/data 拼接 |
| `_merge_env` | `mergeEnv` | 调 buildAcpSubprocessEnv |

### 3.4 反向请求处理（peer → 我们）

| method | Python 行为 | Go 行为 |
|---|---|---|
| `session/request_permission` | `_AUTO_APPROVE`（env `ACP_AUTO_APPROVE_PERMISSIONS` 默认 true）→ 回 `{behavior:"allow"}` | 同 |
| `fs/read_text_file` | 读文件回 result | `os.ReadFile` |
| `fs/write_text_file` | 写文件回 result | `os.WriteFile` |
| 其他 | 回 JSON-RPC error `-32601` | 同 |

fs 路径处理对齐 Python：读/写失败回 error 响应（不抛出），request_permission 关闭时回 `{behavior:"cancel"}`。

### 3.5 三段优雅关闭（env 序列逐字对齐）

```
Close():
  1. stdin.Close() → 等 cmd.Wait 或 ACP_CLOSE_STDIN_WAIT_S(4s)
  2. SIGTERM（ACP_KILL_PROCESS_GROUP=true 且非 win32 时整进程组）→ 等 ACP_CLOSE_TERM_WAIT_S(5s)
  3. Kill() → 等 ACP 自然退出或 ACP_CLOSE_KILL_WAIT_S(8s)
  4. 等 stderrDrain ≤ ACP_CLOSE_STDERR_JOIN_S(3s)
  5. 失败 pending（投递 errClosed）、close(closed)、wg 清理
```

全部阈值 env 可覆盖（`os.Getenv` + 默认值，ValueError 回退同 Python try/except）。

### 3.6 解析器（stdio_client_parse.go）

`_consume_one_json` 的 Go 化：`json.Decoder` 读一个值后 `dec.Buffered()` 剩余即 raw_decode 语义（跳过前导空白、值后剩余保留）。24MB 缓冲上限（`ACP_CHAT_MAX_PARSE_BUFFER_BYTES`）、64KB 读块（`ACP_CHAT_STDOUT_READ_CHUNK`）走 env。JSONDecodeError → (nil, buffer) 不动。

## 10. 偏差预归档（实施前已知 6 项）

1. **future→chan**：asyncio.Future → 缓冲1 Done chan + acpOutputResult{Response, Err} 双字段。必要等价。
2. **profile 锁清理**：Python `_locks` dict 靠 GC 不清理 → Go profileLock 引用计数 + 释放后清理空条目（防 map 膨胀）。Go 侧增强。
3. **解析器**：`json.JSONDecoder.raw_decode` → `json.Decoder` + `Buffered()`。必要等价（语义一致：前导空白跳过、值后剩余保留）。
4. **os.path.exists 吞 OSError**：Python 读文件 except 兜底 → Go `os.ReadFile` err 分支回 error JSON-RPC 响应（fs/read_text_file 对端逻辑）。等价。
5. **Windows 平台**：`_KILL_PG` 非 win32 判定 → `runtime.GOOS != "windows"`；testdata 脚本 Windows t.Skip。必要等价。
6. **acp_chat 工具卡描述**：Python L96-101 是英文 → Go 逐字复制英文（不翻译）。**不算偏差**（提示词逐字复制规则）。
