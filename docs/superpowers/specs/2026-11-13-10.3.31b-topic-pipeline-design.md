## 1. 背景与流程位置

TopicPipeline 是「终态新页话题推荐」（terminal new-page topic recommendation）的**后台生产编排器**，不在主对话链路上：

```
会话事件（回答完成 / 新页请求 / 新闻检查）
  → TopicService (topic_service.py, 31d)          触发调度、per-scope 单槽合并排队、chat 让路
      → TopicPipeline (topic_pipeline.py, 31b)    ★ 本节
          ├─ TopicPreparePipeline (topic_prepare)  状态准备：会话摘要批处理 / 兴趣蒸馏 / RID 决策
          ├─ topic_collector                       结果回收与训练事件投影
          ├─ topic_pool                            起始池读写 + 触发幂等（BackgroundGenerationCoordinator）
          ├─ topic_retrieval                       固定起始检索 + 证据契约（冻结文档 / 准入）
          ├─ topic_search                          搜索提供方适配（⤴️ 31c 已交付：topic_search.go）
          ├─ topic_model                           Ark 后台模型 stage invoker（⤴️ 31c 已交付：topic_model.go）
          └─ 产出 BackgroundGenerationResult → write_starter_pool → TopicStarterStore（10.7.1 已交付）
  → 31c 产物与呈现（build_terminal_card 等）→ 事件账本 → 前端新页卡片
```

设计要点（大白话）：**事件驱动触发、per-scope 单槽 + 深度 1 合并排队（非 MQ）、事件账本幂等、chat 让路、总 deadline + 可选 lane 降级、全链路 receipt 留痕**。

## 4. Go 架构映射（asyncio → goroutine）

| Python 结构 | Go 等价 | 说明 |
|---|---|---|
| `asyncio.Task` + slot.current/queued（per-scope 深度 1 合并队列） | per-scope `current, queued` 两个 `*generationRun`（含 context.CancelFunc）+ `sync.Mutex` 槽状态机 | TopicService 侧调度随 31d；31b 交付 coordinator 幂等/记账 |
| `asyncio.timeout(deadline)` | `context.WithTimeout`（快照 deadline，不得共享可变指针） | 超时记 `background_generation_deadline` 事件 |
| `_GENERATION_ATTEMPT_ID` contextvar | `ctx.Value(generationAttemptIDKey{})` | 31c `providerInvocationContextKey` 同款先例 |
| `asyncio.Lock`（`_state_refresh_lock` / `_summary_locks[scope]`） | `sync.Mutex` + `map[string]*sync.Mutex`（scope 级） | |
| `_OptionalLanes`（可选 lane 超时降级，mandatory_ready） | errgroup + `Select(ctx, done)` 超时分支；可选 lane 结果可缺席（absent_reason） | 不得用 time.After 泄漏；用 ctx 派生 |
| `_Scoring.tasks` / 批量 invoke | 有界并发（信号量 chan struct{}），批大小对齐 Python | |
| origin 等级合并（_ORIGIN_RANK） | 常量序 + 取最强 | TopicService 语义，31d 落地，31b 只导出 rank 表 |

**偏差 2：`OptionalLanes` 用 `context.WithDeadline` + goroutine select，未用 errgroup**
- Python 符号：`topic_pipeline.py:2636-2699` `_OptionalLanes`（asyncio.wait + task.cancel）
- Go 等价位置：`topic_pipeline_c2.go:225-237`（`NewOptionalLanesWithGrace` 注入宽限供测试）
- 偏差性质：并发原语选型。计划 Tech Stack 写 errgroup，实际不用——asyncio.wait 的 done-优先 + 60s 宽限语义用 `context.WithDeadline` + `select{done, deadline}` 表达更直接；errgroup 的 `Wait` 语义需绕行才能实现「过期不执行新调用但不打断已完成」
- 回收条件：无（语义等价且有 race 用例：`TestOptionalLanes_*`，Finish 先查 done 再判 deadline 已实测对齐 asyncio.wait）
- **本偏差经用户 2026-11-27 确认**。
