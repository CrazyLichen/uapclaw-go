## 3. 修订一：docker/wsl 调用不抽架构接口缝（改 plan Task 11 Step 1）

**原 plan 写法**：「docker/wsl 调用统一走注入的 command runner 接口缝」——**作废**。

**定案（方案 γ）**：Python 原文两个 runtime 均直接 `subprocess.run`（swebench_runtime.py:810、terminal_bench_runtime.py:149/177），测试用 monkeypatch 替换。Go 对齐口径：

- 直接 `exec.Command`，不加 command runner 接口；
- 测试等价物：包级函数变量（如 `var swebenchExec = exec.Command` / terminal_bench 同款，对齐 Python monkeypatch `subprocess.run` 的注入点语义），仅 `_test.go` 替换；
- 该函数变量是测试惯用手法，**不登记为架构偏差**、不进反转缝清单。
