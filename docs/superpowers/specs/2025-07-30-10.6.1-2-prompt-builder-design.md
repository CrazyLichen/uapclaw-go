# 10.6.1-2 Prompt Builder 设计

## 概述

实现 10.6.1-2 Prompt Builder，对齐 Python 的 `jiuwenswarm/agents/harness/` 目录结构，
在 Go 的 swarm 层新建 `common/prompt/` 和 `code/prompt/` 两个包，分别承载
Agent 模式和 Code 模式的 prompt 构建逻辑。

### 在 Agent 会话中的流程位置

```
用户请求 → Gateway → E2A → AgentServer
                         ↓
                    DeepAdapter.CreateInstance()
                         ↓
                    ┌──────────────────────────────────────────────┐
                    │  步骤 19: create_deep_agent(...)             │
                    │  system_prompt = BuildXxxPrompt()  ← 本次实现 │
                    └──────────────────────────────────────────────┘
                         ↓
                    DeepAgent 初始化 (system_prompt 作为第一条 SystemMessage)
                         ↓
                    ReAct Loop (Configure → Invoke → ...)
                         ↓
                    Rails 动态注入额外 sections (10.6.3-10)
```

**作用**：Prompt Builder 是 Agent 的"灵魂"——在 Agent 创建时构建系统提示词，
决定 LLM 的行为模式。Agent 模式和 Code 模式产出不同的系统提示词，
决定了 Agent 的身份认知、行为规范、工具使用方式等核心行为。

### Python → Go 目录对齐

Python 的 `jiuwenswarm/agents/harness/` 是 jiuwenswarm 层对 harness 的扩展，
与 agent-core 层（`openjiuwen/harness/prompts/sections/`）是不同层级：

| 层级 | Python 路径 | Go 路径 | 性质 |
|------|------------|---------|------|
| agent-core | `openjiuwen/harness/prompts/sections/` | `agentcore/harness/prompts/sections/` | 通用 section 砖块（纯数据） |
| jiuwenswarm | `jiuwenswarm/agents/harness/common/prompt/` | `swarm/agents/harness/common/prompt/` | Agent 模式 prompt 图纸 |
| jiuwenswarm | `jiuwenswarm/agents/harness/code/prompt/` | `swarm/agents/harness/code/prompt/` | Code 模式 prompt 图纸 |

**关键区别**：agent-core 层是"砖块"（16 个通用 section builder），
jiuwenswarm 层是"图纸"（决定用哪些砖块、怎么组合、什么模式）。

## 详细设计

### 1. `swarm/agents/harness/common/prompt/prompt_builder.go`

对齐 Python：`jiuwenswarm/agents/harness/common/prompt/prompt_builder.py`

#### 常量

```go
// responsePriority 响应节优先级
// 对齐 Python: PromptPriority.RESPONSE = 60
const responsePriority = 60
```

#### 导出函数

**`BuildResponseSection(language string) saprompt.PromptSection`**

对齐 Python：`_response_prompt(language)` (prompt_builder.py L36-105)

- 入参 `language`：`"cn"` 或 `"en"`
- 返回中/英双语消息格式说明 section
- 内容：描述用户消息（channel + preferred_response_language + content + source）和系统消息（type: cron/heartbeat/notify）的 JSON 格式
- Section name：`sections.SectionResponse`（新增常量 `"response"`）
- Priority：60

**`BuildAgentIdentityPrompt(language string) string`**

对齐 Python：`build_agent_identity_prompt(language)` (prompt_builder.py L248-259)

从 `deep_adapter.go:1937` 迁入，逻辑不变：

1. `prompts.ResolveLanguage(language)` 解析语言
2. `prompts.NewSystemPromptBuilder(resolvedLanguage, hschema.PromptModeNone)` 创建 builder
3. `builder.AddSection(sections.BuildIdentitySection())` 添加身份节
4. `return builder.Build()` 构建并返回

#### 非导出函数

**`readWorkspaceFile(filePath string) string`**

对齐 Python：`_read_file(file_path)` (prompt_builder.py L265-281)

- 读取工作空间文件内容
- 文件不存在或读取失败返回空字符串
- 当前 `BuildAgentIdentityPrompt()` 未使用此函数，但为与 Python 对齐保留

#### 8 个 section builder 函数

每个函数返回 `saprompt.PromptSection`，内容为英文（`"en"` 键），对齐 Python 的 8 个
`_code_xxx_prompt()` 函数。

| Go 函数 | Python 函数 | Section Name | Priority |
|---------|------------|--------------|----------|
| `BuildCodeIntroSection()` | `_code_intro_prompt()` | `"code_intro"` | 10 |
| `BuildCodeSystemSection()` | `_code_system_prompt()` | `"code_system"` | 15 |
| `BuildCodeDoingTasksSection()` | `_code_doing_tasks_prompt()` | `"code_doing_tasks"` | 25 |
| `BuildCodeUsingYourToolsSection()` | `_code_using_your_tools_prompt()` | `"code_using_your_tools"` | 31 |
| `BuildCodeActionsWithCareSection()` | `_code_actions_with_care_prompt()` | `"code_actions_with_care"` | 35 |
| `BuildCodeToneAndStyleSection()` | `_code_tone_and_style_prompt()` | `"code_tone_and_style"` | 45 |
| `BuildCodeOutputEfficiencySection()` | `_code_output_efficiency_prompt()` | `"code_output_efficiency"` | 50 |
| `BuildCodeSessionGuidanceSection()` | `_code_session_guidance_prompt()` | `"code_session_guidance"` | 55 |

#### 入口函数

**`BuildCodeSystemPrompt() string`**

对齐 Python：`build_code_system_prompt()` (code_prompt_builder.py L615-626)

```go
func BuildCodeSystemPrompt() string {
    builder := prompts.NewSystemPromptBuilder("en", hschema.PromptModeFull)
    builder.AddSection(BuildCodeIntroSection())
    builder.AddSection(BuildCodeSystemSection())
    builder.AddSection(BuildCodeDoingTasksSection())
    builder.AddSection(BuildCodeUsingYourToolsSection())
    builder.AddSection(BuildCodeActionsWithCareSection())
    builder.AddSection(BuildCodeToneAndStyleSection())
    builder.AddSection(BuildCodeOutputEfficiencySection())
    builder.AddSection(BuildCodeSessionGuidanceSection())
    return builder.Build()
}
```

## 风险与注意

1. **循环依赖**：`swarm/agents/harness/common/prompt/` 依赖 `agentcore/harness/prompts/sections/` 和 `agentcore/harness/prompts/`，这些是 agent-core 层，方向正确（swarm → agentcore）。反向不会有依赖。
2. **coding_memory.go 不动**：Python 中 `coding_memory.py` 在 `openjiuwen/harness/prompts/sections/`（agent-core 层），Go 中 `coding_memory.go` 在 `agentcore/harness/prompts/sections/`，位置正确。
3. **ResponsePromptRail 不在本次范围**：`BuildResponseSection()` 只提供数据，Rail 的运行时注入逻辑留给 10.6.3-10。
4. **提示词文本严格对齐**：Code 模式 8 个 section 的英文文本必须逐行对齐 Python `code_prompt_builder.py`，不能遗漏或修改。
