## 第一部分：ContextEvolutionRail 差异修复

### S-01：retrieval_query 逻辑

**问题**：Python 优先用 `retrieval_query` 做检索和缓存键，Go 只用 `query`。

**修复**：

1. `TaskIterationInputs`（`internal/agentcore/single_agent/interfaces/callback.go`）加字段：
```go
type TaskIterationInputs struct {
    // ... 现有字段 ...
    // RetrievalQuery 检索用查询（优先于 Query）
    // 对齐 Python: retrieval_query = getattr(ctx.inputs, "retrieval_query", None) or query
    RetrievalQuery string
}
```

2. `beforeTaskIteration`（`context_evolution_rail.go`）修改检索键逻辑：
```go
retrievalQuery := taskInputs.Query
if taskInputs.RetrievalQuery != "" {
    retrievalQuery = taskInputs.RetrievalQuery
}
// 缓存键和 Retrieve 调用均使用 retrievalQuery
```

**影响范围**：`TaskIterationInputs` 定义、`beforeTaskIteration` 方法、`ContextEvolvingReActAgent.Execute()` 中已传 `retrieval_query` 到 inputs map 但 `TaskIterationInputs` 未读取 — 需确保上游赋值到新字段。

### S-02：memories_used 标注目标

**问题**：Python 写 `result["memories_used"]`，Go 写 `cbc.Extra()["memories_used"]`。

**修复**：`afterTaskIteration` 中：

```go
// 对齐 Python: result["memories_used"] = self.memories_used
inputs := cbc.Inputs()
if taskInputs, ok := inputs.(*agentinterfaces.TaskIterationInputs); ok && taskInputs.Result != nil {
    taskInputs.Result["memories_used"] = r.memoriesUsed
}
// 删除 cbc.Extra()["memories_used"] = r.memoriesUsed
```

### S-03：LoadMemories context 传递

**问题**：构造时 `context.Background()` 丢弃调用方 context。

**修复**：签名改为 `NewContextEvolutionRail(ctx context.Context, userID string, memoryService *ceservice.TaskMemoryService, opts ...ContextEvolutionRailOption)`，`LoadMemories` 用传入的 `ctx`。

### M-02：auto_summarize_matts_mode 限制

**问题**：硬编码 `"none"` 但未检查配置值。

**修复**：`afterTaskIteration` 中 auto_summarize 条件改为：
```go
if r.autoSummarize && r.autoSummarizeMattsMode == "none" && r.currentQuery != "" && r.memoryService != nil {
    // ... 现有逻辑 ...
} else if r.autoSummarize && r.autoSummarizeMattsMode != "none" {
    logger.Warn(logComponent).Str("matts_mode", r.autoSummarizeMattsMode).Msg("auto_summarize 仅支持 matts_mode=none，跳过")
}
```

### T-01：注入后 content strip

**问题**：拼接后未做 `.strip()`。

**修复**：
```go
import "strings"
// ...
newMsg["content"] = strings.TrimSpace(content + "\n\n" + memoryBlock)
```

### T-02：WithUserID 选项

**修复**：新增选项函数：

## 第二部分：Session Memory 集成回填

### 概述

对齐 Python `ContextProcessorRail` 中的 session memory 调度逻辑。Session memory 的**内容注入**在 `FullCompactProcessor` 层面（已实现），Rail 层只负责**调度触发**（检查 token 阈值 + 启动后台更新任务）。

### SM-01：WithSessionMemoryConfig 选项

**修复**：新增选项函数，支持传入 `SessionMemoryConfig` 或 `map[string]any`：

```go
// WithSessionMemoryConfig 设置会话记忆配置
// 对齐 Python: ContextProcessorRail(session_memory=SessionMemoryConfig(...)) 或 session_memory={...}
func WithSessionMemoryConfig(config *cecontext.SessionMemoryConfig) ContextProcessorRailOption {
    return func(r *ContextProcessorRail) {
        r.sessionMemoryEnabled = config != nil
        r.sessionMemoryConfig = config
    }
}
```

构造函数中根据 `sessionMemoryConfig` 创建 `SessionMemoryManager`：
```go
if r.sessionMemoryConfig != nil {
    r.sessionMemoryMgr = cecontext.NewSessionMemoryManager(*r.sessionMemoryConfig)
}
```

### SM-02：Init 中 BindModelDefaults

**修复**：在 `ContextProcessorRail.Init` 末尾添加：

```go
// 对齐 Python: if self._session_memory_config is not None:
//     self._session_memory_config.set_model_defaults(model_config, model_client_config)
//     self._session_memory_mgr.bind_model_defaults(model_config, model_client_config)
```

### SM-03：AfterModelCall 中 session memory 调度

**修复**：在 `ContextProcessorRail.AfterModelCall` 末尾添加：

```go
// 对齐 Python: if self._session_memory_mgr is not None:
//     self._session_memory_mgr.update_inherited_system_prompt(ctx)
if r.sessionMemoryMgr != nil {
    // UpdateInheritedSystemPrompt 接受 []BaseMessage
    // 从 agent 的 context engine 获取消息列表
    messages := r.getMessagesFromAgent(cbc)
    r.sessionMemoryMgr.UpdateInheritedSystemPrompt(messages)
}

// 对齐 Python: await self._maybe_schedule_session_memory_update(ctx)
if r.sessionMemoryEnabled && r.sessionMemoryMgr != nil {
    deepAgent, ok := cbc.Agent().(hinterfaces.DeepAgentInterface)
    if ok && deepAgent != nil {
        reactAgent := deepAgent.ReactAgent()
        if reactAgent != nil {

                mc := ce.GetContext("default_context_id", sess.GetSessionID())
                if mc != nil {
                    workspaceDir := "" // 从 agent 或 workspace 获取
                    r.sessionMemoryMgr.MaybeScheduleUpdate(ctx, sess, mc, workspaceDir)
                }
            }
        }
    }
}
```

```python
class TeamSkillCreateRail(EvolutionRail):

    Trigger mode: threshold detection in after_task_iteration →

                 min_team_members_for_create=2, trajectory_store=None):

                         evolution_trigger=EvolutionTriggerPoint.NONE)
        self._skills_dir = skills_dir
        self._auto_trigger = auto_trigger
        self._min_team_members = min_team_members_for_create
```

### RA-04：findTeamSkillRail() 查找

**修复**：实现从 `instance.rails` 中查找的逻辑：

```go
func (d *DeepAdapter) findTeamSkillRail() *evolution.TeamSkillEvolutionRail {
    if d.teamSkillEvolutionRail != nil {
        return d.teamSkillEvolutionRail
    }
    // 对齐 Python: harness.find_rails(TeamSkillEvolutionRail)
    if d.instance != nil {
        for _, rail := range d.instance.Rails() {

                d.teamSkillEvolutionRail = tsr
                return tsr
            }
        }
    }
    return nil
}
```
