## 4. 行为规格

### 4.1 ToolComponent 构造期

```
tool_id 非 None → tool = runner.GetResourceMgr().GetTool([]string{tool_id})
tool_id 为 None → tool = nil（等 BindTool 编程式绑定）
```

### 4.2 ToExecutableFn（Python to_executable，槽优先单点）

```
tool == nil → 102002（COMPONENT_TOOL_INIT_FAILED, "tool component not bind a valid tool"）
否则 → 构造 ToolExecutable（config 注入 + set_tool）
```

### 4.3 ToolExecutable.invoke 五步链（invoke 方法体，顺序不改）

1. `tool == nil` → 102000（COMPONENT_TOOL_EXECUTION_ERROR，"tool is not initialized"）
2. `validateInputs(inputs)`：非 map → 102001（错误信息含 pydantic 校验格式化等价物）
3. `tool.Invoke(ctx, toolInputs, WithSkipInputsValidate(false), WithSkipNoneValue(true))`
4. 错误吞没：`errors.As` BaseError → 取其 Code/Message；否则 182012，msg = `"tool execution error, too card={card}, reason={reason}"`（reason=str(e)，nil e → "unknown exception"）→ response = `{errMessage: msg, errCode: code}`
5. `postProcessToolResult(response)` → `createOutput` → 返回 map

### 4.4 postProcessToolResult 三分支（顺序不改）

1. **RestfulApi 分支**（类型断言 `*restfulapi.RestfulApi`）：
   - `data = result["data"]`（缺省 ""）
   - `code` int 化（int64/float64/int/string 数字均转；失败回 -1）
   - `errCode = SUCCESS.code if 200 ≤ code < 300 else 182012.code`
   - `errMessage = result["message"]`（缺省 ""）
2. **普通 Tool 且 result 为 map 且含 code/data/message 三键**：`data/code/message` 透传（code 缺省 182012.code）
3. **其余**：整个 result 塞进 `data`（errCode/errMessage 取信封零值——注意此处 Python 语义为 result 不带 code/message 键时 `result[ERR_CODE]` 不存在，createOutput 用 ToolComponentOutput 默认值兜：0/""）

### 4.5 输出键（D-21-1）

出参 map 键恒为 `errCode/errMessage/data`（驼峰）。**偏差**：Python `model_dump()` 默认 by_alias=False 出蛇形 `error_code/error_message/data`；Go 统一出驼峰，入出一致。下游消费键以驼峰为准。
