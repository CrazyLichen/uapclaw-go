## 1. 流程位置与作用

15.21 是 swarm 平台 provider 装配链的最后缺口。一次团队会话：

```
团队创建 → enrich（15.16c/e）→ RegisterSwarmProviders（15.16f）
  → 按 SwarmBuildContext 角色（leader/teammate）解析 provider 清单
      → 成员 DeepAgent 装配 → rails 目录挂载（… evolution_rails ← 本节）
  → 会话运行：成员调 evolve_skill_experiences / simplify_skill_experiences
      → EvolutionInterruptRail 审批中断 → EvolutionReviewRuntime 审查 → 写技能库
```

Provider（此处指 swarm providers 工厂层，非 harness transport provider）签名统一
`f(params, ctx) → rail | []rail | nil`：params 为 spec 侧可序列化配置（源 =
config.yaml，经 config_specs 抽取；禁止塞运行期值），ctx = SwarmBuildContext
（session/channel/路径/轨迹处理器等运行期值）。三 rail 子类覆盖 `init(agent)`，
在挂载时向 TeamManager 补做 legacy customizer 的注册记账（live-rail、审批/同步
目标、热重载上下文）。
