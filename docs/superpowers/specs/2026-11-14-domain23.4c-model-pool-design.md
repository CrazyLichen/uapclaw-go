## 12. 实施补充（2026-11-14 实施期登记）

### 12.1 新增偏差 D-7（llm_route 流桥的会话注入）

Python `write_llm_route`（model.py:30-56）经框架 `register_sync` 全局注册一次，session 由 contextvar `get_current_session()` 注入。Go 无 contextvar，等价改为：**每次模型调用临时注册 OnCustom(LLMRoute) 处理器**（`react_model_call.go` 的 `writeLLMRouteDuring`，闭包捕获 sess），处理器体一比一复刻 write_llm_route（payload 拷贝 + result_type 兜底 answer + OutputSchema{llm_route, index:0}，session nil 跳过）。触发时机（路由器选路时同步触发、调用同 goroutine）与 chunk 形状不变；注册位置与注入方式偏差。回收条件：Go 引入会话上下文注入机制后改回全局注册。
