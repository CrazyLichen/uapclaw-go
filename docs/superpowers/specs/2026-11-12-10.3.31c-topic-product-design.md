## 1. 流程位置与作用

主动推荐链路：

```
agent 会话（空闲 / 轮次收口）
  └→ proactive_engine.tick（10.3.31a，已交付）
       └→ situation_report + calendar_source + profile_extractor
            └→ 10.3.31b topic 流水线（topic_pipeline 9704 行：prepare → retrieval →
                collector → generation → selection）
                 └→ ★ 10.3.31c「topic 产物与呈现」★
                      └→ recommendation_host / recommendation_rpc → web 前端推送
                           └→ 用户曝光 / 点击 / 反馈
                                └→ topic_outcomes 记账 → gradient_updater 学习闭环
```

31b 负责"算出候选"；**31c 负责"把候选变成可推送、可审计、可回执的卡片产物"**——契约、校验、状态落库、曝光选卡与回执记账，是流水线与前端呈现之间的契约层。

```

                    │   └─ write_terminal_pool → 整池落库
                    ▼
        TopicStarterStore（10.7.1 已有，recommendation.db）

                    │      └─ topic_outcomes：曝光事件落库 → 推给前端
                    ▼
```

## 6. 错误与校验策略

1. **校验矩阵 fail-closed**：`xxxRejectionReason(...)` 系列返回 string（空串=通过），逐条映射上游拒绝原因；任何一环拒绝 → 整池不入库。
2. **卡片 copy 校验**：title ≤60 字、prompt ≤180 字；`_COPY_MARKUP_OR_LIST_RE` / `_COPY_LABEL_RE` 两条正则 RE2 等价改写（仓库已有手写等价先例：`不错(?!过)` / `(?<!…)我来`）。
3. **RID 契约**：输入硬校验（不同 session、同 scope、`later.completed_at > earlier.completed_at`）违反即 error；输出 `{"label"}` 单键、非法即 error；缓存命中即返回；**落库失败回读缓存比对不一致必须报错**；provider 拒绝类错误 → 本轮剩余配对全部拒绝（`summary_pair_matcher_refused`）。
4. **审计器**：manifest 声明计数与 audit snapshot 对不上 → 拒绝；attempt/receipt 180 条环形上限照抄。
5. **模型适配器**：thinking 关闭 extra_body 固定注入；schema 校验 fail-closed；未消费回执上限 64（有界实现）；aclose 清理。
6. **新闻缺席语义**：5 种 absent_reason（`hot_list_unavailable`/`hot_news_matcher_failed`/`news_utility_rejected`/`news_dismissed`/`optional_lane_timeout`）常量照抄 + 槽位留痕；缺席不拒池，补位降级；仅历史兴趣完全蒸馏不出时降级 `news_only` 池（`NEWS_ONLY_SUCCESSOR`）。
7. **日志（规则 3）**：每个校验拒绝点、HTTP 失败点、落库失败点补结构化日志，`event_type` 字段对齐 Python，异常路径 `.Err(err)`；组件常量取值对齐 31a recommendation 侧既有用法。
8. **协议字符串不得本地化**：schema 版本常量、absent_reason、rejection reason 逐字照抄 Python。

## 7. 池组成契约（大白话已与用户对齐）

- 渠道：①新闻热搜（可缺席的第 1 槽）②历史兴趣（RID 标签排序）③短时意图 ④内置语料。
- GLOBAL 池配额（`_GLOBAL_COMPOSITION`）：`profile_recent_progress` 3 + `adjacent_explanation` 2 + `broad_timely_practical` 2 + `profile_interest_continuation` 填满剩余。
- PROJECT 池配额（`_PROJECT_COMPOSITION`）：`project_continuation` 3 + `project_domain_progress` 1。
- 配额不符 → 整池拒绝（`_valid_pool_composition`）。
- 兜底链：RID 蒸馏不出 trigger_interests 且非 news_only → 整池拒绝（`topic_product.py:1284` 语义）。
