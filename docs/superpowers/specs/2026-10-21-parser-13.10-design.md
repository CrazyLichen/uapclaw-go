## 1. 背景与定位

Parser 是文档索引管线的第一站：把外部世界（文件路径/URL）转成统一 `Document` 抽象，交给 Chunker 分块。Python `base.py` 定义 `Parser(Processor)` 模板方法基类：公开入口 `parse` 调子类覆写的 `_parse` 得字符串，非空则包装单个 `Document` 返回，空则返回空列表。

Agent 会话流程位置（仅入库期被调用，不在会话主链路）：

```
【入库管线】文件/链接 → Parser.Parse（★ 13.10 本体：管线第一站）
  → KnowledgeBase.parse_files/parse_urls（Python 消费方，Go 属后续 KB 层章节未排期）
  → Chunker.ChunkDocuments（13.5-13.9 ✅）
  → ComputeChunkEmbeddings（13.4 ✅；isImageChunk 消费 image_path 元数据，
      生产方是 13.15 ImageParser，当前测试手工构造 metadata，非回填债务）
  → Chroma/Milvus Indexer.BuildIndex（13.2/13.3 ✅）

【查询管线】agent 会话内 KnowledgeRetrievalComp（8.25 ☐）→ retrieve → rerank → 注入 prompt
  （查询路径不经过 Parser，检索粒度由入库解析质量决定）
```

Python 侧消费方为 `knowledge_base.py`/`simple_knowledge_base.py`/`graph_knowledge_base.py` 三处（后续章节）；`lazy_parse` 在 Python 生产代码**零调用**（仅基类默认实现逐个 yield）。processor 目录共 15 文件 1623 行，本节只做 base.py（62 行）。

## 4. 类型与接口设计（base.go）

```go
// Parser 文档解析抽象接口。
// 四方法对齐 Python parse/lazy_parse/process/supports。
type Parser interface {
    // Parse 解析文档源（文件路径/URL），返回 Document 列表。
    Parse(ctx context.Context, doc string, opts ...ParseOption) ([]reranker.Document, error)
    // LazyParse 惰性解析：完整 Parse 后逐个回调 fn（对齐 Python 默认实现）。
    LazyParse(ctx context.Context, doc string, fn func(reranker.Document) error, opts ...ParseOption) error
    // Process 处理文档（Processor 契约兼容），转发 Parse。
    Process(ctx context.Context, doc string, opts ...ParseOption) ([]reranker.Document, error)
    // Supports 检查是否支持该文档源。
    Supports(doc string) bool
    // ParseContent 子类覆写点（对齐 Python _parse(file_path, llm_client)）。
    // 必须进接口：BaseParser 模板方法经 b.self 动态派发此方法（13.5 chunkTextOf 同款机制）。
    // 注意不收 Extra：Python **kwargs 在基类 parse 被接收但丢弃，
    // Extra 只留给覆写 Parse 的子类（如 13.11 AutoParser）。
    // BaseParser 默认返回 ("", nil) —— 对齐 Python 基类 _parse 的 `pass` → None → parse 返回 []
    ParseContent(ctx context.Context, doc string, llmClient *llm.Model) (string, error)
}

// ParseOptions 收纳 Python parse 的三个可选参数。
type ParseOptions struct {
    // DocID 文档 ID（Python doc_id；未设置时 Document.ID 保持空串）
    DocID string
    // LLMClient 可选 LLM 客户端（Python llm_client；13.15 Captioner 消费）
    LLMClient *llm.Model
    // Extra 额外参数（Python **kwargs；13.11 AutoFileParser 消费 file_name 等）
    Extra map[string]any
}

// BaseParser 解析器默认适配器（模板方法）。
// 子类嵌入 + 构造注入 self + 覆写 ParseContent。
type BaseParser struct {
    // self 完整 Parser 引用，使模板方法路由到子类覆写的 ParseContent
    self Parser
}

// NewBaseParser 构造并注入 self；self 为 nil 时返回 fmt.Errorf 编程期防御错误
// （编译期约束无法覆盖显式传 nil，对齐 13.8 NewHybridChunker 的 inner nil 防御先例；
// 非 155xxx 业务错误码——155103/155104 是文件未找到/格式不支持语义，不适合 self 为 nil）
func NewBaseParser(self Parser) (*BaseParser, error)
```

### 4.1 模板方法行为

```go
// Parse 默认实现：
//   content, err := b.self.ParseContent(ctx, doc, o.LLMClient)
//   err 非 nil → return nil, err              （决策 4：err 传播）
//   content != "" → 单文档包装：
//       reranker.Document{ID: o.DocID, Text: content, Metadata: map[string]any{}}
//       （Metadata 显式空 map 非 nil，对齐 Python metadata={} 的 default_factory）
//   content == "" → 空切片（对齐 Python if content: truthiness）
func (b *BaseParser) Parse(ctx context.Context, doc string, opts ...ParseOption) ([]reranker.Document, error)

// LazyParse 默认实现：
//   先完整 Parse（对齐 Python "parse 完再逐个 yield"，非流式），再逐个回调 fn；
//   fn 返回 error → 提前终止并原样返回该 error（filepath.Walk 惯例）
func (b *BaseParser) LazyParse(ctx context.Context, doc string, fn func(reranker.Document) error, opts ...ParseOption) error

// Process 默认实现：转发 Parse（Processor 契约兼容）
func (b *BaseParser) Process(ctx context.Context, doc string, opts ...ParseOption) ([]reranker.Document, error)

// Supports 默认实现：返回 false（对齐 Python 基类）
func (b *BaseParser) Supports(doc string) bool

// ParseContent 覆写点（对齐 Python _parse(file_path, llm_client)）。
// 默认返回 ("", nil) —— 对齐 Python 基类 _parse 的 `pass` → None → parse 返回 []
// 已上移至 Parser 接口第五方法（见第 4 节接口定义）。
func (b *BaseParser) ParseContent(ctx context.Context, doc string, llmClient *llm.Model) (string, error)
```

**关键机制**：Parse/LazyParse 经 `b.self` 动态派发 ParseContent——Go 嵌入方法遮蔽是静态绑定，子类同名方法必须经接口路由才能被模板方法看到（13.5 chunkTextOf 同款问题同款解法）。

### 4.2 Python→Go 语义对齐表

| Python | Go | 边界语义 |
|---|---|---|
| `parse` 空内容→`[]` | Parse `""`→空切片 | truthiness 统一为空串 |
| `Document(id_=doc_id, text=content, metadata={})` | `Document{ID, Text, Metadata: map[string]any{}}` | Metadata 显式空 map 非 nil；ID 字面保持（决策 6） |
| `lazy_parse` parse 完再 yield | LazyParse 先 Parse 再逐个回调 | 非流式（名字 lazy 行为非 lazy，忠实对齐） |
| `_parse: pass` → None | ParseContent 默认 `("", nil)` | BaseParser standalone 可直接实例化测试 |
| `supports` 默认 False | Supports 默认 false | 13.11 Auto 三件套覆写 |
| `process` 转发 parse | Process 转发 Parse | — |
| 子类软失败 `except → return None` | 子类自行返回 `("", nil)` | 决策 4：base 不吞 err，软失败语义归子类 |
