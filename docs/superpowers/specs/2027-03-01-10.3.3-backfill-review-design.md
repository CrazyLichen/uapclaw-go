# 10.3.3 AgentAdapter 回填审查与修正设计

## 背景

10.3.3 章节（AgentAdapter 接口与工厂）及相关适配器代码中存在大量 ⤵️ 标记，
标注了等待其他章节实现后回填的代码位置。经过全量审查，发现部分 ⤵️ 标记已过时
（对应功能已实现），以及 CodeAdapter.CreateInstance 步骤 14-20 缺失导致
CodeAdapter 无法正常工作。

## 修改分类

### A. CodeAdapter.CreateInstance 步骤 14-20 回填

**问题**：CodeAdapter.CreateInstance 只实现了步骤 1-13 和 21-24，
中间的步骤 14-20（AgentCard → ToolCards → Rails → Subagents →
CreateDeepAgent → EnsureInitialized）全部跳过，导致 c.deep.instance == nil。

**方案**：对齐 Python JiuwenClawCodeAdapter.create_instance() 的完整重写模式，
在 CodeAdapter.CreateInstance 中直接实现步骤 14-20。

**步骤 14-20 具体实现**：

| 步骤 | Python | Go 实现 |
|------|--------|---------|
| 14 | AgentCard(name=agent_name, id='jiuwenswarm') | agentschema.NewAgentCard() |
| 15 | _get_tool_cards(agent_card.id) | c.deep.getToolCards() |
| 16 | _build_agent_rails(config, configBase, mode="code") | c.buildCodeAgentRails()（完全重写） |
| 17 | _create_sys_operation() | c.deep.createSysOperation() |
| 18 | _build_configured_subagents(model, config, configBase) | c.deep.buildConfiguredSubagents() |
| 19 | create_deep_agent(...) | harness.CreateDeepAgent()（code 模式参数差异） |
| 20 | ensure_initialized() | d.instance.EnsureInitialized() |

**步骤 19 参数差异**（code 模式不传）：

| 参数 | DeepAdapter | CodeAdapter |

**步骤 21 额外（code 专有）**：

- coding_memory workspace set_directory → ⤵️ 10.6.3-10
- _jiuwenswarm_adapter_mode = "code" → ⤵️ 10.6.3-10
- agent_history 写入路径修正 → ⤵️ 10.6.3-10

**步骤 24 修正**：MCP tag 从 "agent.{mode}" 改为 "code"。
