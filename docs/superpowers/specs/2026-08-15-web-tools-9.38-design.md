# WebTool 工具集实现设计

## 概述

在 `internal/agentcore/harness/tools/web_tools/` 下完整复刻 Python `openjiuwen/harness/tools/web_tools.py`，实现 3 个联网搜索/抓取工具（WebFreeSearchTool、WebPaidSearchTool、WebFetchWebpageTool），并回填代码中 5 个因 WebTool 未实现而标注 ⤵️ 的回填点。

## 在 Agent 会话流程中的位置

```
用户输入 → Controller(IntentRecognizer) → LLM决策 → 选择工具
                                                 ↓
                                          ┌──────────────┐
                                          │  free_search  │ ← WebFreeSearchTool（DDG/Bing）
                                          │  paid_search  │ ← WebPaidSearchTool（Bocha/Perplexity/Serper/Jina）
                                          │  fetch_webpage│ ← WebFetchWebpageTool（网页正文提取）
                                          └──────────────┘
                                                 ↓
                                          搜索/抓取结果 → LLM总结 → 回复
```

WebTool 提供 Agent 对外获取信息的「搜索→抓取→阅读」链路，是 DeepAgent、BrowserAgent 的核心能力。

**注意**：`search_tools`（工具发现）和 `load_tool`（工具加载）是不同的概念——它们搜索的是 Agent 自身可用的工具，不涉及联网。

## 工具实现模式

每个工具遵循项目已有模式（与 `code.go`、`vision.go` 一致）：

1. 定义 typed input struct
2. 调用 `hprompts.BuildToolCard()` 获取元数据卡片
3. 用 `tool.NewTool(fn, ...)` 包装为 `tool.Tool` 接口
4. `Stream()` 返回 `ErrStreamNotSupported`（Python 三个工具都不支持流式）

```go
// free_search.go
type FreeSearchInput struct {
    Query          string `json:"query"`
    MaxResults     int    `json:"max_results"`
    TimeoutSeconds int    `json:"timeout_seconds"`
}

func NewWebFreeSearchTool(language, agentID string) tool.Tool {
    card, _ := hprompts.BuildToolCard("free_search", "WebFreeSearchTool", language, nil, agentID)
    fn := func(ctx context.Context, input FreeSearchInput, opts ...tool.ToolOption) (map[string]any, error) {
        // ... 搜索逻辑 ...
        return map[string]any{"result": resultText}, nil
    }
    invokeFn, _ := tool.NewTool(fn, tool.WithToolCard(card), tool.WithToolInputParams(card.InputParams))
    return invokeFn
}
```
