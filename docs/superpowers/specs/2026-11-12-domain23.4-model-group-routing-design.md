## 1. 背景与流程位置

23.4 不在 agent 单轮 ReAct 循环内，位于 **agent 启动前的「选哪个模型可用」前置链**，三个调用点共用：

```
① 网关建会话/发消息   gateway/common/model_routing_registry.py（ModelSelectionResolver.resolve）
② 团队成员分配       agent_teams/models/{pool,allocator}.py（模型池摊分）
③ 定时任务           cron_job_mutations.py 显式拒绝 model_group（Go 已对齐 ✅）
        ↓ 共同产出
   ResolvedModel / ResolvedModelGroup（纯 DTO）
        ↓
   core/foundation/llm/routing/compiler.py（CompileModelSelection / GetModelGroupModels）
        ↓
   ModelClientConfig{client_provider=intelli_router, intelli_router=IntelliRouterConfig}
        ↓
   IntelliRouterModelClient → intelli_router.ReliableRouter（进程内路由器）
        失败 → intelli_router_errors.ToModelError() 四分类 → 重试 rail / 上下文恢复 / 用户报错
```

**作用**：①选择→编译（组编译成 IntelliRouter 客户端配置：策略 ordered-failover/tag-filtered、重试预算、超时、健康检查、可观测）；②no-routing 短路（组未配 strategy 则取第一条启用路由当普通模型）；③context_window 取启用路由最小值；④reasoning 编译期展开（复用 23.3 的 reasoning plan）；⑤失败四分类决定上层重试/缩请求/报人。

**文件级映射**（PyPI wheel → Go，逐文件对应）：

**关键设计决策**：

1. **冷却状态机逐行对齐**：退避公式 `cooldown_time × consecutive_failures`、成功清零、`ResetDeployment` 同时清冷却与计数（错误翻译层 `_release_cooldown` 即调此）。asyncio 单线程 → Go 并发：`sync.Mutex` 保护 map，指针接收者。
2. **router 缓存保留**（`_get_or_create_router` + md5 config key + 锁内 double-check）：同配置共享冷却状态，否则同组多客户端各持一套冷却计数，failover 行为漂移。**loop 绑定防御（`_RouterCacheEntry.loop` / `_ensure_router_for_current_loop`）Go 无对应物**（net/http.Client 天然并发安全）→ 偏差登记。
3. **流式 fallback 边界**：`_is_fallbackable_error(error, visible_output_started)`——流式已吐可见内容后不再换 deployment，必须带 visibleOutputStarted 参数逐行对齐。

## 6. 23.4b 客户端包装 + 失败四分类 + routing 编译器

**① schema/config.go 增量**：`IntelliRouterDeploymentConfig`（14 字段）+ `IntelliRouterConfig`（model_group_id/deployments/strategy/strategy_kwargs/num_retries/timeout/enable_health_check/health_check_interval/enable_observability/web_dashboard_port/router_scope）；`ModelClientConfig` 挂 `IntelliRouter` 字段。

**② `routing/` 包**：
- `schema.go` ← schema.py：ModelSelection/ResolvedModel/ResolvedRoute/ResolvedRoutingConfig/ResolvedModelGroup/CompiledModelSelection + RoutingStrategyName 枚举（两种）
- `compiler.go` ← compiler.py：CompileModelSelection（map 形参 JSON round-trip 归一，对齐 pydantic validate）+ GetModelGroupModels。五个关键步骤逐行对齐：no-routing 短路；num_retries 缺省 = len(deployments)-1；_min_context_window（跳 bool、取正 int 最小）；_apply_reasoning_controls（pop reasoning → 调 23.3 reasoning.ResolveReasoningPlan/ApplyReasoningPlan，anthropic 强制补 api_mode）；_flatten_extra_body
- `errors.go` ← intelli_router_errors.py：失败四分类（switchable=181001；三种 exhausted 共用 181010）；全局 RouteFailure 记录（键 `model_group_id|deployment_id`，带锁）；RecordRoutingEvent / ToModelError；details 是前端契约字符串不本地化
- provider 归一映射 `_ROUTER_PROVIDER_BY_CORE_PROVIDER`（7 条）+ `_ROUTER_PROVIDER_BY_ENDPOINT_PROFILE`（11 条），对齐 23.3 endpointprofiles

**③ `model_clients/intellirouter/` 包**：
- IntelliRouterModelClient 实现 BaseModelClient，注册 `model_clients_register.go`（`__client_name__="intelli_router"`）
- router 缓存（md5 key）；loop 绑定防御不移植（§5 偏差）
- **路由模型命名**：routed_model_label/has_routed_model_placeholder/fill_routed_model——提示词 `{routed_model}` 占位符按选中 deployment 回填；`_RoutedModelAdapter`/`_routed_model_router_class` 动态类型继承在 Go 无对应 → **函数指针注入**（构造期 transform 钩子，非 embedding 覆盖）
- Invoke/Stream + `_to_ow_assistant_message`/`_to_ow_chunk`/`_to_ow_usage_metadata`（reasoning_tokens 入 usage）
- 多模态生成三件套 `_generate_image/speech/video_dashscope`（DashScope 端点直调）全量移植
- `_CoreRoutingEventBridge`：路由器事件总线 → core 回调框架（`_log_route_failover` 日志字段逐条对齐）

**测试**：上游 `test_model_group_routing_compiler.py`（12 例）+ intelli_router errors + routed model 三文件逐用例对齐；集成用 httptest 起三个假上游验证真 failover + 冷却 + switchable→重试 rail 联动。
