## 4. 关键契约（实施期不可漂移）

1. **报错文案逐字对齐**（前端契约，已在上游错误码白名单）：
   - `"session is waiting for an interaction answer; supplemental input was not sent"`（SESSION_INPUT_REJECTED）
   - `"session execution is being cancelled"`（SESSION_INPUT_REJECTED）
   - `"the targeted execution has ended or changed; supplemental input was not sent"`（SESSION_INPUT_TARGET_CHANGED）
   - `"image supplemental input requires an active execution; supplemental input was not sent"`（TARGET_CHANGED，idle 带图）
   - `"session has no active agent: {session_id}"` / `"active agent does not support supplemental input"`（REJECTED）
   - `"target execution changed before submission; queue the message"`（REJECTED，跨会话键请求）
   - `"session output is finishing; supplemental input was not sent, retry after it settles"`（RuntimeError）
   - `"session input requires non-empty text"` 等校验段文案（session_input.go 已对齐）
2. **无 await 同步入队**：enqueue_bound_session_input 的 check-then-enqueue 之间不得插入任何可让渡点（Go：同一 mutex 临界区内完成复核 + EnqueueSteer；注释原话 "No await may separate the target check from enqueueing"）。
3. **accepted 帧形状**：steer 命中活跃轮 → `runtime.accepted` + `input_boundary:"stream"` + is_complete=false 后跟空 payload 终帧；idle 兜底 → `runtime.accepted` + `input_delivery:"chat"`（无 input_boundary）。history 落盘只认**无 input_boundary 的 accepted**（interface.py:3805 判定 `payload.input_boundary != "stream"`）。
4. **投递优先级三级**（承接 11-24 会话已核实事实，spec §8 存档不重复展开）：交互 waiter → attach-only 观察订阅（waiters[:1]）→ 仅终态帧走 server-push 孤儿投递。
5. **竞态三层防线顺序不可调整**：accepted 判定（active_round/output stream）→ await 后复核（图片准备后再查）→ 无 await 同步入队（bound_round 绑定复核 + execution 复核 + steering queue 存在性）。
6. **代次语义**：TeamManager._session_generations 是 coordinator generation 的镜像（bind_generation 传播），has_stream_task/pop 均过 generation_matches 闸；Go 对齐时沿用 coordinator 权威值。
7. **timeout 判定**（C3）：`timeout_scope.expired` → state=FAILED + error=timeout_error 文案；不得折叠进 CANCELLED。

## 5. 取消语义回退（裁决 2 实施）

- `SubmitUnary`：删除「调用方 ctx.Done → goroutine 退出静默不执行」分支；任务一经提交必须执行，取消只经 `CancelExecution`（对齐 Python cancel_handles）。
- `SubmitAndWait`：删除「ctx 取消 → 排队中未执行项直接吞掉」分支；排队项按 Python 语义照常执行或经显式取消摘除。
- 删除后锚点清零（规则 8）：`grep -r "ctx 取消.*静默\|取消.*吞掉排队"` 及对应代码块 0 命中；连带测试改为断言「ctx 取消后任务仍执行/仍在队列」。

## 6. 小项处置

1. **D1 lifecycle guard**：requireOpenSession 前置 server 侧 session lifecycle 状态检查（CLOSED/QUIESCING 拒收），对齐 Python _require_open_session 的 guard 先行顺序。
2. **D2 Register 改 error**：`SessionExecutionRegistry.Register` 返回 `error`（`duplicate execution id: xxx`），调用方（coordinator.go _new_execution 等价处）向上传播；删除 panic 路径；同改动更新全部调用方与测试。
3. **D3 cancelExecutionInternal 对齐 cancel_execution**：展开后代（沿 parent_execution_id 反查子孙一并取消）、超时项归类 timed_out 并入 CancelExecutionResult.TimedOut。

### 8.2 集成测试（跨子系统，tests/integration/）

1. **steer 插话不排队**：单 agent 会话 chat.send 起轮 → 轮内第二条 chat.send（input_mode=steer）→ 断言不进 FIFO（立即插话）、父 execution 绑定、子执行入账本、终态连带取消。
2. **锚定失配**：带 expected_execution_id 且轮已结束 → SESSION_INPUT_TARGET_CHANGED 透传前端。
3. **idle 兜底**：空闲会话发 steer（纯文本）→ runtime.accepted(input_delivery=chat) + 新轮；带图 → TARGET_CHANGED 拒收。
4. **等交互应答拒收**：ask_user 挂起期间 steer → REJECTED；先答题后 steer 成功。
5. **guard rail**：会话收尾窗口 accepting=false 拒收；boundary_error 部分被剔除、正常部分放行。
6. **timeout**：模拟超时执行 → 终态 FAILED + timeout 文案 + 快照可见。
7. **代次防误判**：会话关闭重开（generation+1）后旧代次 execution 不参与活跃判定、旧 stream task 失配。
