## 1. 定位与作用

Workflow 是工作流编排层门面 + 会话生命周期管理器，位于 Pregel 图引擎（8.1-8.9 已完成）之上、具体组件（8.18-8.26）之下。一次执行的链路：

```
调用方 → Workflow.Invoke / Stream            ← 8.14 本体
  → createWorkflowSession                    ← WorkflowSession/SubWorkflowSession + ActorManager(8.12) + StreamWriterManager + Tracer
  → BaseWorkflow.Compile                     ← 构图校验 + auto_complete_abilities + 嵌套深度检查
  → CompiledGraph.Invoke (8.1)               ← INPUTS_KEY 信封进 Pregel 调度
  → Vertex.Call (8.11) × N                   ← 各组件执行；End 节点流帧经 _processChunk(①分支) 进 session emitter 队列
  → 主循环 range StreamOutput                ← 首帧/帧超时、逐帧日志、INTERACTION 收集
  → 收尾：task.Wait → WORKFLOW_FINISHED → 补发 workflow_final → 清理
```

## 4. 组件组合面（前拍板：双基座嵌入组合）

```go
// ComponentComposable 接口（component.py:236-283）
type ComponentComposable interface {
    AddComponent(g *graph.PregelGraph, nodeID string, waitForAll bool) error
    ToExecutable() graphexe.Executable
}

// BaseComponentComposable 组合面基座；槽承载「基座回调外层」唯一边
type BaseComponentComposable struct {
    toExecutableFn func() graphexe.Executable
}

// AddComponent 默认实现一比一（component.py:248-260）
//   nil 槽 ≙ Python NotImplementedError 分支（复刻文案）
//   否则 g.AddNode(nodeID, m.toExecutableFn(), waitForAll→WithWaitForAll())
```

`WorkflowComponent` 修订（D-17-1）：

```go
type WorkflowComponent struct {
    graphexe.BaseExecutable[map[string]any, map[string]any]  // 执行面基座（ComponentExecutable）——保留
    BaseComponentComposable                                  // 组合面基座（ComponentComposable）——新增
    InvokeFn / StreamFn / CollectFn / TransformFn / TraceMetadataFn  // 函数槽——保留
}

// NewWorkflowComponent 构造时 self 接线（≙ Python isinstance(self, Executable) 恒真）
//   wc.toExecutableFn = func() graphexe.Executable { return wc }
```

- 基座永远只调槽不调外层——无基类调子类问题；外层定义同名方法可遮蔽 ≙ Python override（8.14b 用）
- Start/End 在 Python 不覆写这两方法 → Go 仅换构造方式（`WorkflowComponent{...}` 字面量 → `NewWorkflowComponent()` + 槽赋值），同步 component.go / flow 两文件 / 测试 / doc.go

> **实施细化（2026-11-20，Task 1 实际形态）**：`WorkflowComponent` 改为**直接实现** `ComponentComposable` 两方法——`ToExecutable` 自返回自身（≙ Python isinstance 恒真）、`AddComponent` 落默认实现于合成体（≙ Python 继承 mixin 默认实现）。优点：无需构造期 self 接线、既有字面量构造零迁移、基座回调外层的边完全消失；外层同名方法提升遮蔽 ≙ Python override 不变。`BaseComponentComposable` 槽基座保留给纯组合件（8.14b SubWorkflowComponent）。连带破环：graph/vertex.go 直引 ability 叶包（compability 别名，D-17-8 同向），消解 components→graph 反向环；另修 TestPostStream flaky（MainQueueLen 排空敏感 → StreamProcessor.TotalPutCount 单调计数）。
- 纯组合件（8.14b、路由类）可只嵌 `BaseComponentComposable` 自供槽
