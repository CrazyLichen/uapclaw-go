## 1. 流程位置与作用

dsh 是领域十五五个内置 provider 中的第 4 个外部 provider（native 进程内；claudecode/codex/dsh 为外部 CLI/SDK 进程边界）。在 agent 会话中的层次：

```
宿主（Go 协调层 / team 成员运行时）
   └─ harness_protocol（15.1-15.4 已落）
       └─ SerializedTurnHarness（15.5 已落：串行 turn 循环、事件缓冲、交互、checkpoint）
           └─【本节 DshHarness】协议 v1 的 DeepSeek Harness 适配器
               └─ deepseek-harness-sdk-go（第三方，stdio JSON-RPC 2.0 驱动 dsh 子进程）
```

作用：把「一个可复用的 DeepSeek Harness 会话」适配到协议 v1。每个 OpenJiuwen Turn = 一段串行化的 DSH 活动区间（输入接受 → whole-agent idle）；DSH 自身的 turn/step 记录仅为内部观测，不重定义公开 Turn 边界。能力卡：`MCP_TOOLS + ENDPOINT_MODELS`，可选宿主能力 `MCP_SERVERS`。

## 4. SDK 缝（用户拍板方案 A：直接依赖 + 工厂缝）

依赖：`go get github.com/theoneLee/deepseek-harness-sdk-go`（MIT，Go 1.26 兼容本仓 go.mod 1.26.0，clean-room 实现 stdio JSON-RPC 2.0，镜像上游 Python SDK 分层）。

`harness.go` 内定义非导出窄接口（Python `importlib.import_module("deepseek_harness")` 的 Go 等价缝）：

```go
type dshSDKHarness interface {
    StartSession(sessionID string) (dshSDKSession, error)
    Close() error
}
type dshSDKSession interface {
    Run(input any, onNotification func(deepseekharness.Notification)) (*deepseekharness.RunResult, error)
}
```

- `DshHarness` 持有 `sdkFactory func(DshHarnessConfig, HarnessContext) (dshSDKHarness, error)` 字段；默认实现 = Go SDK `NewDeepSeekHarness` 薄包装（`sdkOptions` 的 20 字段一比一映射：Provider/Model/ReasoningEffort/MaxTokens/CWD/RuntimeCWD/DSHBin/DSHHome/Profile/Patches/Env/BaseURL/APIKey/三 timeout/LaunchArgsOverride；Python filter-None → Go SDK merge 逻辑零值省略等价）。
- 单测注入 fake 工厂：上游 `_install_fake_sdk`（ModuleType 注入）/`_FakeSession`（脚本式通知 + released 事件 + active_runs 计数）/`_FakeRunResult`/start_session 失败注入，1:1 迁移为 Go fake（scripts 切片 + channel/sync.WaitGroup 等价物）。
- `RunResult.FinalResponse`/`FinishReason(*string)` 喂 `BuildTerminalResult`；`FinishReason` 非串时 str 化语义保留。

### SDK 调用点核对（Python → Go）

| Python（harness.py） | Go SDK（api.go 实测） |
|---|---|
| `sdk.DeepSeekHarness(**options)` | `deepseekharness.NewDeepSeekHarness(cfg)` |
| `h.start_session(session_id)` | `h.StartSession(id)`（惰性启动 + 会话复用同语义） |
| `session.run(input, on_notification=cb)` | `s.Run(input, cb)`；`Notification{Method, Payload}` 形状一致（`payload/params` 分流逻辑照搬） |
| `h.close()`（幂等） | `h.Close()`（幂等） |
