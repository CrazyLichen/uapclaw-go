## 2. 语义说明（写入 spec 供回看）

### 2.1 persona 拍平

模板人格是一组 `prompt_sections`（identity/sops/output_contract/safety…，各有语言版本/priority/render_params）。`render_template_persona`：按 priority 排序 → 每段按成员语言渲染（`{{language}}/{{workspace}}` + 段 render_params）→ 空段丢弃 → 空行拼接成**一个字符串**。动机（template_member.py 模块注释原文）：Team 把人格放进成员私有 prompt lane，**不让 harness 替换 prompt_sections**——模板段落与成员身份段不得双重注入。

### 2.2 能力快照

`template_snapshot` = 模板去掉 prompt_sections 后整体 `model_dump(mode="json")`（tools/mcps/rails/skills/memories/rubrics/subagents/model/runtime）。存 `DeepAgentSpec.agent_template_spec`，成员**构建时**由 NativeHarness 读它热挂载（复用 15.15 extension binder 六类绑定链）。「快照」含义：①存 JSON 数据非活对象，可持久化、跨进程恢复；②prompt 已剥走——人格走 prompt lane，能力走快照。

### 2.3 prompt 进入系统提示词的链路（已与用户核对源码）

「prompt lane」= 成员 spec 的 `prompt` 字段位置（`TeamAgentSpec.predefined_members[].prompt` / spawn payload `prompt=identity.prompt`），是内存 spec 结构随团队 spec 持久化，**不是**配置文件或独立存储组件。

persona **不整体替换** DeepAgent 系统提示词（deep_agent.py:1283-1290）：成员 `prompt` → `DeepAgentConfig.system_prompt` → 构建时包成 **IDENTITY section（priority=10）** 注入 `SystemPromptBuilder`，即只替换身份段；工具/workspace/安全等其余 section 照常，rail 在 BEFORE_MODEL_CALL 仍可改同一 builder。Go 侧对应：`DeepAgentConfig.SystemPrompt`（agent_specs.go:323）→ 既有 SystemPromptBuilder IDENTITY section（`harness/cli/prompts`），本批**不动** prompt builder。

另有一条声明性小段：`_materialize_agent_template`（deep_agent.py:3283）会话物化时经 `prompt_attachment_manager.add_section` 加 RUNTIME 类型 `_EXPERT_ROLE_SECTION`（「已加载专家角色 xxx」）。**本批不迁**，⤵️ 15.16（Go prompt attachment 地基 S1/S2 已在）。
