## 1. 流程位置与作用

任务板语义横跨三层，处于 `TeamAgent` 协调唤醒层的核心通路：

```
成员 DeepAgent（ReAct 循环）
  └─ team tools（create/claim/complete/reassign/verify/view…）
       └─ TeamTaskManager（写 SQLite + 发布 TASK_* 事件）
            └─ coordination 唤醒层（EventDispatcher 粗筛）
                 └─ TaskBoardHandler（本节主干）→ steer/deliver_input 回灌成员轮次
```

- 回调注册链路：`TaskBoardHandler.GetCallbacks()`（Go `task_board.go:51`）经 dispatcher 注册进回调框架，与 Python `get_callbacks()` → dispatcher 私有 `AsyncCallbackFramework` 一比一同构；dispatcher 只做粗筛（agent_ready / inner-vs-transport / 角色门控），业务判断全在 handler。
- 作用：把「leader 手工派活」升级为「看板状态机自主认领」——定向所有权信号（revoke/verify 闸）、看板巡视唤醒（leader 全看、teammate 只被扩大可认领池的三类事件唤醒）、reassign、one-active-claim 不变量。
