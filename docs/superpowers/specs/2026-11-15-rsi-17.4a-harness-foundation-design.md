## 3. 关键设计点

1. **品牌映射**：config.py 中 `jiuwenswarm_executable`/`jiuwenswarm_python` 等键按 brand-string-mapping 映射为 `uapclawswarm_*`；YAML 模板内品牌字符串同步映射；第三方 env 名不改。
2. **text_encoding 修复链**：Python `str.encode(encoding, errors=...)` → Go `golang.org/x/encoding` 的 GBK/GB18030 + `charmap` Latin1/CP1252，strict/ignore 语义用返回 error / 逐字节跳过实现；候选评估与择优逻辑（`_better_repair`、评分权重 2/3/4、密度阈值 0.18/0.08）逐条对齐。
3. **unicodedata.name 等价**：Python 用 `unicodedata.name(char)` 匹配 ARMENIAN / LATIN EXTENDED / IPA EXTENSIONS 三块；Go 无标准库字符名查询，用等价码点区间判断（登记偏差 D-1，行为等价）。
4. **异常模型**：Python `except BaseException` 广捕获 → Go `error` 捕获 + `panic` 不捕获（等价偏差 D-2：Python 捕获 KeyboardInterrupt 属运行时形态差异）；`asyncio.sleep` → `time.Sleep`；`RetryableModelOutputError` 用 sentinel error 类型。
5. **correction_message 文案**：拼给 LLM 的提示词模板，逐字保留英文原文（提示词一比一纪律）；日志 Msg 译英文，注释中文。
6. **json tag 纪律**：17.1 教训沿用——契约结构体序列化走显式方法或公开字段 tag；`frozen dataclass` → 不可变字段 + 构造校验。
7. **config 校验链**：`__post_init__` 的逐字段校验（score_mode ∈ {binary,continuous} 等）逐条进 `Validate()` 或构造函数，错误文案逐字对齐 Python。
8. **data_loader**：`CaseMapping = map[string]any`（与 OpenViking 先例同风格）；批次规划/剖析/评分契约归一逻辑逐步对齐，`JSONDecodeError` → `json.Unmarshal` error 传播。
9. **日志**：包级 `logComponent = logger.ComponentAgentCore`（rsi 属 agentcore 域，与 17.1 一致）；`config/loader.py` 的 bootstrap 失败 warning 带结构化字段。
