## 1. 概述

### 1.1 一句话

25.1a 把 L2 `NativeHarness` / L3 `TeamHarness` 的表面搭起来了，但**"建脑"的方式仍是临时拼装**：`AgentConfigurator` 手工 new 6 个 rail、手工传给 `BuildTeamHarness`、`BuildTeamHarness` 手工 `AddRail` 6 次、再包成 `NativeHarness`。25.1b 把这套改成上游的 **spec 驱动前向构造**：rail 只在 spec 里**声明**（`RailSpec{Type, Params}`），由 `NativeHarness` 自己 `resolve_parts` → 统一挂载 → `ensure_initialized`。

### 5.1 `BuildContext`（`internal/agentcore/harness/schema/build_context.go`）

9 个字段严格对齐上游 169 行文件：

```go
// BuildContextInterface 构建上下文接口（决策 D2：Derive 保子类）。
type BuildContextInterface interface {
    GetLanguage() string
    GetMemberName() string
    GetRole() string
    GetWorkspace() *workspace.Workspace
    GetMemberCardID() string
    GetProjectDir() string
    GetTeamOutputsDir() string
    GetExtras() map[string]any
    GetMoa() any
    // Derive 返回带 overrides 的浅拷贝，实现方必须保留自身具体类型。
    Derive(overrides BuildContextOverrides) BuildContextInterface
}

// BuildContext 交给能力 provider 的不透明运行时载体。
// Python: BuildContext (openjiuwen/harness/schema/build_context.py:52-169)
type BuildContext struct {
    Language       string
    MemberName     string
    Role           string
    Workspace      *workspace.Workspace
    MemberCardID   string
    ProjectDir     string
    TeamOutputsDir string
    Extras         map[string]any
    Moa            any
}

// Derive 返回浅拷贝并应用 overrides；Extras 深拷贝一层（对齐上游
// `member_build_context.extras = dict(...)`，见 agent_configurator.py:867）。
// Python: BuildContext.derive (**overrides)（:106-118）
func (c *BuildContext) Derive(o BuildContextOverrides) BuildContextInterface

// Python: BuildContext.resolve_member_work_dir（:120-145）
func (c *BuildContext) ResolveMemberWorkDir() *string

// 种子工厂：跨序列化边界（进程 spawn / 冷恢复）重建活上下文。
// Python: register_build_context_factory / build_context_from_seed（:147-169）
func RegisterBuildContextFactory(f BuildContextFactory)
```

**`BuildContextOverrides`**：Go 无 `**overrides`，用零值可选结构体（指针字段区分"未指定"与"置空"）：

```go
type BuildContextOverrides struct {
    Language       *string
    MemberName     *string
    Role           *string
    Workspace      *workspace.Workspace   // 非指针不可空 → 用 HasWorkspace 位
    HasWorkspace   bool
    MemberCardID   *string
    ProjectDir     *string
    TeamOutputsDir *string
    Moa            any
}
```
