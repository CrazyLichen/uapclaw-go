# SessionOps (10.6.12) 实现设计

> 对齐 Python: `jiuwenswarm/agents/harness/common/session_ops_service.py`
> 实现计划章节: 10.6.12
> 日期: 2025-08-18

## 概述

SessionOps 是 AgentServer 内部的会话操作服务层，提供 fork/rewind/restore 等会话生命周期操作。
被 `handleSessionRewind` / `handleSessionFork` 等 E2A handler 调用。

当前 Go 端 4 个 handler 全部是 stub（返回 NOT_IMPLEMENTED），SessionOps 服务函数不存在。

### 在 Agent 会话中的流程位置

```
用户交互 (TUI/Web/ACP)
    ↓
Gateway (MessageHandler / TUI Connect)
    ↓  构造 E2A 信封 (SESSION_REWIND / SESSION_FORK / SESSION_REWIND_AND_RESTORE / HISTORY_LIST_TURNS / SESSION_RESTORE_FILES)
AgentServer (handleEnvelope → handleSessionRewind / handleSessionFork / ...)
    ↓  调用 SessionOps 服务函数
SessionOpsService (session_ops.go)
    ├── 操作文件系统 (history.json / metadata.json)
    ├── 操作内存上下文 (context_engine 重建)
    └── 操作 Checkpointer (DeepAgentState 持久化)
```

### Python 7 个函数概览

| 函数 | 类型 | 作用 |
|------|------|------|
| `fork_session` | sync | 分叉会话：复制 history.json + forked_from 元数据 + 写 metadata |
| `rewind_session` | sync | 回退会话：截断 history.json + 更新 message_count |
| `list_session_turns` | sync | 列出用户 turn 列表（含 diff 统计） |
| `restore_session_files` | sync | 恢复文件到指定 turn 的状态 |
| `rewind_session_context` | async | 重建 context_engine：加载截断后的 history → 清空旧上下文 → 构建新上下文 → 持久化 |
| `copy_session_state` | async | 复制 DeepAgentState：读源 state → 深拷贝变换 → 写目标 checkpointer |
| `copy_session_context` | async | 复制内存上下文：读源 context → 在目标 session 创建相同 history 的 context |

## 设计 1：前置补丁 — 补通 GetInstance 链路

### 问题

Python 中 `_resolve_rewind_agent` 通过 `agent.get_instance()` 获取 `DeepAgent`。
Go 端 `UapClaw.GetInstance()` 返回 `nil`（stub），且 `AgentAdapter` 接口没有 `Instance()` 方法。

### 方案

将 `Instance()` 加入 `AgentAdapter` 核心接口（不是可选接口+类型断言，因为所有 adapter 都有 DeepAgent 实例）。

### 变更清单

**1. `adapter/interface.go` — AgentAdapter 接口新增 Instance() 方法**

```go
type AgentAdapter interface {
    // ... 现有方法 ...

    // Instance 返回底层 DeepAgent 实例，未初始化时返回 nil。
    // Python: JiuWenClaw.get_instance() → self._adapter._instance
    Instance() *harness.DeepAgent
}
```

**2. `adapter/deep_adapter.go` — 新增 Instance() 方法**

```go
// Instance 返回底层 DeepAgent 实例。
// Python: JiuWenClaw.get_instance() → self._adapter._instance
func (d *DeepAdapter) Instance() *harness.DeepAgent {
    if d == nil {
        return nil
    }
    return d.instance
}
```

**3. `adapter/code_adapter.go` — 新增 Instance() 方法**

CodeAdapter 使用命名字段 `deep *DeepAdapter`（非匿名嵌入），方法不会自动提升，需手动委托：

```go
// Instance 返回底层 DeepAgent 实例，委托给内嵌 DeepAdapter。
func (c *CodeAdapter) Instance() *harness.DeepAgent {
    if c.deep == nil {
        return nil
    }
    return c.deep.Instance()
}
```

**4. `runtime/uapclaw.go` — 修改 GetInstance() 实现**

```go
func (uc *UapClaw) GetInstance() *harness.DeepAgent {
    if uc == nil || uc.adapter == nil {
        return nil
    }
    return uc.adapter.Instance()
}
```

**5. `handle_session.go` — 新增 resolveRewindAgent 辅助函数**

```go
// resolveRewindAgent 获取指定渠道的 DeepAgent 实例，用于 rewind/fork 操作。
// Python: AgentWebSocketServer._resolve_rewind_agent(channel_id)
func (s *AgentServer) resolveRewindAgent(channelID string) *harness.DeepAgent {
    agent := s.agentManager.GetAgentNoWait(channelID, "", "", "")
    if agent == nil {
        return nil
    }
    return agent.GetInstance()
}
```

### 关键实现要点

1. **ForkSession** — `shutil.copy2` → Go `io.Copy` + `os.Chmod`；`json.dumps(data, ensure_ascii=False)` → `json.Marshal`；`_get_unique_fork_name` 正则逻辑一比一对齐
2. **RewindSession** — 调用 `session.TruncateHistoryRecords(sessionID, cutIndex)`；`re.sub` 剥离 `<file-content>` 块对齐 Python
3. **ListSessionTurns** — 调用 `utils.GetDiffService().GetTurnDiffs()` 获取 diff 统计；`re.sub` 剥离 `<file-content>` 块
4. **RestoreSessionFiles** — 调用 `utils.GetDiffService().GetFilesToRestore()` 获取待恢复文件；文件操作 `os.WriteFile` / `os.Remove`
5. **RewindSessionContext** — 核心流程：读 history.json → 转换为 `[]BaseMessage` → `contextEngine.ClearContext` → `contextEngine.CreateContext` → `contextEngine.SaveContexts` → `deepAgent.SaveState`
6. **CopySessionState** — `session.CreateAgentSession` + `PreRun` + `GetState(SessionStateKey)` → `deepcopy` + 变换（reset iteration, clear stop_condition_state, clear pending_follow_ups, generate new plan slug）→ `UpdateState` + `PostRun`；plan slug 复制调用 `agentmode.GetOrCreatePlanSlug` / `agentmode.ResolvePlanFilePath`
7. **CopySessionContext** — `deepAgent.GetCurrentContext` → `deepAgent.CreateNewContextEngine`

## 设计 3：Handler 串联 + 回填

### 3.1 新增 Handler 分发

`handle_envelope.go` 的 switch 中新增 2 个 case：

```go
case schema.ReqMethodHistoryListTurns:
    resp, err = s.handleHistoryListTurns(ctx, request)
case schema.ReqMethodSessionRestoreFiles:
    resp, err = s.handleSessionRestoreFiles(ctx, request)
```

### 3.2 实现 6 个 Handler

全部在 `handle_session.go` 中实现。

**handleSessionRewind** — 对齐 Python `_handle_session_rewind_full(restore_files=False)`

1. 解析 params: session_id, turn_index
2. 调用 `RewindSession(sessionID, turnIndex)`
3. 调用 `resolveRewindAgent` 获取 deepAgent
4. 如果 deepAgent != nil → 调用 `RewindSessionContext(ctx, deepAgent, sessionID, turnIndex)`
5. 组装 payload: rewind_result + rewind_context=bool
6. 返回 AgentResponse

**handleSessionRewindAndRestore** — 对齐 Python `_handle_session_rewind_full(restore_files=True)`

1. 解析 params: session_id, turn_index
2. 调用 `RestoreSessionFiles(sessionID, turnIndex)`
3. 调用 `RewindSession(sessionID, turnIndex)`
4. 调用 `resolveRewindAgent` 获取 deepAgent
5. 如果 deepAgent != nil → 调用 `RewindSessionContext(ctx, deepAgent, sessionID, turnIndex)`
6. 组装 payload: rewind_result + rewind_context + restored_files + deleted_files + restore_errors
7. 返回 AgentResponse

**handleSessionRewindContext** — 对齐 Python `_handle_session_rewind_context`

1. 解析 params: session_id, turn_index
2. 调用 `resolveRewindAgent`，如果 nil → 返回错误 "no agent instance available"
3. 调用 `RewindSession(sessionID, turnIndex)` — 先截断 history 再重建上下文
4. 调用 `RewindSessionContext(ctx, deepAgent, sessionID, turnIndex)`
5. 组装 payload: rewind_result + rewind_context=bool
6. 返回 AgentResponse

**handleSessionFork** — 对齐 Python `_handle_session_fork`

1. 解析 params: source_session_id, target_session_id, title
2. 调用 `ForkSession(source, target, title, channelID)`
3. 调用 `resolveRewindAgent` 获取 deepAgent
4. 如果 deepAgent != nil → 调用 `CopySessionContext(ctx, deepAgent, source, target)`
5. 调用 `CopySessionState(ctx, source, target, card, deepAgent)`，card 来源: deepAgent.Card() 或默认 AgentCard
6. 组装 payload: fork_result
7. 返回 AgentResponse

**handleHistoryListTurns** — 新增 handler

1. 解析 params: session_id
2. 调用 `ListSessionTurns(sessionID)`
3. 组装 payload: turns + total
4. 返回 AgentResponse

**handleSessionRestoreFiles** — 新增 handler

1. 解析 params: session_id, turn_index
2. 调用 `RestoreSessionFiles(sessionID, turnIndex)`
3. 组装 payload: restored_files + deleted_files + errors
4. 返回 AgentResponse
