## 1. 背景与流程位置

adapters.py 是 E2A 统一形状与外部协议形状（ACP JSON-RPC / A2A）之间的**纯函数投影层**。入站写 provenance 溯源，出站投影为外协议 JSON，回流构造内部 Message。

三条链路：

```
链路A 入站：ACP 客户端 --JSON-RPC--> EnvelopeFromACPJsonrpc --> E2AEnvelope --> gateway_normalize(10.2.7) --> AgentWS(10.3.1)
链路B 出站：E2AResponse --E2AResponseToACPJsonrpcResponse--> JSON-RPC 2.0 响应 --> 客户端
链路C 回流：客户端 JSON-RPC 响应 --BuildACPToolResponseMessage--> Message(acp.tool_response) --> handleACPToolResponse(24d已交付)
```

A2A 链路（11.26 消费）：`EnvelopeFromA2ASendMessage`（入站 SendMessage→信封）与 `E2AResponseToA2AStreamPayload`（出站 stream_event→四键单键 JSON）。`EnvelopeToACPJsonrpcCall` 双向通用（envelope→调用描述，日志/下游 ACP 端点）。

### Options struct（字段逐一对齐 Python 签名，不多不少）

```go
// EnvelopeFromACPOptions 对应 Python envelope_from_acp_jsonrpc 的 keyword-only 参数。
type EnvelopeFromACPOptions struct {
    // JSONRPCID JSON-RPC 标识（str/int/None）——保留 any 透传（协议保真：客户端数字 id 原样回传）
    JSONRPCID any
    // SessionID 会话 id（空则查 params["session_id"]；非 str 置空）
    SessionID string
    // Channel 渠道
    Channel string
    // IdentityOrigin 身份来源（零值时取 IdentityOriginUser，Python 默认 USER）
    IdentityOrigin IdentityOrigin
    // Converter converter 串（零值时用 converterACP）
    Converter string
    // ExtraProvenanceDetails 合入 provenance details（可覆盖既有键，对齐 dict.update）
    ExtraProvenanceDetails map[string]any
}

// EnvelopeFromA2ASendMessageOptions 对应 Python envelope_from_a2a_send_message 的 keyword-only 参数。
type EnvelopeFromA2ASendMessageOptions struct {
    // Metadata 对应 E2A 的 a2a_metadata（A2A 规范侧，与通道 metadata/channel_context 无关）
    Metadata map[string]any
    // Configuration A2A configuration（acceptedOutputModes 提取为 ExpectedOutputModes）
    Configuration map[string]any
    // Channel 渠道
    Channel string
    // IdentityOrigin 身份来源（零值时取 IdentityOriginUser）
    IdentityOrigin IdentityOrigin
    // Converter converter 串（零值时用 converterA2A）
    Converter string
    // ExtraProvenanceDetails 合入 provenance details
    ExtraProvenanceDetails map[string]any
}
```

**Options struct 而非 Functional Options 的理由**：两函数共享 WithChannel/WithIdentityOrigin/WithConverter/WithExtraProvenanceDetails 四个 With* 名，同包定义必然冲突；共享单一 option 族会让 A2A 调用点静默忽略 WithJSONRPCID。独立 struct 字段直映 Python 签名，类型隔离最干净。

**jsonrpcID 保留 any 的理由**：24d 收紧的是 AcpOutputManager 内部 pending 键（内部状态字符串化）；本处是协议透传字段（写进 envelope 后原样回传客户端），JSON-RPC 严格客户端靠 id 类型匹配响应，中途字符串化会破坏匹配。两处语义不同，不冲突。

## 4. 逐函数语义对齐（12 点）

| # | Python 语义 | Go 实现 |
|---|---|---|
| 1 | `sid = session_id or p.get("session_id")`；`sid if isinstance(sid, str) else None` | opts.SessionID 非空优先，否则查 `params["session_id"]`；类型断言 string 失败（含 JSON 数字）→ 置空串。**注意**：Python `p.get("session_id")` 可能返回 int（JSON 数字），isinstance 检查失败置 None——Go 断言 `.(string)` 失败同置空串 |
| 2 | details 键序：kind → jsonrpc_method → jsonrpc_id（非 None 才加）→ extra.update | map 无序但键存在性等价；opts.JSONRPCID 非 nil 时写 `jsonrpc_id` |
| 3 | A2A `acceptedOutputModes`：`isinstance(acc, list)` 才提取，逐个 `str()` | `configuration["acceptedOutputModes"]` 断言 `[]any`，逐个 `fmt.Sprintf("%v")`；nil configuration → ExpectedOutputModes 为 nil |
| 4 | A2A `params={"message": body, "configuration": configuration or {}}` | nil configuration → `map[string]any{}` 字面量（configuration 键恒存在） |
| 5 | `envelope_to_acp_jsonrpc_call`：`method == "ext" and ext_method` 时用 ext_method；`session/prompt` 走 `merge_params_to_acp_prompt`；输出四键 jsonrpc/id/method/params | 复用包内 `MergeParamsToACPPrompt(env)`；ext 分支注意 `env.Method == "ext" && env.ExtMethod != ""` 双条件 |
| 6 | projections 优先：`proj.get("jsonrpc") == "2.0"` 且含 result/error → 副本 + `setdefault("id", response.jsonrpc_id)` | 同逻辑；`proj["id"]` 缺失时补 `resp.JSONRPCID`（保持 any） |
| 7 | e2a.error 分支：`code_raw = body.get("code")`；code 非 int → `-32603`，字符串码写 `data.e2a_code`；details/external 非 None 进 data | **判定链**（Go JSON 解码数字为 float64，须逐级断言）：`codeRaw` 断言 `.(int)` 命中 → code=codeRaw；断言 `.(float64)` 命中且整数值 → code=int(codeRaw)；断言 `.(bool)` 命中 → code=0/1（Python bool 是 int 子类，isinstance(True,int)==True）；否则 → code=-32603 且 `codeRaw != nil` 时写 `data.e2a_code`。**边界**：float64 非整数值（如 1.5）在 Python 中 isinstance(1.5, int)==False 走 -32603——Go 断言整数值失败同走 -32603。details/external 键存在才写 data |
| 8 | A2A stream：`projections.a2a` 单键（len==1）且 key ∈ {task,message,statusUpdate,artifactUpdate} → 原样副本 | `len(proj) == 1` + 白名单 map 查表 |
| 9 | `branch not in E2A_A2A_STREAM_BRANCHES or not isinstance(payload, dict)` → None | 复用常量 `E2AA2AStreamBranches`（[]string，线性查）；payload 断言 map[string]any 失败 → nil |
| 10 | `f"acp_tool_resp_{uuid4().hex[:12]}"` | crypto/rand 6 bytes → hex 12 字符（24d randomAcpHex12 同款逻辑，本包内私有实现不跨包复用，避免 e2a→tools 反向依赖） |
| 11 | Python 延迟 import schema（防环） | Go 顶层 import schema（agent_compat.go 先例，无环已验证） |
| 12 | `metadata={"acp": {"jsonrpc_id":..., "kind": "tool_response"}}`；`timestamp=time.time()` | 同构 map；`schema.NowTimestamp()`（message.go:149 权威先例，`UnixNano()/1e9` 纳秒精度与 Python time.time() 对齐；send_file.go:346 的毫秒写法是历史偏差不跟随） |

## 5. 错误处理

纯函数层**无 error 返回**（对齐 Python：不适用的投影返回 None）。所有防御性分支（非法 branch、缺 tool_call、非 dict payload、未知 response_kind）以 nil 返回表达，由调用方决定日志策略。本层零日志（Python 同文件零 logger 调用，规则3无对应项）。

## 9. 偏差预归档

1. **converter 串 Go 化**：`jiuwenswarm.common.e2a.adapters:envelope_from_acp_jsonrpc` → `e2a.adapters:EnvelopeFromACPJsonrpc`（gateway_normalize.go:287 既有惯例，同包兄弟文件一致）
2. **keyword-only → Options struct 指针**：nil = 全默认（优于 Functional Options：避免两函数 With* 命名冲突与 A2A 调用点静默忽略 ACP 专属参数）
3. **jsonrpcID any 透传**：24d 收紧先例只覆盖内部 pending 键；本处协议透传字段保真。envelope.JSONRPCID / response.JSONRPCID 字段本身已是 any
4. **uuid4().hex[:12] → crypto/rand 6 bytes hex**：24d randomAcpHex12 同款（本包私有实现，不跨包复用避免 e2a→tools 反向依赖）
5. **Options struct 的 IdentityOrigin 零值处理**：零值 "" 时函数内取 IdentityOriginUser（Python 默认 USER）
6. **无 logger**：Python 源文件零 logger 调用，Go 同（规则3无对应项）
7. **bool/float64 code 判定链**（第 4 节 #7）：Go JSON 解码数字为 float64，逐级断言 int→float64 整数→bool→-32603；float64 非整数值对齐 Python isinstance(1.5,int)==False 走 -32603
8. **时间戳用 schema.NowTimestamp()**：message.go:149 权威先例（UnixNano/1e9 纳秒精度），不自造 UnixMilli/1000（send_file.go:346 是历史偏差不跟随）
9. **details/external 值判定**（实施后审查补归档）：Python `det = body.get("details"); if det is not None` 为值判定；Go 用 `if det := body["details"]; det != nil`（map 取值缺失与 JSON null 同为零值 nil，与 get() 天然等价）。**禁止**键存在性判定 `if _, has := body["details"]; has`——JSON null 场景会误写 `data["details"]=nil`
10. **BuildACPToolResponseMessage 的 channelID 零值回退**（实施后审查补归档）：Python 签名 `channel_id: str = "acp"` 有默认值；Go 无默认参数语法，函数内空串回退 "acp"（与第 5 条 IdentityOrigin 零值回退同模式）。边界：Python 显式传 `""` 得 `""`、Go 得 `"acp"`——Python 真实调用点（acp_connect.py:188/822）恒显式传 `self._channel_id`，此边界无实际影响
