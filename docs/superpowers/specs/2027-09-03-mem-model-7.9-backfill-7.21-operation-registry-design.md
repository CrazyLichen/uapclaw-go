# 7.9 Memory DB Models 全量回填 + 7.21 OperationRegistry 提前实现设计

## 背景

7.9 Memory DB Models 在 IMPLEMENTATION_PLAN.md 中标记为 ✅，但对比 Python 源码发现 3 处缺失：

| 缺失项 | Python 源码 | 行数 |
|--------|------------|------|
| `SupportMemoryType` 枚举 | `mem_model/memory_unit.py` | 3 行 |
| `UserMemStore` | `mem_model/user_mem_store.py` | 261 行 |
| `SemanticStore` | `mem_model/semantic_store.py` | 287 行 |

此外 `SemanticStore` 依赖 `vector_registry`（7.21 迁移系统），以及 `memory/common/base.py` 中的 3 个辅助函数也未移植。

**决策**：全量回填 7.9 缺失内容，同时提前实现 7.21 OperationRegistry 以解除 SemanticStore 对迁移系统的依赖。提前实现的文件组织对齐 Python 目录结构，不放在 7.9 章节目录下。

## 7.9 在 Agent 会话中的流程位置和作用

```
用户请求 → Gateway → AgentServer → SessionManager → Agent(Harness)
  → Memory Rail (9.19-23, 检查是否允许读写记忆)
  → Memory Tool (9.38-49, 执行记忆读写操作)
    → FragmentMemoryManager / SummaryManager / VariableManager (7.6-7.8)
      → [7.9 mem_model] ← 数据模型层
        → SqlDbStore / SqlMessageStore / UserMemStore / SemanticStore ← 持久化层
```

7.9 是记忆管理子系统的**类型契约和持久化基础设施层**，定义了 MemoryType/OperationType/MemoryUnit 等核心类型和 SQL/KV/向量三种存储实现。它不被 harness/agent_teams 等上层直接 import——上层通过 Manager 接口间接使用。

## 类型设计

### 1. `memory/common/base.go`

对齐 Python `openjiuwen/core/memory/common/base.py`。

```go
package common

// ──────────────────────────── 结构体 ────────────────────────────

// HitInfo 记忆检索命中结果。
// 对齐 Python: hits: list[Tuple[str, float]] 中的单个元素
type HitInfo struct {
    // ID 记忆标识
    ID string
    // Score 相似度分数
    Score float64
}

// ──────────────────────────── 导出函数 ────────────────────────────

// GenerateIdxName 生成向量索引名称。
// 对齐 Python: generate_idx_name(usr_id, scope_id, mem_type)
// 格式: uid_{usr_id}_gid_{scope_id}_mtype_{mem_type}
func GenerateIdxName(usrID, scopeID, memType string) string

// ParseMemtypeFromIdxName 从向量索引名称解析记忆类型。
// 对齐 Python: parse_memtype_from_idx_name(idx_name)
func ParseMemtypeFromIdxName(idxName string) string

// ParseMemoryHitInfos 解析记忆命中结果，分离 ID 列表和分数字典。
// 对齐 Python: parse_memory_hit_infos(hits)
func ParseMemoryHitInfos(hits []HitInfo) (ids []string, scores map[string]float64, err error)
```

**设计决策**：
- Python 用 `list[Tuple[str, float]]` 传命中结果，Go 用具名结构体 `HitInfo` 更清晰
- `ParseMemoryHitInfos` 返回 error，对齐 Python 中 `try/except ValueError` 的异常路径

### 3. `mem_model/user_mem_store.go`

对齐 Python `user_mem_store.py`。

```go
package mem_model

// ──────────────────────────── 结构体 ────────────────────────────

// UserMemStore 基于 KV 存储的用户记忆 CRUD。
// 对齐 Python: UserMemStore
//
// 键格式:
//
//	UMD/{user_id}/{scope_id}/{mem_id}       — 记忆数据
//	UMD/{user_id}/{scope_id}/ids             — 用户全部 ID 列表
//	UMD/{user_id}/{scope_id}/{mem_type}/ids  — 按类型 ID 列表
//	UMD/{user_id}/{scope_id}/UPT/ids         — 用户画像主题 ID 列表
type UserMemStore struct {
    // kvStore KV 存储后端
    kvStore kv.BaseKVStore
}

// ──────────────────────────── 常量 ────────────────────────────

const (
    byteNumPerID        = 24   // 每个 ID 占用 24 字节（DataIdManager 生成）
    idsStr              = "ids"
    userProfileTopicStr = "UPT"
    keyPrefixStr        = "UMD"
    separator           = "/"
    memTypeFieldKey     = "mem_type"
)

// ──────────────────────────── 全局变量 ────────────────────────────

// fragmentMemoryTypes 片段记忆类型列表
var fragmentMemoryTypes = []string{
    MemoryTypeUserProfile.String(),
    MemoryTypeSemanticMemory.String(),
    MemoryTypeEpisodicMemory.String(),
}

// ──────────────────────────── 导出函数 ────────────────────────────

// NewUserMemStore 创建用户记忆 KV 存储。
func NewUserMemStore(kvStore kv.BaseKVStore) (*UserMemStore, error)

// Write 写入记忆数据。若 mem_id 已存在返回 false。
func (s *UserMemStore) Write(ctx context.Context, userID, scopeID, memID string, data map[string]any) (bool, error)

// Update 更新记忆数据（合并字段）。若 mem_id 不存在返回 false。
func (s *UserMemStore) Update(ctx context.Context, userID, scopeID, memID string, data map[string]any) (bool, error)

// Delete 删除指定记忆。
func (s *UserMemStore) Delete(ctx context.Context, userID, scopeID, memID string) error

// BatchDelete 批量删除记忆。
func (s *UserMemStore) BatchDelete(ctx context.Context, userID, scopeID string, memIDs []string) error

// Get 获取指定记忆数据。
func (s *UserMemStore) Get(ctx context.Context, userID, scopeID, memID string) (map[string]any, error)

// BatchGet 批量获取记忆数据。
func (s *UserMemStore) BatchGet(ctx context.Context, userID, scopeID string, memIDs []string) ([]map[string]any, error)

// GetAll 获取用户指定类型（或全部）记忆。memType 为空时获取全部类型。
func (s *UserMemStore) GetAll(ctx context.Context, userID, scopeID, memType string) ([]map[string]any, error)

// GetByTopic 按主题获取记忆。
func (s *UserMemStore) GetByTopic(ctx context.Context, userID, scopeID, topic string) ([]map[string]any, error)

// GetInRange 按范围获取记忆（分页）。
func (s *UserMemStore) GetInRange(ctx context.Context, userID, scopeID string, startIdx, endIdx int, memType string) ([]map[string]any, error)

// ──────────────────────────── 非导出函数 ────────────────────────────

func (s *UserMemStore) getUserIDsKey(userID, scopeID, memType string) string
func (s *UserMemStore) getUserMemKey(userID, scopeID, memID string) string
func (s *UserMemStore) getConcatenationKey(fields []string) string
func (s *UserMemStore) innerDelete(ctx context.Context, userID, scopeID, memID string) error
func (s *UserMemStore) deleteMemID(ctx context.Context, idsKey, memID string) error
func writeID(dataList, id string) string
func deleteIDByValue(dataList, idStr string) string
func getAllIDs(dataList string) []string
func getIDsInRange(dataList string, startIdx, endIdx int) []string
```

**设计决策**：
- Python 中 `write` 返回 `bool`，删除类方法无返回值。Go 统一返回 `error`，Write/Update 额外返回 `bool`
- `BatchDelete` 在 Python 中 for 循环逐个调用 `inner_delete`，Go 保持同样逻辑
- `fragmentMemoryTypes` 是包级变量（`MemoryType.String()` 不是编译期常量）
- 构造函数注册 `kv_prefix_registry`，对齐 Python `__init__`
- ID 列表操作（writeID/deleteIDByValue/getAllIDs/getIDsInRange）基于 24 字节定长切割，对齐 Python 的 `BYTE_NUM_PER_ID = 24`

### 4. `mem_model/semantic_store.go`

对齐 Python `semantic_store.py`。

```go
package mem_model

// ──────────────────────────── 结构体 ────────────────────────────

// DocTuple 文档元组 (id, text)，对齐 Python 的 List[Tuple[str, str]]。
type DocTuple struct {
    // ID 文档唯一标识
    ID string
    // Text 文档原始文本
    Text string
}

// SearchResult 语义搜索结果，对齐 Python 的 Tuple[str, float]。
type SearchResult struct {
    // ID 匹配文档标识
    ID string
    // Score 相似度分数
    Score float64
}

// SemanticStore 语义向量存储，使用嵌入模型和向量存储实现语义搜索。
// 对齐 Python: SemanticStore
type SemanticStore struct {
    // embeddingModel 嵌入模型（可选，可通过 InitializeEmbeddingModel 延迟设置）
    embeddingModel embedding.BaseEmbedding
    // vectorStore 向量存储后端
    vectorStore vector.BaseVectorStore
    // createdCollections 已创建的集合缓存，避免重复检查
    createdCollections map[string]struct{}
}

// ──────────────────────────── 导出函数 ────────────────────────────

// NewSemanticStore 创建语义向量存储。embeddingModel 可为 nil。
func NewSemanticStore(vectorStore vector.BaseVectorStore, embeddingModel embedding.BaseEmbedding) *SemanticStore

// InitializeEmbeddingModel 初始化或更新嵌入模型。
func (s *SemanticStore) InitializeEmbeddingModel(embeddingModel embedding.BaseEmbedding)

// AddDocs 将文档添加到指定集合（先嵌入再存储向量）。
func (s *SemanticStore) AddDocs(ctx context.Context, docs []DocTuple, tableName string, scopeID string) (bool, error)

// DeleteDocs 从指定集合删除文档。
func (s *SemanticStore) DeleteDocs(ctx context.Context, ids []string, tableName string) error

// Search 搜索与查询最相似的文档。返回 (id, score) 列表。
func (s *SemanticStore) Search(ctx context.Context, query, tableName string, scopeID string, topK int) ([]SearchResult, error)

// DeleteTable 删除整个集合。
func (s *SemanticStore) DeleteTable(ctx context.Context, tableName string) error

// ──────────────────────────── 非导出函数 ────────────────────────────

// createCollectionIfNotExists 若集合不存在则创建。
func (s *SemanticStore) createCollectionIfNotExists(ctx context.Context, collectionName string, embeddingDim int) error
```

**设计决策**：
- Python 用 `List[Tuple[str, str]]` 和 `List[Tuple[str, float]]`，Go 用具名结构体 `DocTuple` / `SearchResult`
- `_created_collections: set[str]` → `map[string]struct{}`
- `embeddingModel` 可为 nil（延迟初始化），Python 也允许 `embedding_model: Embedding | None = None`
- `createCollectionIfNotExists` 中调用 `migration.VectorRegistry.GetCurrentVersion(entityKey)` 写入 schema_version metadata——唯一依赖迁移系统的地方
- 向量集合 schema：id (VARCHAR PK) + embedding (FLOAT_VECTOR)，对齐 Python

### 6. `migration/operation/operation_registry.go`

对齐 Python `operation/operation_registry.py`。

```go
package operation

// ──────────────────────────── 结构体 ────────────────────────────

// OperationRegistry 按实体键管理链式升级操作的注册表。
// 对齐 Python: OperationRegistry
//
// 约定：
//   - entity_key 为字符串，如 "user_messages"、"vector_summary"
//   - 同一 entity_key 下所有 Operation 的 schema_version 单调递增
type OperationRegistry struct {
    // operations entity_key → Operation 列表（按 schema_version 升序）
    operations map[string][]Operation
}

// Operation 所有操作类型必须实现的接口。
// Go 中替代 Python BaseOperation 继承的多态契约。
// 具体类型（AddColumnOperation 等）嵌入 BaseOperation 结构体来满足此接口。
type Operation interface {
    // SchemaVersion 返回操作的 schema 版本号
    SchemaVersion() int
    // Description 返回操作的描述
    Description() string
}

// ──────────────────────────── 导出函数 ────────────────────────────

// NewOperationRegistry 创建空的注册表。
func NewOperationRegistry() *OperationRegistry

// Register 注册一个 Operation，确保 schema_version 单调递增。
// 对齐 Python: OperationRegistry.register
// 若违反单调递增约束，返回错误。
func (r *OperationRegistry) Register(entityKey string, op Operation) error

// GetOperations 获取指定实体在 [fromVersion, toVersion] 范围内的所有 Operation。
// 对齐 Python: OperationRegistry.get_operations
func (r *OperationRegistry) GetOperations(entityKey string, fromVersion, toVersion int) []Operation

// GetCurrentVersion 获取指定实体的最新 schema_version。
// 对齐 Python: OperationRegistry.get_current_version
// 无注册操作时返回 0。
func (r *OperationRegistry) GetCurrentVersion(entityKey string) int

// GetAllEntities 获取所有已注册的实体键。
// 对齐 Python: OperationRegistry.get_all_entities
func (r *OperationRegistry) GetAllEntities() []string

// GetAllOperations 获取内部映射的浅拷贝。
// 对齐 Python: OperationRegistry.get_all_operations
func (r *OperationRegistry) GetAllOperations() map[string][]Operation

// Clear 清空所有注册的操作（主要用于测试）。
// 对齐 Python: OperationRegistry.clear
func (r *OperationRegistry) Clear()

// SetOperations 设置内部映射（主要用于测试恢复状态）。
// 对齐 Python: OperationRegistry.set_operations
func (r *OperationRegistry) SetOperations(operations map[string][]Operation)
```
