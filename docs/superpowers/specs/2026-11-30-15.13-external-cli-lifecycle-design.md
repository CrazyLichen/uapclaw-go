## 1. 章节定位

外部 CLI 成员链路的核心：把第三方 CLI（adapter 路的 gemini/hermes/openclaw；provider 路的 dsh 等）作为一等团队成员拉起——校验、join 描述符注入、MCP team 工具注入、auth fallback 与模型切换、失败诊断、会话清理。claude/codex SDK 路依赖 15.7/15.8（均 ☐），本批留桩。

调用链（Python）：

```
TeamAgent 组建/spawn_member(role_type='external_cli', cli_agent=...)
  └─ spawn/external_cli_spawn.py
        ├─ descriptor_from_context()      → TeamJoinDescriptor（OPENJIUWEN_TEAM_JOIN 环境变量）
        ├─ _build_team_context_tracker()  → TeamContextTracker（外部 CLI 无 rail，团队状态折叠进下一条消息）
        └─ build_cli_runtime(ctx, ...)    四路分发：
              ① claude → ⛔ 入口守卫 pending 15.7/15.8（本批）
              ② codex  → ⛔ 同上
              ③ provider（dsh 等）→ _build_provider_member_runtime → ExternalHarnessMemberRuntime
              ④ adapter → 流式 CLI → ExternalCliRuntime；one-shot → ReinvokeCliRuntime
```

runtime 层（会话驱动器：轮次循环/进程生死/tracker 折叠）与 provider 层（特定 CLI 协议驱动）分工见讨论记录；`external_cli_agents` 条目是 CLI 级资产配置（路径/技能/模型/超时/env），成员 spec 只写身份 + cli_agent 名字。

## 3. 行为要点（保真清单）

1. **env 合成顺序**：`base_env（继承 env − adapter.env_strip_prefixes）→ extra_env → descriptor.to_env()` 最后覆盖（spawn.py:469-478：descriptor 是团队身份权威，extra_env 不许遮蔽 join）。Claude ssh_transport 非 nil 时 base_env 清空。
2. **`_with_home_env`**：`setdefault` 语义（OPENJIUWEN_HOME_ENV 已显式配不被覆盖）；Codex MCP env 白名单再传一跳进 MCP server。
3. **auth fallback 只给 native 登录成员**：`_is_native_endpoint` = config nil 或 api_base/provider 均空；有端点成员 fallback 丢弃；仅 fallback 被选中时 pop 掉 `model` 键（保持 CLI 默认模型）。
4. **one-shot CLI 稳定 session id**：canonical UUID 跨轮标识；首轮 `session_flag`、后续轮 `resume_flag`（配置了才切）、无 session id 的用 `continue_args`。
5. **MCP 注入三态**：launch flag / 带外注册（stderr 尾 500 字节进 Warn）/ 皆无 → loud warning，不静默。
6. **claude max_buffer_size 显式 nil** 必须取 DEFAULT（spawn.py:760-763），不落 SDK 1MiB 默认。→ claude 路暂缺，随 D-15.13-x 回填。
7. **tracker 折叠契约**：发送前 `pending_text`、发送成功后 `commit`；tracker 或 member_session 为 nil 不折叠。tracker 类型复用 25.0c 已交付的 `internal/agent_teams/tracker/`（**非偏差**）。
8. **入口守卫**：`CliAgent ∈ {claude, codex}` → `AGENT_TEAM_CONFIG_INVALID`，报文含 "pending 15.7/15.8"。
9. **descriptor scope 固定 "member"**：外部 CLI 是一等队员，spawn 时注入团队 system prompt。
10. **错误码**：校验失败 `AGENT_TEAM_CONFIG_INVALID`；pipe 缺失 `AGENT_TEAM_EXECUTION_ERROR`（spawn.py:522-526）。
11. **日志同步（规则 3）**：`[external-cli] preparing/launching/registering MCP/无 MCP 能力 Warn/注册失败 Warn` 逐点映射，f-string 变量全结构化字段化。
