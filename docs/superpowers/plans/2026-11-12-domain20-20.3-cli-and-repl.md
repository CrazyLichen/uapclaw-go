### Task 2.2 新建 `schema/reasoning_injector.go`

**文件**：`internal/swarm/schema/reasoning_injector.go`（新建，← `gateway/common/reasoning_injector.py` 172 行，去掉 patch 调用）

**内容**：
- `InjectReasoningParams(modelClientConfig, modelConfigObj map[string]any) map[string]any`
- `BuildReasoningModelRequestKwargs(modelClientConfig, modelConfigObj map[string]any, modelName string) map[string]any`
- 内部：`resolveModelName`、`modelConfigToDict`、`runtimeConfigCopy`、`buildModelRequestKwargs`

**`InjectReasoningParams` 四步**（`reasoning_injector.py:71-88`）：
```
1. model_config_dict = dict(model_config_obj)
2. level = NormalizeReasoningLevel(model_config_dict["reasoning_level"])
3. runtime_model_config = pop(model_config_dict, "reasoning_level")   ← 注意：pop 掉
4. override = ResolveSamplingOverride(api_base || base_url, model_name || model)
   override 非空 → runtime_model_config 合入 temperature/top_p
   level == "" → 返回 runtime_model_config
   level 非空 → runtime_model_config["reasoning"] = ReasoningConfigForLevel(level)
```

**`buildModelRequestKwargs` 六步**（`reasoning_injector.py:91-138`）：
```
1. request_kwargs = dict(model_config_obj)
2. is_agentos = request_kwargs["_source"] == "agentos"
   是 → legacy = pop("max_tokens")；"context_window" 不存在且 legacy 非 nil → kwargs["context_window"] = legacy
3. pop "model" / "model_name" / "reasoning_level"
4. pop "_source"
5. context_window 归一：bool → 删；int() 失败 → 删；<= 0 → 删（Go 用 config.ParsePositiveTokens）
6. request_kwargs["model"] = resolveModelName(model_name, model_config_obj)
```

**关键约束**：
- **不实现** `core_has_context_window_field()` 探测（spec 偏差 E-5）：Go 的 core 已有正式字段，永远走「保留」分支
- `modelConfigToDict` 接受 `nil` / `map[string]any` / 结构体（Go 无 pydantic，只需处理前两种）
- **不复刻** `apply_provider_compat_patches()`（spec 偏差 E-4，Go 无 monkey-patch）
