# 23.4a intellirouter 路由器核心移植 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 PyPI `intelli-router 0.1.0b1` 的路由器核心（状态机/策略/provider 适配/健康检查/事件桥/router 本体）按规则 9 一比一移植为 `internal/agentcore/foundation/llm/intellirouter/` 内部包。

**Architecture:** 纯新增包，无外部 Go 依赖；每个 Python 文件对应一个 Go 文件，注释标 Python 符号与行号；asyncio 并发 → goroutine + mutex（指针接收者）；动态类继承 → 构造期函数指针（spec 偏差 D-4/D-5）。

**Tech Stack:** Go 1.22+，net/http，encoding/json；测试用标准库 testing + httptest。

**基线源码（唯一事实来源）：**
```bash
mkdir -p /tmp/ir-baseline && cd /tmp/ir-baseline
pip3 download intelli-router==0.1.0b1 --no-deps -d . -q
unzip -o -q intelli_router-0.1.0b1-py3-none-any.whl -d src
# 核对：47 个 .py 文件 / 8385 行；源码根 = /tmp/ir-baseline/src/intelli_router/
```
下文「PyPI 源码」均指该根下路径。若 /tmp 被清理（本机有清理任务）先重跑上述命令。

**与上游 agent-core 的关系：** agent-core 快照里 `openjiuwen/core/foundation/llm/routing/intelli_router_errors.py` 假设的 router 公开面（`state.cooldown_until`/`state.consecutive_failures`/`state.reset_deployment`/`strategy.fallback_tag`）是本包 Go 版必须暴露的契约——Task 6/7 的导出面以此为准。
