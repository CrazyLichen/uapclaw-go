> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把第三方 CLI（adapter 路 gemini/hermes/openclaw；provider 路 dsh 等）作为一等团队成员拉起的完整 spawn/运行/清理链路；claude/codex SDK 路留桩 ⤵️ 15.7/15.8。

**Tech Stack:** Go 1.22 / os/exec 子进程 / google/uuid（或仓库既有 uuid 依赖）/ 既有 `agentcore/harness_providers` 注册缝（dsh） / 既有 `agent_teams/tracker`（25.0c TeamContextTracker）。
