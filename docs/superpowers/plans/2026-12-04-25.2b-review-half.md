# 25.2b 调度模式·review 半区 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 scheduled dispatch 的 review 半区：`_reconcile_reviews` 全链（临时 reviewer harness / 计票裁决 / 结算返工升级 / nudge 重派）+ review 驱动的团队技能演进（evolving signal + rail 挂点 + coordinator）+ 轨迹面缺口随批补（TrajectorySpanProcessor + EvolutionRail 订阅窗口）+ R-6/R-7/F_119/死字段回填 + §7 集成硬要求。

**Architecture:** Python `agent/scheduling/` review 半区 1:1 移植到 `internal/agent_teams/agent/coordination/scheduling/`（25.2a 已建骨架与窄接口缝）；review_feedback_evolution 三件构成（`internal/evolving/signal/review_feedback.go` + `team_skill_evolution_rail.go` 五方法 + coordinator）；轨迹面 processor 移植进 `internal/evolving/trajectory/processor.go` 并接线 EvolutionRail 订阅/drain/scope 窗口（主读面），既有 aggregator 降为回落。

**Tech Stack:** Go 1.22 / sqlite（sqlite_fts5）/ go.opentelemetry.io/otel/sdk（SpanProcessor）/ 既有 coordination/event_bus + harness rails / suite 集成测试。

**Spec:** `docs/superpowers/specs/2026-12-04-25.2b-review-half-design.md`（裁决 §9 / 偏差 §8 / 集成硬要求 §7 / 实施顺序 §10）

- 每处移植在注释写 Python 符号与行号；Python 有而 Go 无的步骤视为 parity 缺陷补齐（规则 9/12/13）。
