# 10.6.1-2 Prompt Builder 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 对齐 Python 的 `jiuwenswarm/agents/harness/` 目录结构，在 Go 的 swarm 层新建 `common/prompt/` 和 `code/prompt/` 两个包，实现 Agent 模式和 Code 模式的 prompt 构建逻辑。

**Architecture:** 新建 `swarm/agents/harness/common/prompt/` 包（含 `BuildResponseSection()` + `BuildAgentIdentityPrompt()`）和 `swarm/agents/harness/code/prompt/` 包（含 8 个 Code section builder + `BuildCodeSystemPrompt()`）。将 `deep_adapter.go` 中的 `buildAgentIdentityPrompt()` 方法迁入新包，adapter 改为调用新包入口函数。

**Tech Stack:** Go, 对齐 Python `jiuwenswarm/agents/harness/common/prompt/prompt_builder.py` 和 `code/prompt/code_prompt_builder.py`

**关键约束：提示词文本必须逐行从 Python 源码复制，禁止自己翻译。**
