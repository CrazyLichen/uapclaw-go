> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 27.8 富媒体个人版链路——media/document 上传落盘、分块上传/下载、steer 图片校验、Gateway 大图分流（单机档）、rsi.artifact 三代理、浏览器腿 150MiB 帧修复；单测 + 真实 e2e（网关↔server 上行/下行）双覆盖。

**Tech Stack:** Go 1.22、`testify/suite`、`gorilla/websocket`、`//go:build integration`、标准库 `image`（替代 PIL）。

## 前置事实（实施前必读，均为实测）

1. **帧上限两腿不同**（`gateway/common/ws_limits.py`）：浏览器腿 `WEB_WS_MAX_MESSAGE_BYTES = 150MiB`，内部腿 `AGENT_WS_MAX_MESSAGE_BYTES = 8MiB`、`AGENT_WS_SEND_BUDGET_BYTES = 6MiB`。Go `web_connect.go:101 wsReadLimit = 8MiB` 是**浏览器腿**，必须改 150MiB；`gateway_server.go:64 gwReadLimit = 8MiB` 是内部腿，不动。
2. **分流阈值**（`app_web_handlers.py:2063` + `gateway/routing/agent_http_bridge.py:31`）：`E2A_PAYLOAD_MAX_BYTES = 4MiB`；逐 item 判 `base64 解码后字节数 > E2A_PAYLOAD_MAX_BYTES - params 其余 JSON 开销`，超预算 item 在 Gateway 侧落盘（单机档直写共享目录）。
3. **图片约束**（`media_attachments.py`）：`_MAX_IMAGE_BYTES = 10MB`、`_MAX_IMAGE_COUNT = 8`；MIME→后缀白名单 png/jpg/webp/gif，`.jpeg/.jfif` 别名保留原名不重复拼后缀。文档（`document_attachments.py`）：`_MAX_DOCUMENT_BYTES = 100MB`、`_MAX_DOCUMENT_COUNT = 8`。
4. **ReqMethod 常量在 Go 侧缺失**：`internal/swarm/schema/req_method.go` 无 MEDIA_*/DOCUMENT_*/PATH_*/FILE_*/IM_* 常量（Python 侧 MEDIA_PERSIST 等在 pinned protocol 包，wire 值见 `mapped.py:796` 一节：`media.persist`、`media.discard`、`document.persist`、`document.formats`、`path.select_directory`、`path.select_files`、`file.import_url`、`file.upload_chunk`、`file.read_upload_chunk`、`file.download_verified_chunk`）。本批新增 10 个常量（im.file_persist、workspace.* 四个**不加**——见 spec D-27.8-1/2）。
5. **server 分发位置**：Python WorkspaceFileAdapter 在 GatewayAdapter 链中先于 agent invoke 短路（`workspace_file_adapter.py:129 handle`）；Go 对应短路点是 `internal/swarm/server/handle_chat.go:30 handleUnaryImpl` 的特殊方法 switch（`ReqMethodInitialize` 等同层）——文件域 case 加在这个 switch，不经 `agentRuntime.Invoke`。
6. **e2e 真链路模板**：`tests/integration/swarm/gateway/team_continuous_dialog_test.go:37-160`——进程内 `transport.NewChannelTransport` + `routing.NewAgentClient` + `server.NewAgentServer` + `gateway.NewAppGatewayServer`，客户端 `websocket.DefaultDialer.Dial("ws://127.0.0.1:<wsPort>/ws")` 真拨号。**端口探活必须读 ListenErr**（Start 非阻塞吞 bind 错，见 gateway-itest-port-collision 记忆）。web 包现有套件走 `testhelpers.ServerEnv`（E2A 直投，非真网关），e2e 新套件不用它。
7. **下载令牌地基已有**：`internal/swarm/agents/harness/common/tools/web_file_download.go`（`WebFileDownloadManager`，`ValidateFileDownloadToken` 同源函数已存在）；`file.download_verified_chunk` 只做 adapter 侧消费，不重写令牌层。
8. **`is_path_within_user_dirs` 已有**：`internal/swarm/agents/harness/common/tools/web_file_download.go`（Python `web_file_download.py` 同名函数），upload_chunk 直接复用，不复制。
9. **工作区有并发会话**：每个 Task 的 `git add` 必须显式列本 Task 文件，禁止 `git add .` / `-A`。
10. **规则 6/11 口径**：本地 `go build ./...` + `go vet ./...` + 全量回归 + 集成 `-race` 绿 + 推送即交付，不追 CI。
